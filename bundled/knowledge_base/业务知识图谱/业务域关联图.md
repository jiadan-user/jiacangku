## 2. 跨域数据流转

### 2.1 订单款项流转（二手交易 → 钱包）

```mermaid
sequenceDiagram
    participant 买家
    participant 二手交易系统
    participant 钱包系统
    participant 卖家
    
    买家->>二手交易系统: 下单并支付
    二手交易系统->>二手交易系统: 订单状态：待发货
    卖家->>二手交易系统: 确认发货
    二手交易系统->>二手交易系统: 订单状态：待收货
    买家->>二手交易系统: 确认收货
    二手交易系统->>二手交易系统: 订单状态：已完成
    二手交易系统->>钱包系统: 款项结算
    钱包系统->>钱包系统: 余额增加
    卖家->>钱包系统: 提现到银行账户
```

### 2.2 KYC状态流转（用户域 → 钱包/交易域）

```mermaid
sequenceDiagram
    participant 卖家
    participant 用户系统
    participant 钱包系统
    participant 交易系统
    
    卖家->>用户系统: 提交KYC认证资料
    用户系统->>用户系统: 审核通过 (Verified)
    用户系统->>钱包系统: 同步KYC状态 (Verified)
    钱包系统->>钱包系统: 解锁提现权限
    用户系统->>交易系统: 同步KYC状态 (Verified)
    交易系统->>交易系统: 解锁收款/高优发布权限
```

### 2.3 AI功能调用（各业务域 → 通用业务域）

```mermaid
sequenceDiagram
    participant 发布页
    participant AI推荐服务
    participant 详情页
    participant AI自动回复服务
    
    发布页->>AI推荐服务: 上传图片/输入标题
    AI推荐服务->>发布页: 返回推荐类目
    发布页->>发布页: 用户选择类目并发布
    
    详情页->>详情页: 买家点击Contact
    详情页->>AI自动回复服务: 买家发送消息
    AI自动回复服务->>详情页: AI自动回复消息
```

### 2.4 B 端职位发布与用户信息（UMC / 登录态）

```mermaid
sequenceDiagram
    participant 招聘方
    participant Biz发布前台
    participant 用户与UMC
    participant Jobs供给

    招聘方->>Biz发布前台: 打开发布入口（未登录）
    Biz发布前台->>用户与UMC: 跳转登录
    用户与UMC->>Biz发布前台: 登录成功 + 回跳 fromUrl
    招聘方->>Biz发布前台: 首次填写雇主信息
    Biz发布前台->>用户与UMC: 读取/校验邮箱、验证码等
    招聘方->>Biz发布前台: Confirm 雇主信息
    Biz发布前台->>Jobs供给: 创建/更新职位发布上下文
    招聘方->>Biz发布前台: Job Basic / Requirement / Detail / Post
    Biz发布前台->>Jobs供给: 发布职位
```
