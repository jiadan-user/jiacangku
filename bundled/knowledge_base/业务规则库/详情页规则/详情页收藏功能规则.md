# 详情页收藏功能规则

## 1. 功能概述
- **业务价值**: 让用户快速收藏感兴趣的帖子,方便后续查看和管理,提升用户粘性和平台活跃度
- **用户角色**: 
  - 访客: 可查看收藏按钮,点击后触发登录流程
  - 登录用户: 可直接收藏/取消收藏,管理收藏列表
  - 买家/卖家: 均可使用收藏功能
- **入口位置**: 详情页图片下方操作区域,心形图标+"Favourites"文字
- **依赖模块**: 
  - 登录认证服务
  - 收藏列表服务
  - Toast提示组件
  - 用户状态管理

## 2. 核心流程

### 2.1 主流程(访客)
1. **访客查看详情页** → 看到收藏按钮(空心图标)
2. **点击收藏按钮** → 触发登录弹窗
3. **在弹窗中登录** → 登录成功后自动收藏
4. **图标变为实心** → 收藏成功,可能显示toast提示

### 2.2 主流程(登录用户)
1. **登录用户查看详情页** → 看到收藏按钮(空心或实心)
2. **点击收藏按钮** → 直接收藏/取消收藏
3. **图标状态切换** → 空心↔实心
4. **同步到收藏列表** → 收藏列表实时更新

### 2.3 异常流程
- **场景1**: 访客取消登录弹窗 → 弹窗关闭,返回详情页,收藏按钮仍为空心
- **场景2**: 网络慢速时收藏 → 显示加载状态,请求完成后状态更新
- **场景3**: 快速连续点击 → 防抖处理,最终状态稳定
- **场景4**: 退出登录 → 收藏按钮变为空心,再次点击触发登录

## 3. 业务规则

### 3.1 按钮展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 位置展示 | 位于详情页图片下方操作区域 | 与价格、分享按钮等在同一水平行 |
| 首屏可见 | 收藏按钮在首屏可见,无需滚动 | 核心操作位置 |
| 图标样式-未收藏 | 心形图标空心(outline样式) | 明确未收藏状态 |
| 图标样式-已收藏 | 心形图标实心(filled样式) | 明确已收藏状态 |
| 文字标签 | 显示"Favourites"文字 | 英文站标准文案 |
| 可交互性 | cursor为pointer | 鼠标悬停提示可点击 |
| 悬停效果 | 鼠标悬停时有视觉反馈 | 颜色变化、高亮等 |
| 工具提示 | 可能显示tooltip | 如"Add to favourites" |

### 3.2 访客状态规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 初始状态 | 收藏按钮显示为空心图标 | 未登录无法查看收藏状态 |
| 点击触发 | 点击收藏按钮弹出登录弹窗 | modal/dialog形式 |
| 弹窗内容 | 包含Email、Password输入框和Login按钮 | 标准登录表单 |
| 弹窗关闭-X按钮 | 点击关闭按钮(X)关闭弹窗 | 返回详情页 |
| 弹窗关闭-遮罩层 | 点击弹窗外遮罩层关闭弹窗 | 返回详情页 |
| 关闭后状态 | 收藏按钮仍为空心图标 | 未收藏状态 |
| 可重复点击 | 可以再次点击收藏按钮 | 重新触发登录 |

### 3.3 登录并收藏规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 登录成功 | 输入有效账号密码,点击Login成功登录 | 如shenchang@58.com/123456Tt |
| 弹窗自动关闭 | 登录成功后登录弹窗自动关闭 | 无需手动关闭 |
| 自动收藏 | 登录成功后自动执行收藏操作 | 一气呵成 |
| 图标变化 | 收藏按钮图标立即变为实心 | 视觉反馈 |
| 页面不刷新 | 收藏操作不触发页面刷新 | SPA行为 |
| 成功提示 | 可能显示toast提示 | 如"Added to favourites" |

| 图标立即变化 | 点击后图标立即变为实心 | 无延迟 |
| 页面不刷新 | 收藏操作不触发页面刷新 | SPA行为 |
| 成功提示 | 可能显示toast提示 | 如"Added to favourites" |

| 规则项 | 规则内容 | 说明 |

| 重复点击 | 支持重复点击收藏按钮 | 状态在空心↔实心之间切换 |

### 3.7 防抖与性能规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 防抖处理 | 快速连续点击时有防抖处理 | 如间隔<100ms |
| 最终状态 | 防抖后最终状态稳定 | 已收藏或未收藏 |
| 无错误提示 | 快速点击不会导致错误提示 | 用户体验 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | 登录失败 | 输入错误的账号密码 | "Invalid email or password" |
| - | 收藏失败 | 网络异常或接口错误 | "Failed to add to favourites" |
| - | 取消收藏失败 | 网络异常或接口错误 | "Failed to remove from favourites" |
| - | 请求超时 | 网络慢速或超时 | "Request timeout, please try again" |
| 401 | 未登录 | 会话过期后操作 | 弹出登录弹窗 |
| - | 加载收藏列表失败 | 网络异常 | "Failed to load favourites list" |
