# 详情页推荐模块规则

## 1. 功能概述
- **业务价值**: 通过智能推荐相似商品,提升用户留存和转化率,延长用户浏览时长,增加交易机会
- **用户角色**: 
  - 访客: 可查看推荐模块,点击收藏触发登录引导
  - 买家: 可查看推荐模块,可直接收藏/取消收藏推荐商品
  - 推荐展示对所有用户开放,不区分登录态
- **入口位置**: 详情页底部,Description和Location之后,Footer之前
- **依赖模块**: 
  - 推荐算法服务(推荐商品计算)
  - 收藏服务(收藏/取消收藏)
  - 登录服务(访客收藏引导)
  - 商品详情服务(卡片信息渲染)

## 2. 核心流程

### 2.1 推荐模块展示流程
1. **用户进入详情页** → 滚动到页面底部
2. **加载推荐模块** → 触发推荐算法
3. **渲染推荐商品** → 展示4张可见卡片,总计最多6张
4. **用户浏览交互** → 点击卡片跳转/收藏/左右箭头翻页

### 2.2 推荐商品跳转流程
1. **用户点击推荐商品卡片** → 当前标签页跳转
2. **新详情页加载** → 显示商品详情
3. **新详情页推荐模块** → 延续推荐链路
4. **用户可后退** → 浏览器后退按钮返回上一页

### 2.3 收藏功能流程(已登录)
1. **用户点击收藏图标(空心)** → 添加到收藏夹
2. **图标状态切换** → 空心变实心
3. **数据同步** → 收藏列表实时更新

### 2.4 收藏功能流程(访客)
1. **访客点击收藏图标** → 弹出登录弹窗
2. **用户登录** → 完成登录后自动收藏
3. **图标状态切换** → 空心变实心

## 3. 业务规则

### 3.1 推荐模块展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 模块位置 | 详情页底部,Description/Location之后,Footer之前 | 固定位置 |
| 模块标题 | "You may also like" | 固定文案,左上角 |
| 可见商品数 | 4张(桌面端) | 受屏幕宽度限制 |
| 总商品数 | 最多6张 | 后端推荐算法返回 |
| 展示方式 | 横向排列,流式滚动 | 支持左右箭头翻页 |
| 适用类目 | 非招聘、非房产类目 | 如Home Decor、Pet、Kitchen等 |
| 不展示场景 | 部分详情页无推荐模块 | 取决于后端推荐算法,可能与商品类目、数据量相关 |
| 登录态无关 | 访客和登录用户均可查看 | 开放功能 |

### 3.2 推荐商品卡片规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 卡片构成 | 商品主图+标题+价格+Free Delivery标签+收藏图标 | 5个核心元素 |
| 商品主图 | 清晰可见,占据卡片主要面积 | 图片质量要求 |
| 商品标题 | 截断显示,hover显示完整标题 | 文本溢出处理 |
| 价格格式 | 美元符号+数字(如$14.03) | 货币格式 |
| Free Delivery标签 | 带图标,位于价格下方 | 物流信息 |
| 收藏图标 | 位于卡片右上角 | 快捷收藏入口 |
| 卡片宽度 | 固定宽度,一行显示4张 | 响应式布局 |
| 卡片间距 | 左右均匀间距 | 视觉统一 |

### 3.3 推荐商品跳转规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 跳转方式 | 当前标签页跳转 | 非新标签页打开 |
| 跳转目标 | 被点击商品的详情页 | URL变更 |
| 埋点触发 | `detail_recommend_item_cli` | 点击事件埋点 |
| 历史记录 | 浏览器历史记录正常记录 | 可通过后退按钮返回 |
| 推荐延续 | 新详情页也包含推荐模块 | 推荐链路延续 |
| 状态保持 | 新详情页正常加载商品信息 | 无状态丢失 |

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 图标位置 | 卡片右上角 | 固定位置 |

| 已收藏状态 | 黑色实心图标 | 视觉反馈 |
| 添加收藏 | 点击空心图标→变实心 | 状态切换 |
| 取消收藏 | 点击实心图标→变空心 | 状态切换 |

| 页面跳转 | 不跳转,停留在当前详情页 | 用户体验 |
| 状态隔离 | 其他推荐商品收藏状态不受影响 | 独立操作 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | 推荐模块不展示 | 后端推荐算法未返回推荐商品 | 无提示,直接不展示模块 |
| - | 商品图片加载失败 | 图片URL无效或网络异常 | 显示占位图 |
| - | 收藏失败 | 网络异常或收藏服务不可用 | Toast提示"收藏失败,请稍后重试" |
| - | 取消收藏失败 | 网络异常或收藏服务不可用 | Toast提示"取消收藏失败,请稍后重试" |
| - | 推荐商品数量不足 | 推荐算法返回<6张商品 | 正常展示,箭头根据实际数量禁用 |
| - | 登录弹窗打开失败 | JS错误或组件加载失败 | 降级处理,不阻塞主流程 |

## 5. 依赖模块

### 5.1 上游依赖(谁调用我)
- **详情页模块**: 详情页底部渲染推荐模块
- **推荐算法服务**: 计算并返回推荐商品列表

### 5.2 下游依赖(我调用谁)
- **推荐算法服务**: 
  - 根据当前商品信息(类目、ID、属性)计算推荐商品
  - 返回最多6张推荐商品信息
  - 支持个性化推荐(基于用户行为)
- **收藏服务**: 
  - 添加商品到收藏夹
  - 从收藏夹移除商品
  - 查询商品收藏状态
- **登录服务**: 
  - 弹出登录弹窗
  - 处理登录流程
  - 登录成功后回调收藏操作
- **商品详情服务**: 
  - 获取推荐商品的图片、标题、价格等信息
  - 渲染推荐商品卡片
- **埋点服务**: 
  - 记录推荐模块曝光
  - 记录推荐商品曝光
  - 记录推荐商品点击
  - 记录收藏操作

### 5.3 跨域交互说明
- **详情页业务域**: 推荐模块是详情页的一部分
- **推荐业务域**: 推荐算法服务提供推荐商品列表
- **收藏业务域**: 收藏服务处理收藏/取消收藏操作
- **用户业务域**: 登录服务处理访客收藏引导登录

## 6. 已知问题
- **跳转行为**: 当前标签页跳转可能导致用户迷失浏览路径,建议改为新标签页打开或添加"返回上一页"按钮
- **推荐模块缺失**: 部分详情页无推荐模块,可能影响用户留存和转化,建议排查推荐算法逻辑
- **推荐商品相关性**: 需验证推荐算法是否真正基于类目/相似度推荐
