# 详情页图片区域规则

## 1. 功能概述
- **业务价值**: 图片是用户了解商品/服务的主要视觉入口,清晰展示图片能提升用户购买意愿和信任度
- **用户角色**: 
  - 访客: 可正常查看所有图片功能
  - 买家: 可正常查看所有图片功能
  - 图片查看不区分登录态,所有用户权限一致
- **入口位置**: 详情页顶部图片展示区域
- **依赖模块**: 
  - 图片加载服务
  - 图片预览lightbox/modal组件
  - 图片切换导航组件

## 2. 核心流程

### 2.1 单图模式流程
1. **用户进入详情页** → 加载单张主图
2. **查看主图** → 图片清晰展示
3. **点击主图(可选)** → 打开放大预览

### 2.2 多图模式流程
1. **用户进入详情页** → 加载主图和缩略图列表
2. **查看默认第一张图** → 主图显示第一张,第一个缩略图高亮
3. **点击缩略图切换** → 主图切换,缩略图高亮同步
4. **使用箭头导航** → 循环切换图片
5. **点击主图放大** → 打开大图预览弹层
6. **大图模式浏览** → 左右箭头切换,缩略图翻页(7+图片)

## 3. 业务规则

### 3.1 图片模式识别规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 单图模式 | 仅有1张图片的详情页 | 展示单张主图 |
| 多图模式 | 有2张及以上图片的详情页 | 展示主图+缩略图列表 |
| 模式自动识别 | 根据图片数量自动选择展示模式 | 无需手动配置 |

### 3.2 单图模式规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 主图展示 | 显示该商品的唯一图片 | 清晰可见,无加载失败 |
| 图片尺寸 | 适配展示区域,保持比例不变形 | 不超出容器边界 |
| 无缩略图 | 不显示缩略图区域 | 简洁展示 |
| 无切换箭头 | 不显示上一张/下一张箭头 | 单图无需切换 |
| 占位图 | 图片加载失败时显示占位图或提示 | 如"Image not available" |
| 布局不错乱 | 加载失败时页面布局不错乱 | 容错处理 |

### 3.3 多图模式-基础展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 主图区域 | 大尺寸展示当前图片 | 清晰可见 |
| 缩略图列表 | 小尺寸,横向或纵向排列 | 整齐排列 |
| 默认第一张 | 主图默认显示第一张图片 | 初始状态 |
| 第一个高亮 | 第一个缩略图默认高亮 | 如边框、阴影、透明度 |
| 数量一致 | 缩略图数量=实际图片总数 | 无重复或缺失 |
| 图片加载 | 所有图片成功加载,无破损图标 | 性能要求 |
| 图片清晰 | 主图清晰,缩略图可辨识 | 质量要求 |
| 不超出边界 | 图片不超出容器边界 | 无溢出或裁剪错误 |

### 3.4 多图模式-切换交互规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 点击切换 | 点击缩略图立即切换主图 | 无延迟 |
| 切换流畅 | 主图切换流畅,无卡顿或闪烁 | 用户体验 |
| 高亮同步 | 点击的缩略图变为高亮,之前高亮取消 | 同步更新 |
| 唯一高亮 | 任何时刻只有一个缩略图处于高亮状态 | 状态唯一性 |
| 箭头导航 | 主图区域显示左右箭头按钮 | 可能悬停时显示 |
| 循环切换 | 第一张点左箭头→最后一张,最后一张点右箭头→第一张 | 循环逻辑 |
| 箭头不禁用 | 左右箭头始终可点击,不禁用 | 循环特性 |
| 点击放大 | 点击主图打开放大预览弹层 | lightbox/modal |

### 3.5 多图模式-放大预览规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 弹层打开 | 点击主图打开全屏或大尺寸预览弹层 | modal |
| 高清展示 | 弹层显示当前主图的高清版本 | 质量提升 |
| 遮罩背景 | 半透明黑色遮罩背景 | 聚焦主图 |
| 关闭按钮 | 右上角有关闭按钮(× 图标) | 明确关闭入口 |
| 导航箭头 | 显示左右导航箭头用于切换图片 | 便捷浏览 |
| cursor提示 | 鼠标悬停在主图上时cursor变为可点击样式 | 交互提示 |

### 3.6 大图模式-主图切换规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 左右箭头 | 大图弹层显示左右箭头导航按钮 | 清晰可见 |
| 循环逻辑 | 第一张点左箭头→最后一张,最后一张点右箭头→第一张 | 与详情页一致 |
| 切换流畅 | 循环切换流畅,有淡入淡出或滑动动画(可选) | 视觉反馈 |
| 箭头不禁用 | 左右箭头始终保持可点击,不禁用 | 循环特性 |
| 缩略图高亮 | 大图弹层底部或侧边显示缩略图列表 | 状态同步 |
| 高亮同步 | 当前显示的主图对应的缩略图高亮 | 实时同步 |
| 状态一致 | 每次切换主图时,缩略图高亮立即同步更新 | 无延迟 |

### 3.7 大图模式-关闭规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 关闭方式-按钮 | 点击关闭按钮(×)关闭弹层 | 标准交互 |
| 关闭方式-键盘 | 按ESC键关闭弹层 | 快捷操作 |
| 关闭方式-遮罩 | 点击弹层外遮罩区域关闭弹层 | 直观交互 |
| 返回状态 | 关闭后返回详情页,主图保持关闭前的状态 | 状态保持 |
| 滚动位置 | 页面滚动位置保持不变 | 用户体验 |
| 关闭动画 | 关闭动画流畅(淡出效果) | 视觉反馈 |

### 3.8 大图模式-缩略图翻页规则(7+图片)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 条件触发 | 图片数量≥8张时显示翻页箭头 | 条件展示 |
| 可见数量 | 缩略图区域一次性显示7个缩略图 | 固定窗口 |
| 翻页箭头 | 缩略图区域显示左右翻页箭头按钮 | 清晰可见 |
| 箭头样式 | 样式与主图箭头一致或相似 | 视觉统一 |
| 初始状态 | 显示第1-7张图片 | 默认起始 |
| 逐张滚动 | 每次点击箭头,缩略图列表向左/右滚动一张 | 逐张翻页 |
| 循环翻页 | 在最后一组点右箭头→回到第1-7张,在第一组点左箭头→到最后一组 | 循环逻辑 |
| 滚动流畅 | 滚动过程流畅,有平滑的过渡动画 | 视觉反馈 |
| 选中可见 | 当前选中的缩略图始终在可见区域内 | 自动调整 |

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | 图片加载失败 | 图片URL无效或网络异常 | 显示占位图或"Image not available" |
| - | 主图加载失败 | 主图URL无效 | 显示占位图 |
| - | 缩略图加载失败 | 缩略图URL无效 | 显示占位图或默认图标 |
| - | 大图预览加载失败 | 高清图URL无效 | 显示原始主图或占位图 |
