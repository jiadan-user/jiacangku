# 详情页核心信息区域规则

## 1. 功能概述
- **业务价值**: 展示帖子的核心信息,让用户快速了解帖子内容,促进交易达成
- **用户角色**: 
  - 访客: 可查看所有核心信息
  - 登录用户: 可查看所有核心信息
  - 功能对所有用户开放,无需登录
- **入口位置**: 详情页顶部核心区域
- **依赖模块**: 
  - 列表页(用户从列表页进入详情页)
  - 帖子数据服务
  - 地理位置服务

## 2. 核心流程

### 2.1 主流程
1. **用户从列表页进入详情页** → 点击帖子卡片
2. **详情页加载** → 渲染核心信息区域
3. **展示核心信息** → 价格、标题、地点、时间、描述按顺序展示
4. **用户浏览信息** → 查看帖子详细内容

### 2.2 异常流程
- **场景1**: 列表页与详情页信息不一致 → 以详情页为准
- **场景2**: 核心信息加载失败 → 显示占位符或错误提示
- **场景3**: 描述内容超长 → 提供展开/收起功能

## 3. 业务规则

### 3.1 价格区域规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 价格展示 | 价格清晰可见,位于页面显著位置 | 通常在顶部或标题附近 |
| 价格格式 | 包含货币符号"$" | 美国站使用美元符号 |
| 千分位分隔符 | 价格≥1000时使用千分位分隔符 | 如"$1,200" |
| 小数位 | 小数点后最多2位 | 如"$12.99" |
| 免费帖子 | 价格显示"Free"或等价标识 | 不显示货币数字 |
| 无价格帖子 | 显示"Contact for price"或不显示价格区域 | 某些服务类、活动类帖子 |
| 价格一致性 | 列表页价格=详情页价格 | 格式一致(货币符号、千分位) |
| 字体大小 | 价格文字大号突出显示 | 吸引用户注意 |

### 3.2 标题区域规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 标题展示 | 标题清晰可见,位于页面顶部核心位置 | 通常为h1或较大字号 |
| 标题必填 | 标题内容非空,必须有内容 | 所有帖子都必须有标题 |
| 标题一致性 | 列表页标题=详情页标题 | 去除空格后一致 |
| 标题长度 | 字符数在5-200个字符范围内 | 合理范围 |
| 超长标题 | 不应换行超过3行 | 保持可读性 |
| 特殊字符 | 不包含异常字符(乱码、特殊符号过多) | 如"�"、"\x00" |
| 可读性 | 文字颜色与背景有足够对比度 | 不被其他元素遮挡 |
| 完整展示 | 标题完整展示,无省略号 | 除非内容超长 |

### 3.3 发帖地点区域规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 地点展示 | 地点区域清晰可见 | 位于标题下方、发布时间上方 |
| 地点必填 | 显示具体地址或城市名称,非空 | 所有帖子都必须有地点 |
| 位置图标 | 通常伴有位置图标(pin icon) | 视觉提示 |
| 不可点击 | 地点元素为纯文本展示,不支持点击 | 不是链接 |
| 地点一致性 | 列表页地点=详情页地点(或详情页更详细) | 核心地名一致 |
| 地点格式 | 格式规范如"City, State"或"City, State ZIP" | 可读性强 |
| 无异常字符 | 不包含异常字符或乱码 | 不以逗号开头 |
| 元素位置 | 垂直排列:标题→地点→发布时间 | 固定位置关系 |
| 类别限制 | 招聘(Jobs)和房产(Property)类别不适用 | 这些类别有不同布局 |

### 3.4 发布时间区域规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 时间展示 | 发布时间清晰可见 | 必填字段 |
| 时间格式-相对 | 相对时间包含"ago"、"minute"、"hour"、"day" | 如"2 hours ago" |
| 时间格式-绝对 | 绝对时间符合日期格式 | 如"Mar 20, 2026"或"2026-03-20" |
| 时间必填 | 时间信息非空 | 所有帖子都必须有时间 |
| 时间逻辑 | 时间合理,不显示负数或未来时间 | 逻辑正确 |
| 时间一致性 | 列表页与详情页时间基本一致 | 允许相对时间小幅变化(±1) |
| 新帖子 | 刚发布的帖子(<1 hour)显示相对时间 | 如"30 minutes ago" |
| 时间更新 | 从列表到详情可能经过几分钟,时间可能变化 | 如"59 minutes ago"→"1 hour ago" |

### 3.5 描述区域规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 描述展示 | 描述区域清晰可见 | 位于标题/价格/地点/时间下方 |
| 描述必填 | 描述内容非空,必须有内容 | 所有帖子都必须有描述 |
| 最小长度 | 描述至少包含10个字符 | 不能为空或过短 |
| 文字排版 | 段落、换行正确 | 保持原格式 |
| 完整展示 | 描述内容完整显示,无截断 | 或提供展开按钮 |
| 展开功能 | 内容过长时有"Read more"/"Show more"展开按钮 | 可选功能 |
| 展开后 | 展开后显示完整内容,展开文本长度>初始文本长度 | 完整展示 |
| 收起功能 | 展开后显示"Show less"按钮 | 恢复初始状态 |
| 格式化-换行 | 换行符正确处理(HTML `<br>`或段落`<p>`) | HTML结构合理 |
| 格式化-链接 | 链接正确渲染 | 如果包含URL |
| 格式化-特殊字符 | 特殊字符正确显示 | emoji、标点符号 |
| 文本对齐 | 文本对齐合理 | 可读性强 |

### 3.6 综合展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 整体布局 | 价格、标题、地点、时间、描述同时可见 | 在一屏或滚动后可见 |
| 排列顺序 | 通常为:标题→价格→地点→时间→描述 | 合理顺序 |
| 元素间距 | 元素之间间距适当,不重叠 | 视觉舒适 |
| 必填字段 | 标题、时间、描述为必填字段 | 不可为空 |
| 可选字段 | 价格字段可选 | 部分类别可能不显示价格 |
| 刷新一致性 | 刷新后价格、标题、地点、描述保持一致 | 时间可能有轻微变化 |
| 类别完整性 | 所有适用类别的帖子都正确展示核心信息 | 排除Jobs、Property |
| 适用类别 | Community、Services、Marketplace、Cars、Others等 | 通用类别 |
| 排除类别 | Jobs(招聘)、Property(房产) | 这些类别有不同布局 |

### 3.7 响应式布局规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 桌面端 | 浏览器窗口尺寸1440x900 | 标准桌面分辨率 |
| 元素可见性 | 所有核心信息在桌面端清晰可见 | 无重叠、无溢出 |
| 文字大小 | 文字大小合适,可读性强 | 不同元素有不同字号 |
| 元素排列 | 标题、价格、地点、时间、描述按顺序排列 | 固定布局 |

### 3.8 数据一致性规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 价格一致性 | 列表页价格=详情页价格 | 排除格式差异 |
| 标题一致性 | 列表页标题=详情页标题 | 去除空格后一致 |
| 地点一致性 | 列表页地点包含于详情页地点或相反 | 核心地名一致 |
| 时间一致性 | 列表页与详情页时间基本一致 | 允许±1差异 |
| 跳转验证 | 点击列表页卡片后成功跳转到详情页 | URL包含`/city-XXX/` |
| URL验证 | 详情页URL包含城市标识和帖子ID | 标准URL格式 |

### 3.9 加载与性能规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 页面加载 | 等待详情页加载完成后再验证元素 | 使用合理的超时时间 |
| 元素定位 | 使用精确的选择器定位核心信息元素 | 提高稳定性 |
| 超时设置 | 默认30秒,等待10秒,导航30秒 | 合理的超时配置 |

### 3.10 类别限制规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 适用类别 | Community、Services、Marketplace、Cars、Others | 通用详情页布局 |
| 排除类别 | Jobs(招聘)、Property(房产,包括租房、买房、学生公寓) | 特殊布局 |
| URL过滤 | 排除`href*="/cate-jobs/"`和`href*="/cate-property/"` | 列表页选择时过滤 |
| 选择策略 | 优先选择`href*="/cate-community/"`或`href*="/cate-services/"` | 确保适用类别 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | 核心信息加载失败 | 网络异常或接口错误 | 显示占位符或错误提示 |
| - | 价格格式错误 | 价格不符合规范 | 显示原始价格或"联系询价" |
| - | 标题为空 | 数据异常 | "标题加载失败" |
| - | 地点为空 | 数据异常 | "地点信息不可用" |
| - | 时间为空 | 数据异常 | "发布时间不可用" |
| - | 描述为空 | 数据异常,违反必填规则 | "描述加载失败"或重试 |
