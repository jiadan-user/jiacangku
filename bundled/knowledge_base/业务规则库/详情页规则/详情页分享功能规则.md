# 详情页分享功能规则

## 1. 功能概述
- **业务价值**: 提供便捷的内容分享功能,增加帖子曝光度,促进用户传播和平台增长
- **用户角色**: 
  - 访客: 可使用分享功能
  - 买家/浏览者: 可使用分享功能
  - 功能对所有用户开放,无需登录
- **入口位置**: 
  - 详情页图片下方操作区域
  - 位于"Sell Similar"和"Favourites"按钮右侧
- **依赖模块**: 
  - 剪贴板API(Clipboard API)
  - Toast提示组件
  - 分享追踪服务(可选)

## 2. 核心流程

### 2.1 主流程
1. **用户访问详情页** → 页面加载完成
2. **查看操作区域** → 显示Share按钮(位于Sell Similar和Favourites右侧)
3. **点击Share按钮** → 复制详情页URL到剪贴板
4. **显示Toast提示** → "Link copied"提示显示2-3秒后自动消失
5. **用户粘贴链接** → 可在其他地方(如社交媒体、消息应用)粘贴分享链接

### 2.2 异常流程
- **场景1**: 剪贴板权限被拒绝 → 显示错误提示或回退到其他复制方案
- **场景2**: 浏览器不支持Clipboard API → 回退到`document.execCommand('copy')`方案
- **场景3**: HTTP环境下复制失败 → 回退到降级方案或显示提示
- **场景4**: 网络断开 → 复制功能正常工作(本地操作不依赖网络)

## 3. 业务规则

### 3.1 Share按钮展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 按钮位置 | 位于"Sell Similar"和"Favourites"按钮右侧 | 固定位置,图片下方操作区域 |
| 按钮文案 | "Share" | 英文站显示"Share" |
| 按钮图标 | 包含分享图标 | 标准分享图标 |
| 按钮样式 | 与"Sell Similar"、"Favourites"保持一致 | 统一的按钮风格 |
| 可交互性 | cursor:pointer | 鼠标悬停显示指针样式 |
| 所有类目 | 所有类目详情页都显示Share按钮 | 不区分类目 |
| 权限要求 | 无需登录,访客和登录用户均可使用 | 开放功能 |

### 3.2 链接复制规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 复制内容 | 详情页完整URL | 包含协议、域名、path路径 |
| path路径 | 与原始URL的path路径一致 | 不修改核心路径 |
| query参数 | 可能追加分享追踪参数 | 如utm_source、share_from等 |
| 参数示例 | ?utm_source=share&share_from=detail | 用于统计追踪 |
| URL格式 | 标准URL格式,可在浏览器中打开 | 格式正确 |
| 前后空格 | 复制内容前后无多余空格或特殊字符 | 干净的URL |
| 剪贴板API | 使用`navigator.clipboard.writeText()` | 优先使用现代API |
| 降级方案 | 回退到`document.execCommand('copy')` | 兼容老旧浏览器 |
| 响应时间 | 复制操作在500ms内完成 | 快速响应 |
| 页面行为 | 页面不刷新,不跳转 | 静默复制 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | 剪贴板权限被拒 | 用户拒绝剪贴板访问权限 | "无法复制链接,请允许剪贴板权限" |
| - | 复制失败 | Clipboard API不可用 | "复制失败,请手动复制链接" 或回退到降级方案 |
| - | 浏览器不支持 | 老旧浏览器不支持Clipboard API | "您的浏览器不支持此功能" 或使用降级方案 |
| - | HTTP环境限制 | 在HTTP环境下Clipboard API受限 | 使用降级方案或显示提示 |

## 5. 依赖模块

### 5.1 上游依赖(谁调用我)
- **详情页模块**: 详情页图片下方操作区域展示Share按钮
- **用户浏览行为**: 用户点击Share按钮触发分享功能

### 5.2 下游依赖(我调用谁)
- **剪贴板API**: 
  - `navigator.clipboard.writeText(url)` 复制链接到剪贴板
  - 降级方案: `document.execCommand('copy')` 兼容老旧浏览器
- **Toast提示组件**: 
  - 显示"Link copied"提示
  - 2-3秒后自动消失
- **分享追踪服务(可选)**: 
  - 在URL中追加分享追踪参数
  - 如utm_source、share_from等
  - 用于统计分享效果

### 5.3 跨域交互说明
- **用户业务域**: 无需登录,对所有用户开放
- **统计分析域**: 分享链接可能包含追踪参数,用于统计分析
- **社交分享域**: 用户可将复制的链接分享到社交媒体、消息应用等
