# 详情页Location区域规则

## 1. 功能概述
- **业务价值**: 在详情页集中展示与地点相关的信息,并提供「在地图中查看」的能力,帮助买家确认线下位置或地标,提升交易信任度
- **用户角色**: 
  - 访客: 可查看Location区域,可打开地图查看位置
  - 买家: 可查看Location区域,可打开地图查看位置
  - 权限一致,不区分登录态
- **入口位置**: 详情页Description等详情内容之后,与Description、发布者信息等模块并列
- **依赖模块**: 
  - 地图服务(Google Maps)
  - 地址数据服务
  - 主信息区(地址数据来源)

## 2. 核心流程

### 2.1 Location区域展示流程
1. **用户进入详情页** → 滚动到Description之后区域
2. **Location模块渲染** → 展示标题、地址、Show map区域
3. **用户查看地址** → 确认位置信息

### 2.2 地图查看流程
1. **用户点击Show map按钮** → 打开全屏地图模态
2. **Google Maps渲染** → 显示地理位置
3. **用户查看地图** → 确认详细位置
4. **点击关闭图标** → 关闭地图模态,返回详情页

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | 地址为空 | 后端未返回地址数据 | 不显示Location模块或显示占位文案 |
| - | 地图加载失败 | Google Maps服务不可用 | 显示地图加载失败提示 |
| - | 地址不一致 | 主信息区与Location区地址不一致 | 数据异常,需修复 |
| - | 模态打开失败 | JS错误或组件加载失败 | 降级处理,不阻塞主流程 |

## 5. 依赖模块

### 5.1 上游依赖(谁调用我)
- **详情页模块**: 详情页渲染Location区域
- **地址数据服务**: 提供地址文案数据

### 5.2 下游依赖(我调用谁)
- **Google Maps服务**: 
  - 渲染地图
  - 提供地图交互能力
  - 加载地图资源(maps.gstatic.com)
- **地址数据服务**: 
  - 获取商品地址信息
  - 确保主信息区与Location区地址一致
- **主信息区模块**: 
  - 共享地址数据
  - 保持地址展示一致性

### 5.3 跨域交互说明
- **详情页业务域**: Location区域是详情页的一部分
- **地图服务业务域**: 调用第三方地图服务(Google Maps)
- **地址数据业务域**: 地址数据统一管理

## 6. 已知问题
- **Escape键不关闭模态**: 实测Escape键不会关闭地图模态,若产品期望支持则需修复
- **地图初始化较慢**: Google Maps初始化需2-5秒,可能影响用户体验
- **类目限制不明确**: 当前规则基于非招聘非房产类目实测,其他类目行为待验证
