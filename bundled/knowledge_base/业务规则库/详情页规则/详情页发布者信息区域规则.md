# 详情页发布者信息区域规则

## 1. 功能概述
- **业务价值**: 在详情页展示发布者信息,建立买卖双方信任,提供联系发布者的快捷入口
- **用户角色**: 
  - 买家/浏览者: 查看发布者信息,联系发布者
  - 访客: 查看发布者信息,点击Contact根据联系历史状态进入访客微聊或引导登录
- **入口位置**: 
  - 详情页右侧
  - 发布者信息卡片区域
- **依赖模块**: 
  - 用户信息服务(获取发布者基础信息)
  - 认证服务(判断是否已认证)
  - 聊天服务(Contact跳转到聊天页/访客微聊)
  - 登录服务(特定场景触发登录引导)
  - 发布者主页服务
  - 客户端状态管理(记录「曾联系过此发布者」状态)

## 2. 核心流程

### 2.1 主流程
1. **用户访问详情页** → 页面右侧显示发布者信息卡片
2. **查看发布者信息** → 显示用户名、头像、认证标识、listings数量、sold数量、Contact按钮
3. **点击用户名或头像** → 跳转到发布者主页/店铺页
4. **点击Contact按钮** → 根据用户状态和联系历史执行不同操作：
   - **从未登录（纯访客）**: 进入访客微聊（guest chat）
   - **当前已登录**: 进入已登录用户微聊
   - **曾登录且点击过Contact，退出登录后**: 引导登录（登录弹层/登录页）
   - **曾登录但未点击Contact，退出登录后**: 进入访客微聊（与纯访客行为一致）

### 2.2 异常流程
- **场景1**: 发布者信息加载失败 → 显示默认信息或占位符
- **场景2**: 曾登录且点击过Contact的用户退出登录后点击Contact → 引导登录（与纯访客区分）
- **场景3**: 快速重复点击Contact → 防重处理,仅触发一次跳转
- **场景4**: 发布者主页不存在 → 显示404或错误提示
- **场景5**: 访客微聊服务不可用 → 显示错误提示或降级处理

### 3.7 Contact按钮交互规则(未登录用户与退出登录场景)

**核心业务规则**：系统通过客户端状态（如特定Cookie或localStorage）区分「纯访客」、「曾建立联系后退出的用户」和「仅登录未联系过的用户」

#### 3.7.1 从未登录（纯访客）

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 用户状态 | 从未在本设备/本会话登录过 | Cookie/storage无登录记录 |
| 按钮样式 | 黑色背景,白色文字 | 与已登录用户样式一致 |
| 点击行为 | 跳转到访客微聊页面（guest chat） | 不弹登录窗，直接进入微聊 |
| 会话身份 | 以未登录用户身份发起微聊 | 访客会话 |
| 目标URL | 可能包含 `chat-guest`、`needLogin` 等参数 | 如: /biz/en/chat-guest-server1/?postId=... |
| 页面内容 | 展示微聊相关界面（会话区域、输入框或登录引导等） | 根据产品设计 |

#### 3.7.2 曾登录且点击过Contact，退出登录后

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 用户状态 | 登录期间点击过Contact（已建立联系记录） | 客户端状态记录「曾联系过此发布者」 |
| 前置条件 | 在当前详情页执行退出登录，保留联系状态 | Cookie/localStorage保留联系标记 |
| 按钮样式 | 黑色背景,白色文字 | 样式不变 |
| 点击行为 | **引导登录**（不直接进入微聊） | 与纯访客区分 |
| 引导形式 | 登录弹层/登录页/中间页 | 根据产品实现 |
| URL参数 | 可能包含 `needLogin=true` | 标识需要登录 |
| 登录后行为 | 登录成功后按「已登录」口径进入已登录用户微聊 | 恢复会话身份 |
| 业务目的 | 保护用户历史会话安全，防止未授权访问 | 核心安全逻辑 |

#### 3.7.3 曾登录但未点击Contact，退出登录后

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 用户状态 | 登录期间未点击过Contact（未建立联系记录） | 客户端状态无联系标记 |
| 前置条件 | 在当前详情页执行退出登录 | Cookie/localStorage无联系标记 |
| 按钮样式 | 黑色背景,白色文字 | 样式不变 |
| 点击行为 | 直接进入访客微聊页面 | 与纯访客行为一致 |
| 会话身份 | 以未登录用户身份发起微聊 | 访客会话 |
| 目标URL | 包含 `chat-guest` 关键字 | 如: /biz/en/chat-guest-server1/?postId=... |
| 业务逻辑 | 系统仅在「登录后点击过Contact」时记录联系状态 | 精细化状态管理 |

#### 3.7.4 联系状态记录机制

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 记录时机 | 仅在「已登录 + 点击Contact」时记录 | 精确控制 |
| 存储方式 | 客户端状态（Cookie或localStorage） | 持久化存储 |
| 状态生命周期 | 退出登录后保留，用于判断是否引导登录 | 跨会话保持 |
| 状态清除 | 清除Cookie/localStorage后恢复为纯访客 | 可重置状态 |
| 识别逻辑 | 通过特定标识区分3种访客状态 | 业务判断依据 |

### 3.11 健壮性规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 发布者信息加载失败 | 显示默认信息或占位符 | 不崩溃 |
| 发布者主页不存在 | 显示404或错误提示 | 友好提示 |
| 快速重复点击Contact | 防重处理,仅触发一次 | 避免多次跳转 |
| 聊天服务不可用 | 显示错误提示 | 降级处理 |
| 访客微聊服务不可用 | 显示错误提示或降级到登录引导 | 降级策略 |
| 联系状态识别失败 | 降级为纯访客处理（进入访客微聊） | 保守策略 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| 404 | Not Found | 发布者主页不存在 | "页面不存在" |
| 500 | Internal Server Error | 服务端错误 | "系统错误,请稍后再试" |
| 401 | Unauthorized | 曾建立联系的用户未登录访问 | 引导登录（登录弹层/页面） |
| - | 发布者信息加载失败 | 网络异常或接口错误 | 显示占位符或默认信息 |
| - | 聊天服务不可用 | 聊天服务异常 | "聊天功能暂时不可用" |
| - | 访客微聊服务不可用 | 访客微聊服务异常 | "服务暂时不可用，请稍后再试" |

## 5. 依赖模块

### 5.1 上游依赖(谁调用我)
- **详情页模块**: 详情页右侧展示发布者信息卡片
- **用户浏览行为**: 用户访问详情页时自动展示

### 5.2 下游依赖(我调用谁)
- **用户信息服务**: 
  - `GET /api/user/[publisherId]` 获取发布者基础信息
  - 返回: 用户名、头像、认证状态、listings数量、sold数量
- **认证服务**: 
  - 判断发布者是否已认证(Verified User)
- **聊天服务**: 
  - `GET /biz/en/chat?postId=[postId]&shopId=[shopId]&shopName=[shopName]...` 跳转到聊天页（已登录用户）
  - `GET /biz/en/chat-guest-server1/?postId=[postId]&...` 跳转到访客微聊（纯访客/登录后未联系的退出用户）
- **登录服务**: 
  - 曾登录且点击过Contact的用户退出登录后触发登录引导
- **发布者主页服务**: 
  - `GET /en/profile/[publisherId]/[category]/` 跳转到发布者主页
- **客户端状态管理**: 
  - 通过Cookie/localStorage记录和读取「用户曾联系过此发布者」状态

### 5.3 跨域交互说明
- **用户业务域**: 发布者用户信息、认证状态
- **聊天业务域**: Contact按钮跳转到聊天页面（已登录）或访客微聊（未登录）,建立买卖双方沟通
- **商品业务域**: 发布者主页展示该用户发布的所有商品
- **会话管理域**: 判断用户登录态及联系历史状态，路由到不同微聊入口
- **客户端状态域**: 管理联系历史标记，区分不同访客身份
