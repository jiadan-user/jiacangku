# 详情页发布者信息区域规则

## 1. 功能概述
- **业务价值**: 在详情页展示发布者信息,建立买卖双方信任,提供联系发布者的快捷入口
- **用户角色**: 
  - 买家/浏览者: 查看发布者信息,联系发布者
  - 访客: 查看发布者信息,点击Contact触发登录
- **入口位置**: 
  - 详情页右侧
  - 发布者信息卡片区域
- **依赖模块**: 
  - 用户信息服务(获取发布者基础信息)
  - 认证服务(判断是否已认证)
  - 聊天服务(Contact跳转到聊天页)
  - 登录服务(未登录时触发登录弹窗)
  - 发布者主页服务

## 2. 核心流程

### 2.1 主流程
1. **用户访问详情页** → 页面右侧显示发布者信息卡片
2. **查看发布者信息** → 显示用户名、头像、认证标识、listings数量、sold数量、Contact按钮
3. **点击用户名或头像** → 跳转到发布者主页/店铺页
4. **点击Contact按钮** → 
   - 已登录用户: 跳转到聊天页面
   - 未登录用户: 弹出登录弹窗

### 2.2 异常流程
- **场景1**: 发布者信息加载失败 → 显示默认信息或占位符
- **场景2**: 未登录用户点击Contact → 弹出登录弹窗,不跳转
- **场景3**: 快速重复点击Contact → 防重处理,仅触发一次跳转
- **场景4**: 发布者主页不存在 → 显示404或错误提示

## 3. 业务规则

### 3.1 发布者信息展示规则(已认证用户)

| 用户名 | 显示发布者用户名 | 如: OKerSA_mihwjid |
| 头像 | 显示圆形头像,带OK图标 | 橙色圆形背景 |
| 认证标识 | 显示蓝色盾牌图标+"Verified User"文案 | 仅已认证用户显示 |
| listings数量 | 显示格式:"[数字] listings" | 如: 96 listings,不带千分位 |

| Contact按钮 | 黑色背景,白色文字 | 始终可见 |
| 卡片位置 | 详情页右侧 | 固定位置 |

### 3.2 发布者信息展示规则(未认证用户)

| 用户名 | 显示发布者用户名 | 正常显示 |
| 头像 | 显示圆形头像 | 正常显示 |
| 认证标识 | 不显示"Verified User"标识 | 与已认证用户区分 |
| listings数量 | 显示格式:"[数字] listings" | 正常显示 |

| Contact按钮 | 黑色背景,白色文字 | 正常显示 |

### 3.3 发布者信息展示规则(新用户)

| 规则项 | 规则内容 | 说明 |

| sold数量 | 显示"0 sold"或不显示 | 无销售记录时 |

| 规则项 | 规则内容 | 说明 |

| 可点击 | 用户名可点击 | 鼠标光标变为手型(pointer) |

| 点击行为 | 跳转到发布者主页/店铺页 | 当前标签页跳转 |
| 目标URL | /en/profile/[publisherId]/[category]/ | 如: /en/profile/796370233146021568/services/ |
| 页面标题 | 包含发布者用户名 | 如: Local Services – Home, Repair & Everyday Services \| OKerSA_mihwjid - OK.com |
| 页面内容 | 显示发布者详细信息 | 用户名、徽章、地址、店铺介绍、listings数量、分类Tab、商品列表 |

### 3.5 头像交互规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|

| hover状态 | 出现边框高亮或视觉反馈 | 提示可点击 |
| 点击行为 | 跳转到发布者主页 | 与点击用户名行为一致 |
| 目标URL | /en/profile/[publisherId]/[category]/ | 同用户名跳转 |

### 3.6 Contact按钮交互规则(已登录用户)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 按钮样式 | 黑色背景,白色文字 | 显眼的CTA按钮 |
| hover状态 | 保持黑色背景,可能有微小不透明度调整 | 鼠标光标变为手型 |
| 点击行为 | 跳转到聊天页面(Messages页面) | 当前标签页跳转 |
| 目标URL | /biz/en/chat?postId=[postId]&shopId=[shopId]&shopName=[shopName]... | 包含商品和发布者信息参数 |
| 页面标题 | "Messages" | 聊天页面 |
| 页面内容 | 左侧显示聊天列表,右侧显示当前商品卡片和消息输入框 | 完整聊天界面 |
| 安全提示 | 显示"For your safety, please avoid sharing sensitive personal information such as bank details or passwords." | 保护用户隐私 |
| 消息输入框 | 底部显示"Input message"输入框 | 可立即发送消息 |
| 防重复点击 | 快速连续点击仅触发一次跳转 | 按钮进入loading态或禁用状态 |

| 关闭弹窗 | 点击X按钮或点击蒙层关闭 | 返回详情页 |

### 3.8 数据格式化规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| listings数量格式 | [数字] listings | 不带千分位,如: 96 listings |

| 千分位规则 | 数字大于1000时使用逗号分隔 | 如: 5,558,889 |

### 3.10 会话与状态规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 刷新页面 | 发布者信息卡片完整展示 | 数据重新加载 |
| 后退导航 | 从发布者主页返回详情页,发布者信息正常展示 | 浏览器后退 |

| 从聊天页返回 | 返回详情页,发布者信息正常展示 | 浏览器后退 |

### 3.11 健壮性规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 发布者信息加载失败 | 显示默认信息或占位符 | 不崩溃 |
| 发布者主页不存在 | 显示404或错误提示 | 友好提示 |
| 快速重复点击Contact | 防重处理,仅触发一次 | 避免多次跳转 |
| 聊天服务不可用 | 显示错误提示 | 降级处理 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| 404 | Not Found | 发布者主页不存在 | "页面不存在" |
| 500 | Internal Server Error | 服务端错误 | "系统错误,请稍后再试" |
| 401 | Unauthorized | 未登录访问需登录功能 | 弹出登录弹窗 |
| - | 发布者信息加载失败 | 网络异常或接口错误 | 显示占位符或默认信息 |
| - | 聊天服务不可用 | 聊天服务异常 | "聊天功能暂时不可用" |

## 5. 依赖模块

### 5.1 上游依赖(谁调用我)
- **详情页模块**: 详情页右侧展示发布者信息卡片
- **用户浏览行为**: 用户访问详情页时自动展示

### 5.2 下游依赖(我调用谁)
- **用户信息服务**: 
  - `GET /api/user/[publisherId]` 获取发布者基础信息
  - 返回: 用户名、头像、认证状态、listings数量、sold数量
- **认证服务**: 
  - 判断发布者是否已认证(Verified User)
- **聊天服务**: 
  - `GET /biz/en/chat?postId=[postId]&shopId=[shopId]&shopName=[shopName]...` 跳转到聊天页
- **登录服务**: 
  - 未登录用户点击Contact时触发登录弹窗
- **发布者主页服务**: 
  - `GET /en/profile/[publisherId]/[category]/` 跳转到发布者主页

### 5.3 跨域交互说明
- **用户业务域**: 发布者用户信息、认证状态
- **聊天业务域**: Contact按钮跳转到聊天页面,建立买卖双方沟通
- **商品业务域**: 发布者主页展示该用户发布的所有商品
- **会话管理域**: 判断用户登录态,未登录时触发登录流程
