# 详情页面包屑导航规则

## 1. 功能概述
- **业务价值**: 帮助用户理解当前页面在网站层级结构中的位置,提供快速返回上级页面的能力,增强SEO效果
- **用户角色**: 
  - 访客: 可查看和使用面包屑导航
  - 登录用户: 可查看和使用面包屑导航
  - 功能对所有用户开放,无需登录
- **入口位置**: 详情页顶部,图片上方
- **依赖模块**: 
  - 页面路由系统
  - 类目层级数据
  - 导航跳转服务

## 2. 核心流程

### 2.1 主流程
1. **用户访问详情页** → 页面加载
2. **渲染面包屑导航** → 显示完整层级路径
3. **用户点击面包屑节点** → 跳转到对应页面
4. **快速返回上级** → 用户浏览上级类目或首页

### 2.2 异常流程
- **场景1**: 直接访问详情页URL → 面包屑正常显示
- **场景2**: 浏览器后退后返回 → 面包屑状态保持
- **场景3**: 页面刷新 → 面包屑重新渲染,状态一致
- **场景4**: 无效或已删除的详情页 → 404页面不显示面包屑或仅显示Home链接

## 3. 业务规则

### 3.1 基础展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 位置展示 | 面包屑位于详情页顶部,图片上方 | 距离顶部约96px |
| 水平布局 | 水平居中或靠左对齐 | left约392px,宽度约1136px |
| 容器高度 | 约62px | 单行展示 |
| 必须显示 | 所有详情页都必须显示面包屑导航 | 除404页面外 |
| 可见性 | 面包屑始终可见,不折叠 | 所有设备端 |

### 3.2 层级结构规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 展示顺序 | 首页 > 一级类目 > 二级类目 > ... > 当前页标题 | 按层级从左到右 |
| 最少节点 | 至少3个节点 | Home > 一级类目 > 当前页标题 |
| 节点数量 | 根据类目层级动态确定 | 如Property详情页有5个节点 |
| 路径完整性 | 面包屑路径必须完整反映页面的类目层级 | 不能缺失中间层级 |
| 类目名称 | 节点文本为类目名称或页面标题 | 清晰易懂 |

### 3.3 链接导航规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 可点击节点 | 除最后一个节点外,所有节点均为可点击链接 | 使用`<a>`标签 |
| Home链接 | 第一个节点为"Home",点击跳转到首页 | 如`https://ae.ok.com/en/city-abu-dhabi/` |
| 中间节点链接 | 中间节点点击跳转到对应类目列表页 | 如"Property"跳转到`/cate-property/` |
| 当前页节点 | 最后一个节点为当前页标题,不可点击 | 使用`<span>`标签 |
| 链接属性 | 可点击节点有`href`属性 | 支持右键新标签页打开 |
| cursor样式 | 链接节点cursor为pointer,span节点为默认 | 视觉反馈 |
| 跳转方式 | 默认在当前标签页跳转 | 支持Ctrl/Cmd+点击新标签页打开 |

### 3.4 当前页节点规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 元素类型 | 最后一个节点使用`<span>`元素 | class: `Breadcrumb_breadcrumbSpan__B3vYJ` |
| 不可点击 | 该节点不包含`<a>`链接 | 无href属性 |
| 文本内容 | 节点文本内容为当前页面标题 | 与页面标题一致 |
| cursor样式 | cursor为默认样式,非pointer | 明确不可点击 |
| 点击行为 | 点击该节点无任何反应 | 页面不发生跳转 |

### 3.5 分隔符规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 分隔符类型 | 使用箭头图标">" | class: `Breadcrumb_arrow__CBW9C` |
| 分隔符数量 | 节点数量-1 | 如5个节点有4个箭头 |
| 分隔符位置 | 位于相邻节点之间 | 不在首尾 |
| 图片URL | `https://sgj1.ok.com/yongjia/_next/static/media/icon-breadcrumb-right.65c0f951.png` | 标准箭头图标 |
| 最后节点 | 最后一个节点后无箭头 | 明确结束 |

### 3.6 视觉样式规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 文本颜色 | `rgb(17, 17, 17)` | 接近黑色 |
| 字体大小 | 14px | 标准字号 |
| 文本装饰 | 无下划线 | `text-decoration: none` |
| 悬停效果 | 鼠标悬停时显示视觉反馈 | 颜色变化或下划线 |
| cursor样式 | 链接节点悬停时cursor为pointer | 交互提示 |
| 悬停流畅性 | 悬停效果流畅,无延迟 | 用户体验 |

### 3.7 文本处理规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 单行展示 | 面包屑内容单行展示 | 不换行 |
| 超长文本 | 超出容器宽度时文本末尾显示省略号(...) | 应用`singleLineEllipsis`类名 |
| 文本截断 | 保持单行显示,不换行 | `text-overflow: ellipsis` |
| 完整文本 | 尽量完整显示当前页标题 | 如实测标题完整显示 |

### 3.8 响应式布局规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 移动端显示 | 375px viewport下面包屑仍然显示 | display为block |
| 移动端宽度 | 宽度仍为1136px | 可能需要横向滚动或自适应 |
| 移动端高度 | 约62px | 保持不变 |
| 移动端链接 | 所有链接功能正常 | 支持触摸点击 |
| 平板端显示 | 768px viewport下正常显示 | 布局适配平板屏幕 |
| 桌面端大屏 | 1920px viewport下正常显示 | 布局居中或靠左对齐 |

### 3.9 跨类目一致性规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 所有类目 | 所有类目的详情页均显示面包屑导航 | Property、Jobs、Cars等 |
| 结构一致 | 面包屑结构一致 | `Home > [类目层级] > [当前页标题]` |
| 样式一致 | 样式、布局、交互行为一致 | 统一体验 |
| 单层级类目 | 单层级类目至少显示3个节点 | Home > 一级类目 > 当前页标题 |
| 多层级类目 | 多层级类目完整展示所有层级 | 如Property > For Sale > Apartment |

### 3.10 状态保持规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 页面刷新 | 刷新后面包屑导航正常显示 | 路径与刷新前一致 |
| 浏览器后退 | 后退后面包屑导航正常显示 | 路径正确 |
| 直接访问 | 直接访问详情页URL后面包屑正常显示 | 路径正确反映页面层级 |
| 链接功能 | 刷新、后退后所有链接功能正常 | 可重复使用 |

### 3.11 SEO优化规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 结构化数据 | 面包屑增强页面结构化数据 | 提升搜索引擎友好度 |
| 语义化标签 | 使用语义化HTML标签 | `<nav>`、`<a>`、`<span>` |
| 链接可抓取 | 面包屑链接可被搜索引擎抓取 | 无JavaScript依赖 |

### 3.12 选择器规则(实现层)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 面包屑容器 | class: `Breadcrumb_breadcrumb__nKH2A` | 导航容器 |
| 面包屑项 | class: `Breadcrumb_breadcrumbItem__R0lp7` | 单个节点 |
| 面包屑链接 | class: `Breadcrumb_breadcrumbLink__7juPR` | 可点击链接 |
| 箭头分隔符 | class: `Breadcrumb_arrow__CBW9C` | 箭头图标 |
| 当前页节点 | class: `Breadcrumb_breadcrumbSpan__B3vYJ` | span元素 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | 面包屑加载失败 | 网络异常或接口错误 | 面包屑不显示或显示占位符 |
| - | 类目层级数据缺失 | 数据异常 | 显示简化面包屑(仅Home) |
| 404 | 页面不存在 | 访问无效或已删除的详情页 | 404页面不显示面包屑或仅显示Home链接 |
| - | 链接跳转失败 | 目标页面不存在 | 跳转到404页面 |

## 5. 依赖模块

### 5.1 上游依赖(谁调用我)
- **详情页模块**: 详情页加载时渲染面包屑导航
- **用户浏览行为**: 用户访问详情页触发面包屑显示

### 5.2 下游依赖(我调用谁)
- **页面路由系统**: 
  - 获取当前页面的URL路径
  - 解析页面层级结构
- **类目层级数据服务**: 
  - 获取类目的层级关系
  - 获取类目名称和URL
- **导航跳转服务**: 
  - 处理面包屑节点点击
  - 执行页面跳转

### 5.3 跨域交互说明
- **首页业务域**: Home节点跳转到首页
- **列表页业务域**: 类目节点跳转到对应列表页
- **详情页业务域**: 面包屑在详情页显示
- **SEO业务域**: 面包屑增强页面结构化数据
