# 消息模块 - 群发任务管理规则

## 1. 功能概述
- **功能描述**: 提供群发任务创建、管理、查看功能，支持按状态和时间筛选、搜索任务，查看任务详情和执行状态
- **用户角色**: 
  - 管理员/运营人员：创建、编辑、查看群发任务
  - 普通用户：查看群发任务（权限依实际产品设计）
- **入口位置**: 
  - 入口1：消息管理 → 群发任务
  - 入口2：直链 `https://vidflow.ok.com/#/groupTaskManagement/groupTaskList`
- **依赖模块**: 用户登录模块、消息发送服务

## 2. 核心流程
### 2.1 主流程
1. 用户登录后访问群发任务页面
2. 查看群发任务列表（默认展示所有任务或空状态）
3. （可选）使用搜索框按任务名称/关键词搜索
4. （可选）使用筛选器按状态或时间范围筛选
5. （可选）切换分页或调整每页条数
6. 点击「新建任务」创建新群发任务
7. 填写必填项（任务名称、发送对象、内容等）并提交
8. 查看任务详情或编辑已有任务

### 2.2 异常流程
- 新建任务必填项为空提交 → 提交被阻止，显示必填提示
- 搜索不存在的关键词 → 列表为空或展示无结果文案
- 筛选无匹配结果 → 列表为空或展示空状态
- 取消任务点击取消 → 弹窗关闭，任务仍存在
- 重复点击提交按钮 → 按钮进入 loading/禁用态，仅触发一次提交
- 页面刷新后登录态失效 → 跳转登录页

## 3. 业务规则
### 3.1 列表展示规则
| 功能 | 规则 | 说明 |
|-----|------|------|
| 默认展示 | 有数据时展示任务列表；无数据时展示空状态 | 包含任务名、状态、创建时间等字段 |
| 分页 | 支持切换页码（第2页、下一页等） | 列表内容切换，分页高亮正确 |
| 每页条数 | 支持切换每页条数（如20/50） | 总页数相应变化 |
| 空状态 | 无任务时展示空状态插图/文案 | 引导用户「新建任务」 |

### 3.2 搜索规则
| 功能 | 规则 | 说明 |
|-----|------|------|
| 搜索触发 | 输入关键词后回车或点击搜索按钮 | 列表展示匹配结果 |
| 有结果 | 列表仅展示匹配的任务 | - |
| 无结果 | 列表为空或展示「无结果」文案 | - |
| 搜索范围 | 按任务名称或关键词匹配 | - |

### 3.3 筛选规则
| 筛选器 | 类型 | 规则 | 说明 |
|-------|------|------|------|
| 任务状态 | 单选/多选 | 支持按状态筛选（全部/待执行/执行中/已完成/失败等） | 列表仅展示选中状态的任务 |
| 时间范围 | 日期选择 | 选择开始日期与结束日期 | 列表仅展示时间范围内的任务 |
| 重置筛选 | 按钮 | 清空所有筛选条件 | 恢复默认列表展示 |

### 3.4 新建/编辑规则
| 功能 | 规则 | 说明 |
|-----|------|------|
| 新建入口 | 点击「新建」/「创建任务」按钮 | 打开新建弹窗或跳转表单页 |
| 必填项 | 任务名称、发送对象、内容等必填 | 具体必填项以实际页面为准 |
| 必填校验 | 必填项为空时提交被阻止 | 必填项处显示错误提示文案 |
| 提交成功 | 弹窗关闭，列表新增任务 | 显示成功提示文案 |
| 取消操作 | 点击取消关闭弹窗 | 若有未保存内容，应有二次确认或直接丢弃 |
| 编辑保存 | 修改可编辑字段并保存 | 列表或详情展示更新后内容 |
| 防重复提交 | 快速连续点击提交按钮 | 仅触发一次提交，按钮进入 loading/禁用态 |

### 3.5 任务操作规则
| 操作 | 规则 | 说明 |
|-----|------|------|
| 查看详情 | 点击「查看」/任务名称 | 进入详情页或展开详情区域 |
| 编辑任务 | 点击「编辑」（仅待执行状态） | 打开编辑弹窗，修改后保存 |

### 3.6 权限规则
| 角色 | 权限 | 说明 |
|-----|------|------|
| 未登录 | 无权限访问 | 跳转登录页 |
| 已登录用户 | 查看、创建、编辑自己创建的任务 | 权限范围依实际产品设计 |
| 管理员 | 查看、管理所有任务 | 权限范围依实际产品设计 |

### 3.7 页面状态规则
| 场景 | 规则 | 说明 |
|-----|------|------|
| 页面刷新 | F5 刷新 | 登录态失效则跳转登录页；否则保持在当前页 |
| Tab 切换 | 切到其他页再切回 | 按业务设计保留或刷新列表状态 |
| 任务状态展示 | 状态标签/文案正确 | 与业务定义一致（待执行/执行中/已完成/失败等） |

## 4. 错误处理
### 4.1 错误码定义
| 错误码 | 说明 | 触发条件 |
|-------|------|---------|
| - | 待补充 | 待实际产品文档确认 |

### 4.2 错误提示文案
| 场景 | 提示文案 | 位置 |
|-----|---------|------|
| 必填项为空 | 「请输入XXX」或类似文案 | 必填项下方，待实测确认 |
| 提交成功 | 「创建成功」或类似文案 | Toast 提示，待实测确认 |
| 搜索无结果 | 「无结果」或类似文案 | 列表区域，待实测确认 |

## 5. 依赖模块
### 5.1 上游依赖（谁调用我）
- **消息管理模块**：从消息管理菜单进入群发任务页

### 5.2 下游依赖（我调用谁）
- **用户登录模块**：访问需登录态
- **消息发送服务**：群发任务执行时调用底层消息发送接口

### 5.3 跨域交互说明
- 群发任务模块相对独立，不直接依赖钱包、房产、招聘等其他业务域
- 消息发送服务属于基础设施层，供多个业务域复用

## 6. 已知问题
### 6.1 产品待确认问题
- 测试用例中多数预期结果标注「待实测确认」，需实际探测后补充：
  - 必填项具体有哪些
  - 错误提示文案具体内容
  - 任务状态枚举值与文案
  - 是否支持导出功能
  - 编辑功能的可用条件（是否仅待执行状态可编辑）

### 6.2 技术风险
- 防重复提交机制需验证（前端禁用 + 后端幂等）
- 大量任务时列表性能（分页加载策略）
