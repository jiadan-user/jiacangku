# 消息模块 - AI 聊天功能规则

## 1. 功能概述
- **功能描述**: AI 聊天是平台提供的智能对话功能，用于在商品详情页（房产、二手商品）自动回复买家/租户咨询，提升响应效率和用户体验
- **用户角色**: 
  - 买家/租户（Buyer）：主动发起咨询、提供需求信息、询问商品/房产细节
  - 卖家/房东（Seller）：通过 AI 自动回复买家咨询
  - AI 系统：主动询问用户需求、回答用户问题、引导对话方向
- **入口位置**: 
  - 入口1：房产详情页 → AI 聊天窗口
  - 入口2：二手商品详情页 → AI 聊天窗口
  - 入口3：其他商品类目详情页（未来扩展）
- **依赖模块**: AI Auto Reply 服务、用户登录模块、商品/房产详情模块

## 2. 核心流程
### 2.1 主流程
1. 用户在商品/房产详情页打开 AI 聊天窗口
2. AI 主动发起询问（预算、需求、入住时间等）
3. 用户回答 AI 的询问，建立信任关系
4. 用户提供联系方式（邮箱、电话）
5. 用户主动询问商品/房产信息（位置、价格、配置、成色等）
6. AI 根据商品信息自动回复用户咨询
7. 用户询问交易细节（价格协商、付款方式、配送/看房等）
8. 用户礼貌结束对话或继续深入咨询

### 2.2 异常流程
- 用户提出与商品无关的问题（如宗教信仰）→ AI 礼貌引导回商品话题
- AI 回复超时 → 显示等待提示或超时错误
- 用户提出敏感问题 → AI 识别并过滤，引导至正常对话
- 网络断开 → 消息发送失败，显示错误提示

## 3. 业务规则
### 3.1 AI 主动询问规则
| 业务场景 | AI 询问内容 | 用户预期回复 | 说明 |
|---------|-----------|------------|------|
| **房产租赁** | | | |
| 租期需求 | "租期多久？" | 具体月数或时间段 | 如："12个月，从2026年4月开始" |
| 预算范围 | "预算是多少？" | 具体金额区间 | 如："每周 600-800 AED" |
| 入住时间 | "计划什么时候入住？" | 具体日期或时间范围 | 如："4月中旬，具体日期灵活" |
| **二手商品** | | | |
| 预算范围 | "预算是多少？" | 具体金额区间 | 如："500-800 AED" |
| 用途需求 | "用途是什么？" | 使用场景和面积 | 如："卧室使用，15-20平米" |

### 3.2 联系方式交换规则
| 功能 | 规则 | 说明 |
|-----|------|------|
| 提供顺序 | 优先提供邮箱，然后电话 | 符合用户习惯，降低隐私顾虑 |
| 邮箱格式 | 标准邮箱格式验证 | 如：john.smith@example.com |
| 电话格式 | 带国际区号的手机号 | 如：+61 412 345 678（澳大利亚）、+971 50 123 4567（阿联酋） |
| AI 响应 | AI 确认收到联系方式 | 表示已记录，方便后续联系 |

### 3.3 用户主动咨询规则（房产场景）
| 咨询类型 | 典型问题 | AI 回复依据 | 优先级 |
|---------|---------|-----------|--------|
| 地理位置 | 具体地址、周边设施、交通 | 房产详情页地址字段 | P0 |
| 房屋配置 | 卧室数量、面积、楼层、车位 | 房产详情页配置字段 | P0 |
| 租金价格 | 每周/每月租金 | 房产详情页价格字段 | P0 |
| 看房时间 | 何时可以看房 | 引导用户留下联系方式，由房东联系 | P1 |
| 付款方式 | 押金、付款周期 | 标准租赁条款或引导咨询房东 | P1 |
| 物业管理 | 物业费、维护服务 | 房产详情页或引导咨询房东 | P2 |
| 租赁条款 | 租期、水电、宠物政策 | 引导咨询房东或标准条款 | P2 |

### 3.4 用户主动咨询规则（二手商品场景）
| 咨询类型 | 典型问题 | AI 回复依据 | 优先级 |
|---------|---------|-----------|--------|
| 商品图片 | 更多照片、不同角度 | 商品详情页图片字段 | P0 |
| 物品成色 | 是否有划痕、损坏 | 商品详情页描述字段 | P0 |
| 规格大小 | 尺寸、容量、功率 | 商品详情页规格字段 | P0 |
| 商品数量 | 是否有多件、批发 | 商品详情页库存字段 | P1 |
| 是否可用 | 功能是否正常 | 商品详情页描述字段 | P0 |
| 使用时长 | 已使用多久、新旧程度 | 商品详情页描述字段 | P1 |
| 价格协商 | 砍价、包邮 | 引导用户与卖家私聊协商 | P0 |
| 地理位置 | 卖家位置、自提地点 | 商品详情页地址字段 | P1 |
| 看货方式 | 何时可以看货 | 引导用户留下联系方式，由卖家联系 | P1 |
| 付款方式 | 支付方式、分期 | 平台支付规则或引导咨询卖家 | P1 |
| 邮寄方式 | 快递、自提、安装 | 引导咨询卖家 | P1 |
| 置换交易 | 以物换物 | 引导用户与卖家私聊协商 | P2 |
| 比价 | 与其他商品对比 | 强调本商品优势或引导咨询卖家 | P2 |

### 3.5 AI 回复质量规则
| 规则类型 | 规则内容 | 说明 |
|---------|---------|------|
| 响应时间 | 10-30 秒内完成回复 | 超过 30 秒显示等待提示 |
| 回复准确性 | 基于商品/房产详情页字段回复 | 不编造信息，不确定时引导咨询卖家/房东 |
| 回复完整性 | 回答用户问题的核心要点 | 避免答非所问 |
| 多轮对话能力 | 记住上下文，连贯对话 | 如：用户提到预算后，后续回答考虑预算因素 |
| 引导能力 | 主动引导用户提供需求信息 | 如：主动询问预算、用途、租期 |

### 3.6 敏感问题处理规则
| 问题类型 | 处理方式 | 示例 |
|---------|---------|------|
| 宗教信仰 | 礼貌引导回商品话题 | "抱歉，我们专注于讨论商品信息。关于空调，您还有其他问题吗？" |
| 政治立场 | 礼貌引导回商品话题 | 同上 |
| 人身攻击 | 礼貌提醒，必要时结束对话 | "请保持礼貌交流。关于商品，我可以为您提供帮助。" |
| 违法交易 | 拒绝回答，提示违反平台规则 | "抱歉，该类交易不符合平台规则。" |

### 3.7 对话结束规则
| 结束方式 | AI 响应 | 说明 |
|---------|---------|------|
| 用户主动结束 | 礼貌回应，期待后续联系 | 如："感谢咨询，有问题随时联系！" |
| 长时间无回复 | 无需主动结束，保留对话历史 | 用户可随时继续对话 |
| 敏感问题拒答后 | 引导回正常话题，不强制结束 | 给用户重新开始对话的机会 |

## 4. 错误处理
### 4.1 错误码定义
| 错误码 | 说明 | 触发条件 |
|-------|------|---------|
| - | 待补充 | 待实际产品文档确认 |

### 4.2 错误提示文案

|-----|---------|------|

## 6. 已知问题
### 6.1 产品待确认问题
- AI 聊天是否需要登录才能使用
- 对话历史是否持久化保存
- 用户提供的联系方式是否同步到卖家/房东
- AI 回复超时的具体阈值（当前推断 30 秒）
- 是否支持发送图片、文件等附件
- 是否支持消息撤回、删除功能
- AI 主动询问的具体问题列表（当前基于测试用例推断）
- 敏感问题的过滤规则和关键词列表
- 是否支持多语言 AI 回复

### 6.2 技术风险
- AI Auto Reply 响应时间依赖外部服务，可能存在延迟或失败
- AI 回复准确性依赖商品/房产详情页数据质量
- 多轮对话的上下文管理和状态维护
- 敏感问题识别的准确性（可能误判或漏判）
- 对话历史存储容量和性能

### 6.3 业务风险
- AI 回复不当可能导致用户体验下降或投诉
- 用户提供虚假联系方式，影响后续沟通
- 恶意用户通过 AI 聊天发送垃圾信息或诈骗
- AI 无法处理的复杂问题，需要人工介入
