# 商品发布规则

## 1. 功能概述
- **功能描述**: 二手交易商品发布功能,支持图片/视频上传、分类选择、价格设置、配送选项配置
- **用户角色**: 卖家/发布者
- **入口位置**: 导航栏Post按钮 → Marketplace分类 → 发布表单页
- **依赖模块**: 图片上传服务、分类管理、地图服务

## 2. 核心流程
### 2.1 主流程
1. 用户登录后点击Post按钮
2. 选择二手交易分类(如Electronics → Cell Phones → Apple)
3. 上传商品图片(1-9张)和视频(可选,1个<200MB)
4. 填写商品信息(Title/Description/Price/Location)
5. 选择配送选项(Seller pays/Buyer pays/Arrange pickup)
6. 点击Post按钮提交发布
7. 发布成功,跳转到商品详情页

### 2.2 异常流程
- 场景1: 未登录点击Post → 跳转登录页,登录成功后返回发布页
- 场景2: 图片上传失败 → 显示错误提示,允许重新上传
- 场景3: 必填项未填写 → 提交失败,高亮显示未填写字段
- 场景4: 图片/视频超出限制 → 自动截断或显示错误提示
- 场景5: 网络超时 → Toast提示"提交失败,请稍后重试"

## 3. 业务规则
### 3.1 图片/视频上传规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 图片数量 | 1-9张,必填 | 至少上传1张 |
| 图片格式 | JPG/PNG | 其他格式拒绝 |
| 图片大小 | < 5MB | 单张图片大小限制 |
| 视频数量 | 0-1个,可选 | 最多上传1个视频 |
| 视频格式 | MP4/MOV/AVI | 常见视频格式 |
| 视频大小 | < 200MB | 超过限制提示错误 |
| 主图逻辑 | 第一张图片为主图 | 删除主图后下一张自动成为主图 |
| 图片预览 | 点击图片可查看大图 | 显示缩略图预览 |
| 图片删除 | 点击删除按钮移除图片 | 计数器减1 |
| 计数器显示 | 显示已上传数量/最大数量 | 如"1/9"或"9/9" |
| 上传限制 | 达到9张时禁用上传按钮 | 无法继续上传第10张 |
| 未上传图片提交 | 提示"Please upload a photo before submitting." | 发布被阻止 |

### 3.2 Delivery Options配送选项规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 配送选项类型 | 3种: Seller pays/Buyer pays/Arrange pickup | 单选,必填 |
| Seller pays for postage | 卖家承担邮费 | 买家免运费 |
| Buyer pays for postage | 买家承担邮费 | 卖家不承担运费 |
| Arrange pickup with the buyer | 买家自提 | 线下交易 |
| 未选择配送选项提交 | 提示"Please fill out this field." | 发布被阻止 |
| 配送选项切换 | 每次只能选中一个选项 | 单选行为 |
| 说明文案 | "This category supports online transactions. Choose shipping if needed." | 支持在线交易的分类显示 |
| 分类影响 | 不同分类可能不显示配送选项 | 如Free Stuff分类 |

### 3.3 分类规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 分类路径 | Marketplace → Electronics → Cell Phones → Apple | 多级分类 |
| 分类必填 | 必须选择完整分类路径 | 未选择时无法提交 |
| 分类影响 | 不同分类显示不同字段 | 如Cell Phones显示Condition/Storage |

### 3.4 字段输入规则
| 字段 | 类型 | 必填 | 长度 | 格式 | 默认值 | 说明 |
|------|------|------|------|------|--------|------|
| Title | String | 是 | 1-100 | 纯文本 | - | 商品标题 |
| Description | String | 是 | 1-10000 | 纯文本 | - | 商品描述 |
| Price | Number | 是 | 1-100,000,000 | 正整数 | - | 价格(AED) |
| Location | String | 是 | - | 地址选择 | 默认地址 | 商品位置 |
| Condition | 单选 | 否 | - | New/Used | - | 商品状态 |
| Storage | 单选 | 否 | - | 64GB/128GB/256GB等 | - | 存储容量 |

**Title规则**:
- 必填,不能为空
- 最大长度100字符
- 超出时显示字符计数警告

**Description规则**:
- 必填,不能为空
- 最大长度10,000字符
- 超出时显示字符计数警告

**Price规则**:
- 必填,必须>0
- 不能超过100,000,000 AED
- 拒绝负数输入
- 输入非数字时显示错误提示

**Location规则**:
- 必填,不能为空
- 输入关键词显示搜索建议列表
- 点击搜索建议或按Enter键填充位置信息
- Locate me按钮可自动定位当前位置

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| 1001 | 图片上传失败 | 图片大小超限或格式不支持 | 请上传有效的JPG/PNG图片 |
| 1002 | 未上传图片 | 不上传任何图片尝试提交 | Please upload a photo before submitting. |
| 1003 | 图片超过9张 | 尝试上传第10张图片 | 图片最多9张 |
| 1004 | 视频超过200MB | 上传超过200MB的视频 | 视频文件必须小于200MB |
| 1005 | 视频超过1个 | 尝试上传第2个视频 | 只能上传1个视频 |
| 1006 | 未选择配送选项 | 未选择配送选项尝试提交 | Please fill out this field. |
| 1007 | Title为空 | Title未填写尝试提交 | 请填写商品标题 |
| 1008 | Description为空 | Description未填写尝试提交 | 请填写商品描述 |
| 1009 | Price为0 | Price输入0尝试提交 | 价格必须大于0 |
| 1010 | Price超过最大值 | 输入价格>100,000,000 | 价格不能超过100,000,000 AED |
| 1011 | Location为空 | Location未填写尝试提交 | 请选择商品位置 |
| 1012 | 分类未选择 | 未选择完整分类路径 | 请选择商品分类 |

## 5. 已知问题
- 问题1: 图片上传计数 - 上传1张图片后,计数器可能显示"2/9",系统可能自动生成了缩略图
- 问题2: Location搜索建议选择 - 按Enter键会直接提交表单,而不是选择搜索建议
