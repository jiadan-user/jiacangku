# 首页搜索规则

## 1. 功能概述
- **功能描述**: 首页搜索输入框，支持关键词搜索、Sug词联想、搜索历史记录
- **用户角色**: 所有用户（游客、买家、卖家）
- **入口位置**: 首页顶部搜索区域
- **依赖模块**: Sug词服务、搜索结果页、localStorage

## 2. 核心流程
### 2.1 主流程
1. 用户访问首页
2. 点击搜索输入框
3. 输入关键词（或查看历史记录）
4. 点击Search按钮或按Enter键
5. 跳转到搜索结果页

### 2.2 异常流程
- 场景1: 空内容搜索 → 跳转至全品类页（无keyword参数）
- 场景2: 特殊字符搜索 → URL编码后正常跳转，不执行XSS
- 场景3: 网络超时/断网 → Sug词请求失败，页面不崩溃
- 场景4: Sug接口5xx → 前端降级，不展示sug词但可正常搜索

## 3. 业务规则
### 3.1 输入框规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 底纹词 | "Search for anything" | 未聚焦或无内容时显示 |
| 底纹词颜色 | 浅灰色 | 与正常输入文字明显区分 |
| 聚焦后底纹词 | 有内容时消失，无内容时展示 | - |
| 失焦后底纹词 | 内容为空时重新显示 | - |
| 字符长度限制 | 无限制 | 支持200+字符输入 |
| Clear按钮显示 | 有内容时显示，无内容时隐藏 | class: `CustomInput_searchClear___ZaYy` |
| Clear按钮功能 | 点击后清空输入框，底纹词恢复 | value变为空字符串 |
| 输入框选择器 | `#custom-input` | class: `CustomInput_searchInput__Xf3DF` |

### 3.2 Search按钮规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 按钮文案 | "Search" | 固定文案 |
| 按钮选择器 | `.TopBarMiddleContent_searchButton__3UG6i` | - |
| 按钮状态 | 始终可点击 | 无禁用态 |
| 空内容搜索 | 跳转至全品类页 | URL: `/en/city-dubai/cate/`（无keyword参数）|
| 有内容搜索 | 跳转至搜索结果页 | URL: `/en/city-dubai/cate/?keyword={keyword}` |
| Enter键搜索 | 等同于点击Search按钮 | 跳转至搜索结果页 |
| 快速连续点击 | 不产生重复跳转 | 防抖处理 |

### 3.3 关键词处理规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 空格关键词 | 空格编码为`%20`或`+` | URL编码 |
| 特殊HTML字符 | `<`→`%3C`, `>`→`%3E` | 防XSS，不执行脚本 |
| Emoji字符 | 正确URL编码 | 如`🏠`→`%F0%9F%8F%A0` |
| 超长关键词 | 支持200+字符 | 无截断限制 |
| 仅空格内容 | 跳转至搜索结果页或全品类页 | 不报错 |
| 中文/阿拉伯语 | 正确URL编码 | 支持国际化 |

### 3.4 Sug词规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 触发条件 | 输入内容后约1秒 | 实时联想 |
| 展示位置 | 输入框下方下拉面板 | class: `TopBarMiddleContent_dropdownWrapper__MT_eh` |
| 面板可见状态 | class含`dropdownWrapperShow`时可见 | - |
| Sug词条目选择器 | `.SuggestItem_modalSugItem__iYU6f` | - |
| 最大展示数量 | 10条 | 不超过10条 |
| Sug词来源 | 后端接口返回 | 与输入内容相关 |
| 接口响应格式 | `{"responseCode":200,"responseMsg":"success","data":[]}` | - |
| 无匹配时 | 面板不展示任何条目 | 空列表 |
| 点击Sug词 | 跳转至该关键词搜索结果页 | URL: `?keyword={sug词}` |
| 长文案展示 | 单行截断，省略号 | class含`singleLineEllipsis` |
| 清空输入框 | Sug词面板消失 | 历史面板重新展示（如有历史）|
| 特殊字符输入 | 接口正常响应，不报错 | 如`%`、`?`、`#` |
| 实时更新 | 每次输入变化后sug词列表随之更新 | - |

### 3.5 搜索历史规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 触发条件 | 聚焦输入框且无内容 | 有历史时展示 |
| 展示位置 | 输入框下方下拉面板 | class: `SearchSuggestContent_modalHistoryList__vD8Y_` |
| 历史条目选择器 | `.SearchSuggestContent_modalHistoryItemPC__W7Zwc` | - |
| 标题文案 | "Recent Searches" | class: `SearchSuggestContent_modalHistoryListTitle__s1S_g` |
| 最大展示数量 | 10条 | 超过10条时最旧的被挤出 |
| 排序规则 | 时间倒序 | 最新搜索在第一位 |
| 存储方式 | 浏览器localStorage | 客户端持久化，刷新不丢失 |
| 点击历史词 | 跳转至该关键词搜索结果页 | URL: `?keyword={历史词}` |
| 重复搜索 | 历史不重复，已有词更新到第一位 | 去重逻辑 |
| 首次访问 | 无历史时不展示"Recent Searches"区域 | - |
| 面板切换 | 有输入内容→sug面板；无内容→历史面板 | 两个面板不同时出现 |
| 历史图标 | 每条历史词左侧有历史图标 | class: `historyItemIcon` |

### 3.6 会话与状态规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 刷新页面 | 历史记录保留 | localStorage持久化 |
| 浏览器后退 | 返回首页后输入框清空 | 底纹词正常显示 |

### 3.7 健壮性规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 网络超时/断网 | 页面不崩溃、不白屏 | Sug词请求失败降级 |
| Sug接口5xx | 前端降级，不展示sug词 | 可正常搜索 |
| 快速连续点击 | 防抖处理 | 不产生重复跳转 |

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | 无 | 空内容搜索 | 跳转至全品类页（无错误提示）|
| - | 无 | XSS字符搜索 | URL编码后正常跳转（无错误提示）|
| - | 无 | Sug接口失败 | 降级处理（无错误提示）|
