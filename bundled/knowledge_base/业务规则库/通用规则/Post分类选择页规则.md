# Post分类选择页规则

## 1. 功能概述

### 业务价值
- 作为发布流程的入口页，引导用户选择发布类型
- 提供搜索功能，快速定位目标分类
- 支持6种核心业务类型的发布入口

### 用户角色
- **Seller（卖家）**：发布各类信息

### 入口位置
- 首页 → 点击"Post"按钮 → 进入分类选择页
- URL: `https://aepub.58v5.cn/biz/en/publish/front`

---

## 2. 核心流程

### 主流程
```
1. 用户点击首页"Post"按钮
2. 进入分类选择页（/publish/front）
3. 选择方式A：点击分类卡片（6个分类）
4. 选择方式B：搜索框输入关键词 → 选择建议项
5. 跳转至对应的发布表单页
```

### 异常流程
- **未登录** → 跳转至登录页
- **搜索无结果** → 显示"No results"
- **点击无效区域** → 无响应

---

## 3. 业务规则

### 3.1 页面基础信息

| 规则项 | 说明 |
|--------|------|
| **页面标题** | "Post"（H1标签） |
| **Free标签** | 标题右上角显示黄色"Free"标签 |
| **登录状态** | 右上角显示用户名和头像 |
| **URL** | https://aepub.58v5.cn/biz/en/publish/front |

### 3.2 分类卡片规则

| 规则项 | 说明 |
|--------|------|
| **分类数量** | 6个分类 |
| **分类名称** | Jobs / Property / Marketplace / Services / Community / Cars |
| **布局方式** | 2行3列网格布局 |
| **第一行** | Jobs、Property、Marketplace |
| **第二行** | Services、Community、Cars |
| **卡片内容** | 彩色图标 + 分类名称 |
| **交互行为** | 点击卡片 → 跳转至对应发布表单页 |

### 3.3 搜索框规则

| 规则项 | 说明 |
|--------|------|
| **占位符文本** | "Search for category" |
| **搜索图标** | 左侧显示搜索图标 |
| **获得焦点** | 点击后边框高亮，光标闪烁 |
| **搜索触发** | 输入关键词后实时显示建议列表 |
| **清空行为** | 清空搜索框 → 建议列表消失，分类卡片恢复显示 |

### 3.4 搜索建议列表规则

| 规则项 | 说明 |
|--------|------|
| **列表标题** | "Suggested Categories" |
| **显示时机** | 输入关键词后立即显示 |
| **建议项内容** | 完整的分类路径（面包屑格式，如"Marketplace > Free Stuff"） |
| **建议项数量** | 根据匹配结果动态显示（通常4-6个） |
| **无结果处理** | 显示"No results"提示 |
| **点击行为** | 点击建议项 → 跳转至对应发布表单页 |
| **关闭方式** | 清空搜索框 或 点击建议项 |

### 3.5 搜索关键词匹配规则

| 关键词 | 匹配结果示例 |
|--------|-------------|
| **marketplace** | Marketplace / Free Stuff / Transportation / Home Goods |
| **job** | Jobs / Other / Laboratory & Technical Services / Human Resources & Recruitment |
| **property** | Property 相关子分类 |
| **car** | Cars 相关子分类 |
| **无匹配** | 显示"No results" |

### 3.6 埋点上报规则

| 操作 | 埋点名称 | 说明 |
|------|---------|------|
| 点击搜索框 | post_search_box_click | 搜索框获得焦点时触发 |
| 显示建议列表 | post_search_sug_show | 建议列表出现时触发 |
| 显示建议项 | post_search_sug_item_show | 每个建议项显示时触发 |
| 点击分类卡片 | post_category_card_click | 点击6个分类卡片之一时触发 |
| 点击建议项 | post_search_sug_item_click | 点击建议列表中的某一项时触发 |

## 4. 跳转路径规则

### 4.1 点击分类卡片跳转

| 分类卡片 | 跳转URL模式 |
|---------|------------|
| Jobs | /biz/en/publish/jobs?... |
| Property | /biz/en/publish/property?... |
| Marketplace | /biz/en/publish/classified?traceId=xxx |
| Services | /biz/en/publish/services?... |
| Community | /biz/en/publish/community?... |
| Cars | /biz/en/publish/cars?... |

### 4.2 点击搜索建议项跳转

- 跳转至对应的子分类发布表单页
- URL包含完整的分类路径参数

## 5. 错误处理

### 5.1 错误场景

| 错误场景 | 处理方式 |
|---------|---------|
| 未登录访问 | 重定向至登录页 |
| 搜索无结果 | 显示"No results"提示 |
| 网络异常 | 页面加载失败，显示错误提示 |

### 5.2 边界值处理

| 场景 | 处理方式 |
|------|---------|
| 搜索框输入特殊字符 | 接受输入，按关键词匹配 |
| 搜索框输入空格 | 建议列表消失 |
| 搜索框输入大小写 | 不区分大小写（如"Job"和"job"结果相同） |
