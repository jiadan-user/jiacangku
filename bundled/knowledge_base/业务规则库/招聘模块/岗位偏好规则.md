# 招聘模块 - 岗位偏好设置业务规则

## 1. 功能概述
- **功能描述**: 允许求职者设置求职偏好（职位类型、工作地点、薪资期望、工作方式、工作类型），系统根据偏好推荐匹配职位
- **用户角色**: 求职者（已登录）；游客（需先登录）
- **入口位置**: 
  - 入口1：首页 Jobs 金刚位（已登录首次访问）→ Job Preferences 页面（URL含 `showSkip=1` 参数）
  - 入口2：Jobs 列表页顶部 "Add Job Preference" 卡片（未登录/已登录无偏好）→ Job Preferences 页面（无 `returnUrl` 参数）
  - 入口3：Jobs 列表页顶部 "Edit" 链接（已登录有偏好）→ Job Preferences 页面（URL含 `returnUrl` 参数）
- **依赖模块**: 用户登录模块、招聘列表模块

## 2. 核心流程
### 2.1 主流程
1. 用户通过入口进入 Job Preferences 页面
2. 选择 Job Functions（必填，最多10项，两级级联选择）
   - 点击触发器 "Select preferred job function (0/10)"
   - 在两栏面板中选择（左侧31个一级分类，右侧对应二级分类）
   - 点击二级分类项选中，点击 Confirm 确认
3. 选择 Location（必填，最多5项，checkbox多选）
   - 点击触发器 "Select preferred work location (0/5)"
   - 在城市列表中勾选（各站点城市列表不同）
   - 点击 Confirm 确认
4. 设置 Salary（必填，Pay Type + 金额）
   - 选择 Pay Type（Yearly/Monthly/Hourly，默认 Yearly）
   - 输入金额（正整数，自动千位分隔符格式化）
5. 选择 Workplace Type（可选，Onsite/Remote/Hybrid，多选checkbox）
6. 选择 Job Type（可选，Full-time/Part-time/Contract/Internship/Temporary，多选checkbox）
7. 点击 Continue 提交
8. 提交成功，跳转到 Jobs 列表页，顶部显示已选偏好标签 + Edit 链接

### 2.2 异常流程
- 未登录访问 Add Job Preference → 弹出登录弹窗，登录成功后自动跳转到 Job Preferences 页面
- 必填字段未填写点击 Continue → 显示红色错误提示 "Don't leave this field empty."（Job Functions/Location/Salary 下方）
- Salary 只选 Pay Type 不填金额 → 显示错误提示 "Don't leave this field empty."
- Salary 填写0 → 显示错误提示 "Don't leave this field empty."
- Job Functions 选满10项 → 其他未选项变为禁用状态
- Location 选满5项 → 其他未选项变为禁用状态
- 点击 Skip（仅首次创建时显示）→ 跳过偏好设置，直接进入列表页
- 点击 Back → 返回上一页（首页或列表页，根据 returnUrl 参数决定）
- 点击面板 Clear → 清空面板内选中状态（面板保持打开，需点击 Confirm 才生效）

## 3. 业务规则
### 3.1 输入规则
| 字段 | 类型 | 必填 | 长度/范围 | 格式 | 默认值 | 说明 |
|-----|------|-----|---------|------|--------|------|
| Job Functions | 多选（级联） | 是 | 最多10项 | 两级选择 | - | 31个一级分类，每个一级下有多个二级；必须点击二级项才算选中 |
| Location | 多选（checkbox） | 是 | 最多5项 | 城市列表 | - | 各站点城市列表不同（ES:20省+城市，AE:9城市，SG:1城市） |
| Salary - Pay Type | 单选 | 是 | - | Yearly/Monthly/Hourly | Yearly | 薪资周期，默认选中 Yearly |
| Salary - 金额 | 数字 | 是 | >0 | 正整数 | - | 输入后自动格式化千位分隔符（5000→5,000），不接受0值 |
| Workplace Type | 多选（checkbox） | 否 | - | Onsite/Remote/Hybrid | - | 工作方式，可选多个 |
| Job Type | 多选（checkbox） | 否 | - | Full-time/Part-time/Contract/Internship/Temporary | - | 工作类型，可选多个 |

### 3.2 校验规则
- **Job Functions 必填校验**：
  - 未选择时点击 Continue → 显示 "Don't leave this field empty."（红色文案，字段下方）
  - 已选择后可正常提交
  - 选满10项后，其他未选项变为禁用状态（不可再选）
  
- **Location 必填校验**：
  - 未选择时点击 Continue → 显示 "Don't leave this field empty."（红色文案，字段下方）
  - 已选择后可正常提交
  - 选满5项后，其他未选项变为禁用状态（不可再选）

- **Salary 必填校验**：
  - 只选 Pay Type 不填金额 → 显示 "Don't leave this field empty."
  - 填写0 → 显示 "Don't leave this field empty."
  - 填写负数 → 输入框自动拦截（无法输入负号）
  - 填写字母 → 输入框自动拦截（无法输入字母）
  - 填写小数 → 接受小数输入
  - 填写正整数 → 校验通过，自动格式化千位分隔符

- **数量限制校验**：
  - Job Functions：最多10项，选满后其他项禁用
  - Location：最多5项，选满后其他项禁用

- **空表单校验**：
  - 三个必填字段均为空时点击 Continue → 同时显示三条错误提示

### 3.3 权限规则
- **未登录用户**：
  - 点击 "Add Job Preference" → 弹出登录弹窗（dialog，不跳转页面）
  - 登录成功后自动跳转到 Job Preferences 页面
  - 登录弹窗包含：邮箱/手机号输入 → Continue → 密码输入 → Log in
  - 登录弹窗包含第三方登录（Google/Facebook/Apple）
  - 可点击 × 关闭弹窗
  
- **已登录用户**：
  - 无偏好：
    - 首页 Jobs 金刚位 → 跳转到 Job Preferences 页面（URL含 `showSkip=1`，显示 Skip 链接）
    - 列表页显示 "Add Job Preference" 卡片（点击直接跳转，无弹窗）
  - 有偏好：
    - 首页 Jobs 金刚位 → 直接跳转到列表页（不经过偏好页）
    - 列表页顶部显示偏好标签（如 "Developers/Programmers"）+ "Edit" 链接
    - 点击 Edit → 跳转到 Job Preferences 页面（URL含 `returnUrl`，数据自动回填）

### 3.4 业务约束
- Job Functions 最多选择10项（选满后其他项禁用）
- Location 最多选择5项（选满后其他项禁用）
- Salary 金额必须大于0（0值和负数不接受）
- 提交后偏好数据持久化，刷新页面后仍保留
- 编辑模式下，原有数据自动回填（Job Functions、Location、Salary、Workplace Type、Job Type）
- 偏好标签在列表页顶部持久显示（直到用户修改或清除）

### 3.5 交互规则
- **Job Functions 选择交互**：
  - 点击触发器打开两栏面板（左侧一级分类，右侧二级分类）
  - 点击左侧一级分类，右侧显示对应二级分类
  - 必须点击右侧二级分类项才算选中（点击一级分类不算选中）
  - 已选项在触发器区域显示为 tag（带 × 删除按钮）
  - 点击 tag 的 × 可删除该项
  - 点击面板内的 Clear 清空所有选中（面板保持打开）
  - 点击 Confirm 确认选择并关闭面板

- **Location 选择交互**：
  - 点击触发器打开城市列表面板
  - 使用 checkbox 多选城市
  - 已选项在触发器区域显示为 tag（带 × 删除按钮）
  - 点击 tag 的 × 可删除该项
  - 点击面板内的 Clear 清空所有选中（面板保持打开）
  - 点击 Confirm 确认选择并关闭面板
  - ES站特有：面板顶部有 "Search City" 搜索框，支持搜索城市
  - ES站特有：面板顶部有 "Use current location" 按钮，使用地理位置

- **Salary 输入交互**：
  - Pay Type 为按钮组单选（Yearly/Monthly/Hourly）
  - 金额输入框为 `type="text"`，自动拦截字母和负号
  - 输入数字后自动格式化千位分隔符（5000 → 5,000）
  - 接受小数输入

- **Continue 按钮交互**：
  - 三个必填字段均已填写 → 按钮可点击（蓝色）
  - 任一必填字段未填写 → 点击后显示对应错误提示（不提交）

- **Skip 链接交互**（仅首次创建时显示）：
  - 点击 Skip → 跳过偏好设置，直接跳转到 Jobs 列表页
  - URL 跳转到 returnUrl 参数指定的地址

- **Back 按钮交互**：
  - 有 returnUrl 参数 → 跳转到 returnUrl 指定地址
  - 无 returnUrl 参数 → 跳转到首页或列表页

### 3.6 站点特殊规则

#### ES站（西班牙站）
- **货币单位**：€ (EUR)
- **偏好页URL**：https://espub.58v5.cn/biz/en/jobPreference
- **Location 结构**：两级级联（省份 → 城市）
  - 第一级：20个省份（All Spain、Andalusia、Aragon、Asturias、Balearic Islands、Basque Country、Canary Islands、Cantabria、Castille and Leon、Castille-La Mancha、Catalonia、Ceuta、Extremadura、Galicia、La Rioja、Madrid、Melilla、Murcia、Navarre、Valencia）
  - 第二级：点击省份后展开该省城市列表
  - 面板顶部有 "Search City" 搜索框
  - 面板顶部有 "Use current location" 按钮
- **默认城市**：Madrid（列表页地址筛选器默认值）

#### AE站（阿联酋站）
- **货币单位**：AED
- **偏好页URL**：https://aepub.58v5.cn/biz/en/jobPreference
- **Location 结构**：单级城市列表（checkbox）
  - 城市列表：All United Arab Emirates、Dubai、Abu Dhabi、Ras al Khaimah、Sharjah、Fujairah、Ajman、Umm al Quwain、Al Ain（共9个）
- **默认城市**：无（列表页地址筛选器显示 "Location"）

#### SG站（新加坡站）
- **货币单位**：S$ (SGD)
- **偏好页URL**：https://sgpub.58v5.cn/biz/en/jobPreference
- **Location 结构**：单级城市列表（checkbox）
  - 城市列表：仅 Singapore 一个城市
- **默认城市**：Singapore
- **特殊行为**：已登录用户点击首页 Jobs 金刚位 → 跳转到偏好页（而非直接进入列表页）
