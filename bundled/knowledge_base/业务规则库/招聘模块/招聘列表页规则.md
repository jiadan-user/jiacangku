# 招聘模块 - 招聘列表页业务规则

## 1. 功能概述
- **功能描述**: 提供职位列表浏览、搜索、筛选功能，支持查看职位详情、收藏、分享、快速回复等操作
- **用户角色**: 求职者（已登录/未登录）；发布者（查看和管理自己发布的职位）
- **入口位置**: 
  - 入口1：首页 Jobs 金刚位
  - 入口2：导航栏 Jobs 链接
  - 入口3：Job Preferences 提交后自动跳转
  - 入口4：搜索中间页（搜索后进入独立搜索结果页）
- **依赖模块**: 用户登录模块、岗位偏好模块、职位详情模块、搜索模块

## 2. 核心流程
### 2.1 主流程
1. 用户访问 Jobs 列表页（URL: `/en/city-xxx/cate-jobs/?iconSource=jobs`）
2. （可选）输入搜索关键词并搜索
   - 输入关键词 → 点击 Search 按钮 → 跳转到搜索中间页（URL含 `keyword=xxx`）
   - 或聚焦搜索框 → 显示 Recent Searches 历史记录 → 点击历史记录触发搜索
3. （可选）使用筛选器筛选
   - Location：选择城市（URL路径变化）
   - Job Type：多选工作类型（URL含 `attr_60=1,2,3`）
   - Workplace Type：多选工作方式
   - Salary：设置薪资范围（URL含 `lowestPrice`、`highestPrice`）
4. 浏览职位列表（无限滚动加载）
   - 滚动到底部自动加载更多职位
   - 加载完毕显示 "You've reached the end"
5. 点击职位卡片查看详情面板
   - 右侧详情面板展开，显示职位完整信息
6. 在详情面板进行操作
   - Contact：联系招聘方
   - Favourites：收藏职位
   - Share：分享职位
   - New tab：在新标签页打开
   - Resume：创建/编辑简历
   - Withdraw/Edit：管理自己发布的职位（仅本人帖）

### 2.2 异常流程
- 搜索无结果 → 显示空状态提示 "No results found"
- 筛选无结果 → 显示空状态提示
- 网络超时 → 显示加载失败提示
- 未登录点击 Favourites → 弹出登录弹窗
- 未登录点击 Resume → 弹出登录弹窗
- 未登录点击 Contact → 弹出登录弹窗
- Salary Min > Max → 显示错误提示 "Max price must be higher than min price"
- 点击 Reset → 清除所有筛选参数（保留搜索词 `keyword`），URL恢复为 `?iconSource=jobs`

## 3. 业务规则
### 3.1 搜索规则
| 功能 | 规则 | 说明 |
|-----|------|------|
| 搜索触发 | 输入关键词点击 Search 按钮 | URL 追加 `?keyword=xxx`，跳转到搜索中间页 |
| 空搜索 | 允许空搜索 | URL 包含 `keyword=`（空值），跳转到搜索中间页 |
| 搜索历史 | 聚焦搜索框显示 Recent Searches | 最多7条历史记录，标题 "Recent Searches"，含清空按钮 |
| 历史记录点击 | 点击历史记录触发对应关键词搜索 | 跳转到搜索中间页 |
| 搜索中间页 | 搜索后进入独立搜索结果页 | 页面结构变化（无详情面板、无Reset、无偏好标签栏） |
| 防抖处理 | 输入框有防抖 | 建议使用 `press_sequentially()` 逐字输入 |
| 特殊字符 | 支持特殊字符搜索 | 如 @#$%^&*()、中文、超长文本 |

### 3.2 筛选规则
| 筛选器 | 类型 | 规则 | URL参数 | 显示文案 |
|-------|------|------|---------|---------|
| Location | 单选 | 选择城市后 URL 路径变化 | `/en/city-xxx/cate-jobs/` | 显示城市名（如 "Madrid"） |
| Location - All | 单选 | 选择 "All Spain/UAE" | `/en/city/cate-jobs/` | 显示 "Location"（恢复默认） |
| Job Type | 多选 | 可选多个，显示 "Job Type · N" | `attr_60=1,2,3`（逗号分隔） | "Job Type · N"（N为选中数量） |
| Workplace Type | 多选 | 可选多个，显示 "Workplace type · N" | 对应参数 | "Workplace type · N" |
| Salary | 范围 | Min/Max 输入框 | `lowestPrice`、`highestPrice` | "Salary · 2"（同时填写Min+Max） |
| Salary - Pay Type | 单选 | Per Hour/Per Month/Per Year | Per Month: `attr_80=4`；Per Hour: 无参数 | - |
| Reset | 清除 | 清除所有筛选（保留搜索词） | URL 恢复为 `?iconSource=jobs` | 筛选无效时不显示/置灰 |

### 3.3 列表加载规则
- **加载方式**: 无限滚动（feed流），无分页按钮（无 Previous/Next/页码）
- **触发条件**: 滚动到列表底部自动加载更多职位
- **加载状态**: 加载过程中显示 loading 状态
- **加载完毕**: 显示 "You've reached the end" 或空白
- **URL行为**: 滚动加载时 URL 始终不变

### 3.4 职位卡片规则
- **卡片内容**：
  - 职位标题（可点击）
  - 薪资范围（如 "€5,000/year"）
  - Job Type 标签（如 "Full-time"）
  - Workplace 标签（如 "Remote"）
  - 城市标签（如 "Madrid"）
  - 公司 Logo
  - 招聘者姓名和职位
  - Quick Reply 文案标签（展示性，点击等同于点击整张卡片）
  - 高亮技能标签（如 ok1 · ok2 · ok3，匹配用户技能）

- **点击行为**：
  - 点击卡片 → 右侧详情面板切换到该职位详情（不跳转页面，URL不变）
  - 点击 Quick Reply → 等同于点击整张卡片

- **Add Job Preference 卡片**（特殊卡片）：
  - 位置：列表顶部第一个位置
  - 显示条件：未登录 或 已登录无偏好
  - 内容：图标 + "Add Job Preference" 标题 + "Unlock more opportunities tailored for you." 副文本
  - 点击行为：未登录弹出登录弹窗；已登录跳转到偏好页

### 3.5 搜索中间页规则
- **页面结构变化**：
  - 无右侧详情面板（职位卡片点击后在新标签页打开）
  - 无 Reset 按钮
  - 无偏好标签栏（无 Edit 链接）
  - 无清空搜索词按钮（× 号）
  - 筛选栏新增：Best Match、Filter·N、Jobs、Unit
  - 搜索框右侧显示当前搜索词 chip（可点击但只触发重新搜索，非清空）

- **Filter·N 计数规则**：
  - N 反映所有已激活维度（含 keyword 本身计1）
  - 例如：keyword + Job Type（2个） + Salary → Filter·4

- **职位卡片点击**：
  - 卡片为 `<a>` link 元素
  - 点击后在新标签页打开职位详情页

- **修改搜索词**：
  - 需手动编辑搜索框内容，重新点击 Search 按钮
  - 无清空按钮（× 号）

### 3.6 偏好标签栏规则（已有偏好时显示）
- **显示位置**：列表页顶部，搜索栏下方
- **显示内容**：横向滚动标签（显示已选的 Job Functions）+ "Edit" 链接
- **标签数量**：显示所有已选的 Job Functions（可横向滚动查看）
- **Edit 链接**：点击跳转到 Job Preferences 编辑页（URL含 `returnUrl`）
- **隐藏条件**：进入搜索中间页后不显示

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|-------|---------|---------|---------|
| - | Max price must be higher than min price | Salary Min > Max | Max price must be higher than min price（红色文案，Salary 下方） |
| - | No results found | 搜索/筛选无结果 | 显示空状态页面 |
| - | 加载失败 | 网络超时 | 显示加载失败提示 |
