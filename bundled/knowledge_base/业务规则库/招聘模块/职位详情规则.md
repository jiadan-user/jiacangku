# 招聘模块 - 职位详情业务规则

## 1. 功能概述
- **功能描述**: 展示职位完整信息，支持联系招聘方、收藏、分享、在新标签页打开、管理自己发布的职位等操作
- **用户角色**: 求职者（已登录/未登录）；发布者（查看和管理自己发布的职位）
- **入口位置**: 
  - Jobs 列表页 → 点击职位卡片 → 右侧详情面板展开
  - 搜索中间页 → 点击职位卡片 → 在新标签页打开职位详情页
- **依赖模块**: 用户登录模块、招聘列表模块、简历模块

## 2. 核心流程
### 2.1 主流程
1. 用户在列表页点击职位卡片
2. 右侧详情面板展开，显示职位完整信息：
   - 职位标题
   - 薪资范围（如 "€5,000 - €10,000/month"）
   - Job Type 标签（如 "Full-time"）
   - Workplace 标签（如 "Remote"）
   - 城市标签（如 "Madrid"）
   - 公司 Logo
   - 招聘者姓名和职位
   - 职位描述（Description）
   - 职位要求（Requirements）
   - 技能标签（Skills）
   - 发布时间（如 "Posted 2 days ago"）
3. 用户在详情面板进行操作：
   - **Contact**：联系招聘方（未登录需先登录）
   - **Favourites**：收藏职位（未登录需先登录）
   - **Share**：分享职位（弹出分享面板）
   - **New tab**：在新标签页打开职位详情页
   - **Resume**：创建/编辑简历（未登录需先登录）
   - **Withdraw/Edit**：管理自己发布的职位（仅本人帖）

### 2.2 异常流程
- 未登录点击 Contact → 弹出登录弹窗
- 未登录点击 Favourites → 弹出登录弹窗
- 未登录点击 Resume → 弹出登录弹窗
- 点击 Share → 弹出分享面板（包含复制链接、分享到社交媒体等选项）
- 点击 × 关闭详情面板 → 面板关闭，返回列表页
- 点击面板外部区域 → 面板关闭，返回列表页

## 3. 业务规则
### 3.1 详情面板展示规则
| 区域 | 内容 | 说明 |
|-----|------|------|
| 顶部操作栏 | × 关闭按钮 | 点击关闭详情面板 |
| 职位标题 | 职位名称 | 如 "Software Engineer" |
| 薪资范围 | 薪资区间 + 周期 | 如 "€5,000 - €10,000/month" |
| 标签组 | Job Type、Workplace、Location | 如 "Full-time · Remote · Madrid" |
| 公司信息 | Logo + 招聘者姓名 + 职位 | 如 "John Doe · HR Manager" |
| 发布时间 | 相对时间 | 如 "Posted 2 days ago" |
| Description | 职位描述 | 富文本内容 |
| Requirements | 职位要求 | 富文本内容 |
| Skills | 技能标签 | 如 "JavaScript · React · Node.js" |
| 操作按钮组 | Contact、Favourites、Share、New tab、Resume | 底部固定操作栏 |
| 本人帖特殊操作 | Withdraw、Edit | 仅本人发布的职位显示 |

### 3.2 操作按钮规则
| 按钮 | 功能 | 权限 | 行为 |
|-----|------|------|------|
| Contact | 联系招聘方 | 需登录 | 未登录弹出登录弹窗；已登录跳转到聊天页面 |
| Favourites | 收藏职位 | 需登录 | 未登录弹出登录弹窗；已登录切换收藏状态（图标变化） |
| Share | 分享职位 | 无限制 | 弹出分享面板（复制链接、社交媒体分享） |
| New tab | 在新标签页打开 | 无限制 | 在新标签页打开职位详情页（独立URL） |
| Resume | 创建/编辑简历 | 需登录 | 未登录弹出登录弹窗；已登录跳转到简历页 |
| Withdraw | 撤回职位 | 仅本人帖 | 弹出确认对话框，确认后撤回职位 |
| Edit | 编辑职位 | 仅本人帖 | 跳转到职位编辑页 |

### 3.3 权限规则
- **未登录用户**：
  - 可查看职位详情（无限制）
  - 点击 Contact → 弹出登录弹窗
  - 点击 Favourites → 弹出登录弹窗
  - 点击 Resume → 弹出登录弹窗
  - 点击 Share → 直接弹出分享面板（无需登录）
  - 点击 New tab → 直接在新标签页打开（无需登录）
  
- **已登录用户**：
  - 可查看职位详情（无限制）
  - 可联系招聘方（Contact）
  - 可收藏职位（Favourites）
  - 可分享职位（Share）
  - 可在新标签页打开（New tab）
  - 可创建/编辑简历（Resume）
  
- **本人发布的职位**：
  - 显示 Withdraw 和 Edit 按钮（替代 Contact 按钮）
  - 可撤回职位（Withdraw）
  - 可编辑职位（Edit）

### 3.4 业务约束
- 详情面板宽度：固定宽度（约占页面1/2）
- 详情面板高度：自适应内容高度，支持滚动
- 详情面板位置：右侧固定位置
- 详情面板切换：点击不同职位卡片，面板内容切换（不关闭面板）
- 详情面板关闭：点击 × 或面板外部区域，面板关闭
- URL 行为：详情面板展开/切换时，URL 不变（不跳转页面）

### 3.5 收藏功能规则
- **收藏状态**：
  - 未收藏：Favourites 按钮为空心图标
  - 已收藏：Favourites 按钮为实心图标（颜色变化）
  
- **收藏操作**：
  - 点击 Favourites 按钮 → 切换收藏状态
  - 收藏成功：图标变为实心，显示 toast 提示 "Added to favourites"
  - 取消收藏：图标变为空心，显示 toast 提示 "Removed from favourites"
  
- **收藏列表**：
  - 用户可在个人中心查看所有收藏的职位
  - 收藏数据持久化到数据库

### 3.6 分享功能规则
- **分享面板**：
  - 点击 Share 按钮 → 弹出分享面板（底部弹出或居中弹出）
  - 分享面板包含：
    - 复制链接按钮（Copy Link）
    - 社交媒体分享按钮（Facebook、Twitter、LinkedIn、WhatsApp等）
  
- **复制链接**：
  - 点击 Copy Link → 复制职位详情页 URL 到剪贴板
  - 显示 toast 提示 "Link copied"
  
- **社交媒体分享**：
  - 点击社交媒体按钮 → 打开对应分享窗口
  - 分享内容包含：职位标题、薪资范围、职位链接

### 3.7 站点特殊规则

#### ES站（西班牙站）
- **货币单位**：€ (EUR)
- **详情页URL格式**：`https://espub.58v5.cn/biz/en/city-xxx/cate-jobs/post-xxx/`
- **薪资显示格式**：€5,000 - €10,000/month

#### AE站（阿联酋站）
- **货币单位**：AED
- **详情页URL格式**：`https://aepub.58v5.cn/biz/en/city-xxx/cate-jobs/post-xxx/`
- **薪资显示格式**：AED 5,000 - AED 10,000/month

#### SG站（新加坡站）
- **货币单位**：S$ (SGD)
- **详情页URL格式**：`https://sgpub.58v5.cn/biz/en/city-xxx/cate-jobs/post-xxx/`
- **薪资显示格式**：S$5,000 - S$10,000/month

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|-------|---------|---------|---------|
| - | 需要登录 | 未登录点击 Contact/Favourites/Resume | 弹出登录弹窗 |
| - | 职位已下架 | 访问已撤回的职位 | 显示 "This job is no longer available" |
| - | 加载失败 | 网络超时 | 显示加载失败提示 |
