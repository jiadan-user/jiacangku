# 招聘模块 - 简历管理业务规则

## 1. 功能概述
- **功能描述**: 求职者创建和编辑个人简历，包括个人信息、工作经验、教育背景，支持头像上传和数据持久化
- **用户角色**: 求职者（已登录）；游客（需先登录）
- **入口位置**: 
  - Jobs 列表页 → 职位详情面板底部 "Resume" 按钮
  - 首次访问：跳转到 `resume/add` 页面（两步式创建流程）
  - 已有简历：跳转到 `resume` 页面（简历详情展示页，可点击 Edit 编辑）
- **依赖模块**: 用户登录模块、图片上传模块

## 2. 核心流程
### 2.1 主流程（首次创建）
1. 用户点击 Resume 按钮进入 resume/add 页面
2. **Step 1 - Personal Information**：
   - 选择头像（10个预设头像 或 上传自定义头像）
   - 填写 First Name（必填，1-100字符，显示字符计数 X/100）
   - 填写 Last Name（必填，1-100字符，显示字符计数 X/100）
   - Email 自动预填（登录邮箱，不可编辑）
   - Current Location 自动预填（可修改，下拉选择国家）
   - 选择 Gender（可选，下拉选择 Male/Female/Other）
   - 点击 Continue 进入 Step 2（按钮仅在 First Name + Last Name 都填写后可点击）
3. **Step 2 - Recent Experience**：
   - **Latest Work Experience**：
     - 选择 Job Function（必填*，两级级联下拉）
     - 选择 From 日期（必填*，年月滚动选择器，1925-2036）
     - 选择 To 日期（默认 "Present"，可取消勾选 "I currently work here" 后选择）
     - 或开启 "I have no work experience" 开关（隐藏工作经验字段）
   - **Education Experience**：
     - 选择 Education Level（必填，单级下拉）
     - 选择 From 日期（必填，年月滚动选择器）
     - 选择 To 日期（必填，年月滚动选择器）
   - 点击 Done 提交（按钮仅在所有必填项填写后可点击）
4. 提交成功，跳转离开 resume/add 页面

### 2.2 异常流程
- 未登录点击 Resume → 弹出登录弹窗，登录成功后跳转到简历页
- Step 1 必填字段未填写 → Continue 按钮禁用（灰色不可点击）
- Step 2 必填字段未填写 → Done 按钮禁用（灰色不可点击）
- 上传头像超过大小限制 → 显示错误提示
- 上传头像格式不支持 → 显示错误提示
- 点击 Back（Step 1）→ 返回上一页（列表页）
- 点击 Back（Step 2）→ 返回 Step 1
- 有未保存变更点击 Back/Done → 弹出 "Unsaved Changes" 确认对话框

## 3. 业务规则
### 3.1 输入规则（Step 1 - Personal Information）
| 字段 | 类型 | 必填 | 长度 | 格式 | 默认值 | 说明 |
|-----|------|-----|------|------|--------|------|
| 头像 | 图片 | 否 | <10MB | JPG/PNG | 默认头像 | 10个预设头像 + 上传自定义头像 |
| First Name | String | 是 | 1-100 | 纯文本 | - | 字符计数显示 X/100 |
| Last Name | String | 是 | 1-100 | 纯文本 | - | 字符计数显示 X/100 |
| Email | String | 是 | - | 邮箱格式 | 登录邮箱 | 预填，不可编辑，灰色背景 |
| Current Location | Enum | 是 | - | 国家列表 | Spain/UAE/Singapore | 预填，可修改，下拉选择 |
| Gender | Enum | 否 | - | Male/Female/Other | - | 下拉选择，可选 |

### 3.2 输入规则（Step 2 - Recent Experience）
| 字段 | 类型 | 必填 | 长度/范围 | 格式 | 默认值 | 说明 |
|-----|------|-----|---------|------|--------|------|
| Job Function | Enum | 是* | - | 两级级联 | - | *除非开启"I have no work experience" |
| Work From | Date | 是* | 1925-2036 | YYYY-MM | - | 年月滚动选择器，两列（年份+月份） |
| Work To | Date | 是* | 1925-2036 | YYYY-MM | Present | 默认勾选"I currently work here"，显示 "Present" |
| I currently work here | Boolean | 否 | - | 复选框 | 已勾选 | 勾选时 To 显示 "Present"（不可编辑） |
| I have no work experience | Boolean | 否 | - | 开关 | 关闭 | 开启时隐藏工作经验所有字段 |
| Education Level | Enum | 是 | - | 单级下拉 | - | 学历等级（如 Bachelor's Degree、Master's Degree等） |
| Education From | Date | 是 | 1925-2036 | YYYY-MM | - | 年月滚动选择器 |
| Education To | Date | 是 | 1925-2036 | YYYY-MM | - | 年月滚动选择器 |

### 3.3 校验规则
- **Continue 按钮激活条件**（Step 1）：
  - First Name 已填写 AND Last Name 已填写
  - 否则按钮禁用（灰色不可点击）
  - 字符计数实时更新（X/100）

- **Done 按钮激活条件**（Step 2）：
  - **场景1（有工作经验）**：
    - Job Function 已选择
    - Work From 已选择
    - Work To 已选择 OR "I currently work here" 已勾选（显示 Present）
    - Education Level 已选择
    - Education From 已选择
    - Education To 已选择
  - **场景2（无工作经验）**：
    - "I have no work experience" 开关已开启
    - Education Level 已选择
    - Education From 已选择
    - Education To 已选择
  - 否则按钮禁用（灰色不可点击）

- **日期选择器规则**：
  - 年份范围：1925 - 2036（当前年份+10年）
  - 月份范围：1 - 12（January - December）
  - 两列滚动选择器（左列年份，右列月份）
  - 滚动选择年份和月份后，点击 Done 确认
  - 取消选择：点击面板外部或 × 关闭

- **"I currently work here" 复选框规则**：
  - 默认状态：已勾选（`img[alt="checked"]` 可见）
  - 勾选时：Work To 字段显示 "Present"（灰色文本，不可编辑）
  - 取消勾选：Work To 字段变为可编辑，显示 "YYYY-MM" 占位符
  - 点击复选框区域可切换勾选状态

- **"I have no work experience" 开关规则**：
  - 默认状态：关闭
  - 开启时：隐藏所有工作经验字段（Job Function、From、To、"I currently work here"）
  - 关闭时：显示所有工作经验字段
  - Done 按钮激活条件相应调整（无需填写工作经验）

### 3.4 权限规则
- **未登录用户**：
  - 点击 Resume 按钮 → 弹出登录弹窗
  - 登录成功后跳转到简历页
  
- **已登录用户**：
  - 无简历：进入 resume/add 页面（两步式创建流程）
  - 有简历：进入 resume 页面（简历详情展示页）
    - 页面显示：Personal Info（可编辑）、Personal Summary、Work Experience（+添加）、Education Background（+添加）、Language（+添加）
    - 可点击各区域的 Edit 按钮编辑对应内容

### 3.5 业务约束
- First Name 和 Last Name 合计不超过200字符
- 头像图片大小限制：<10MB
- 头像格式限制：JPG/PNG
- 工作经验 To 日期不能早于 From 日期
- 教育经验 To 日期不能早于 From 日期
- 提交后数据持久化到数据库：
  - `resume` 表：简历基础信息
  - `resume_person_info` 表：个人信息
  - `resume_work_experience` 表：工作经验
  - `resume_education` 表：教育背景
- 重新进入简历页面时，数据自动回显最新保存的数据

### 3.6 头像上传规则
- **预设头像**：10个预设头像可选（编号1-10）
- **上传自定义头像**：
  - 点击 "Upload" 按钮打开文件选择器
  - 支持格式：JPG/PNG
  - 大小限制：<10MB
  - 上传成功后显示预览
  - 可删除已上传头像（恢复为默认头像）

### 3.7 数据回显规则
- **首次创建后重新进入**：
  - 如果是 resume/add 页面：数据自动回显到表单（可继续编辑）
  - 如果是 resume 页面：显示简历详情展示页（可点击 Edit 编辑）

- **回显字段**：
  - Step 1：头像、First Name、Last Name、Email、Current Location、Gender
  - Step 2：Job Function、Work From、Work To、"I currently work here" 状态、Education Level、Education From、Education To

- **Current Location 预填**：Spain
- **日期选择器年份范围**：1925-2036

#### AE站（阿联酋站）
- **简历页URL**：https://aepub.58v5.cn/biz/en/resume/add
- **Current Location 预填**：UAE
- **日期选择器年份范围**：1925-2036
- **编辑模式**：已有简历时进入 resume 页面（详情展示页），可点击 Edit 编辑各区域

#### SG站（新加坡站）
- **简历页URL**：https://sgpub.58v5.cn/biz/en/resume/add
- **Current Location 预填**：Singapore

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|-------|---------|---------|---------|
| - | Unsaved Changes | 有未保存变更点击 Back/Done | 弹出确认对话框："You have unsaved changes. Are you sure you want to leave?" |
| - | 上传失败 | 头像上传超过大小限制 | 显示错误提示（具体文案待确认） |
| - | 上传失败 | 头像格式不支持 | 显示错误提示（具体文案待确认） |
