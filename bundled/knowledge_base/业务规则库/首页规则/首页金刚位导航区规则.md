# 首页金刚位导航区规则

## 1. 功能概述
- **业务价值**: 金刚位是首页首屏的核心业务入口,以图标+文案形式提供快速导航,引导用户进入各业务分类,是流量分发的关键枢纽
- **用户角色**: 
  - 访客(visitor): 未登录用户,所有金刚位入口均可见可点击
  - 买家(buyer): 已登录用户,金刚位功能基本一致,但Jobs入口跳转逻辑不同
- **入口位置**: 首页首屏搜索框下方
- **依赖模块**: 
  - 登录状态服务
  - 城市定位服务
  - 分类页面服务

## 2. 核心流程

### 2.1 金刚位展示流程
1. 用户访问城市首页(如纽约首页)
2. 页面首屏搜索框下方展示金刚位区域
3. 按固定顺序展示8个业务入口

### 2.2 入口点击流程
1. 用户点击任一金刚位入口(图标+文案区域均可点击)
2. 系统根据入口类型和登录态判断目标页面
3. 整页跳转至对应列表或导购页

## 3. 业务规则

### 3.1 金刚位展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 展示位置 | 首页首屏搜索框下方 | 固定位置 |
| 入口数量 | 8个 | 固定不变 |
| 入口顺序 | Marketplace→Free→Jobs→Property→Cars→Services→Community→All | 固定顺序 |
| 入口样式 | 图标+文案(重复可读名称) | 如"Marketplace Marketplace" |
| 可见性 | 访客和买家均可见 | 不区分登录态 |
| 可点击性 | 所有入口均可点击 | 不区分登录态 |

### 3.2 Marketplace入口规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 文案显示 | "Marketplace Marketplace" | 图标+重复名称 |
| 访客跳转 | `/en/city-{city}/cate-marketplace/?iconSource=marketplace` | 城市Marketplace导购页 |
| 买家跳转 | 与访客一致 | 无登录态差异 |
| 落地页标题 | "{数量} Marketplace in the {城市}: The Ultimate Buyers Guide (2026) \| ok.com" | 如"425 Marketplace in the New York..." |
| 落地页h1 | "Marketplace" | 页面主标题 |
| Home链接 | `/en/city-{city}/` | 面包屑Home指向城市首页 |

### 3.3 Free入口规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 文案显示 | "Free Free" | 图标+重复名称 |
| 访客跳转 | `/en/city-{city}/cate/?lowestPrice=0&highestPrice=0` | 城市全部分类+0价筛选 |
| 买家跳转 | 与访客一致 | 无登录态差异 |
| 落地页标题 | "{城市} Classifieds Website - OK" | 如"New York Classifieds Website - OK" |

| 特殊说明 | 价格筛选参数lowestPrice=0&highestPrice=0 | 免费商品列表 |

### 3.4 Jobs入口规则(登录态差异)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 文案显示 | "Jobs Jobs" | 图标+重复名称 |
| 访客跳转 | `/en/city-{city}/cate-jobs/?iconSource=jobs` | **城市职位列表** |
| 买家跳转 | `/en/city/cate-jobs/?iconSource=jobs` | **全美/全国职位列表(无城市参数)** |
| 访客标题 | "{数量}K+ Jobs in the {城市}: The Ultimate Buyers Guide (2026) \| ok.com" | 如"12K+ Jobs in the New York..." |
| 买家标题 | "{数量}K+ Jobs in the US: The Ultimate Buyers Guide (2026) \| ok.com" | 如"159K+ Jobs in the US..." |
| 访客Home链接 | `/en/city-{city}/` | 指向城市首页 |
| 买家Home链接 | `/en/` | 指向国家首页 |
| 落地页h1 | "Jobs" | 页面主标题 |
| 重要差异 | **登录态影响跳转URL、页面标题和面包屑Home链接** | Jobs是唯一有登录态差异的入口 |

### 3.5 Jobs入口特殊说明

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| href属性 | `https://us.ok.com/en/city/cate-jobs/` | 访客态金刚位Jobs的href可能展示为全美路径 |
| 实际点击行为 | 访客点击进入城市职位列表 | href与实际跳转不一致 |
| 直接访问href | 进入全美职位列表 | 与点击金刚位行为不同 |
| 自动化建议 | 使用click+落地URL校验,不依赖href断言 | 避免误判 |

| 规则项 | 规则内容 | 说明 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| 404 | 页面不存在 | 目标分类页不存在 | "Page not found" |
| - | 加载失败 | 网络异常或服务不可用 | "Failed to load" |
| - | 登录状态失效 | 会话过期 | 跳转登录页 |

## 5. 依赖模块

- **Marketplace业务域**: Marketplace入口引流

- **Property业务域**: Property入口引流

## 6. 已知问题
- **Jobs入口href不一致**: 访客态金刚位Jobs的href属性可能展示为全美路径(`/en/city/cate-jobs/`),但实际点击行为进入城市职位列表,自动化测试应使用click+落地URL校验,不依赖href断言
- **数量文案动态**: 标题中的数量(如"12K+ Jobs"、"425 Marketplace")随实际数据变化,自动化断言应使用正则或包含匹配
- **移动端未验证**: 当前测试基于宽屏视口(1440×900),移动端表现需单独验证
