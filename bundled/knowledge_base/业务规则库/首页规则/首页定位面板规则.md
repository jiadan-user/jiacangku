# 首页定位面板规则

## 1. 功能概述
- **业务价值**: 定位面板是用户快速切换城市地区的核心工具,准确的位置信息能提升用户体验和内容相关性
- **用户角色**: 
  - 所有用户(访客/买家/卖家): 都可以使用定位面板选择城市
  - 权限一致: 不区分登录态,所有用户权限相同
- **入口位置**: 首页顶部导航栏地图定位图标(map pin icon)
- **依赖模块**: 
  - 地理位置服务(Geolocation API)
  - 城市数据服务
  - LocalStorage(历史记录存储)
  - 搜索服务

## 2. 核心流程

### 2.1 打开定位面板
1. 用户点击顶部导航栏的地图定位图标
2. 面板以模态形式弹出,带半透明蒙层
3. 面板展示完整内容(搜索框、当前位置、历史记录、热门城市、城市列表、字母导航)

### 2.2 城市选择流程
1. 用户通过以下任一方式选择城市:
   - 点击Top Cities中的热门城市(Dubai/Abu Dhabi)
   - 点击Used Locations中的历史记录城市
   - 从完整城市列表中点击目标城市
   - 搜索后点击搜索结果中的城市
   - 点击Near me使用地理定位
2. 面板立即关闭
3. 页面内容更新为选中城市的内容
4. 选中的城市记录到Used Locations

### 2.3 城市搜索流程
1. 用户在搜索框输入城市名称
2. 系统实时筛选城市列表
3. 显示匹配的城市结果
4. 用户点击搜索结果选择城市

## 3. 业务规则

### 3.1 面板展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 打开方式 | 点击顶部地图定位图标 | 单一入口 |
| 展示形式 | 模态面板+半透明蒙层 | 覆盖页面内容 |
| 搜索框 | placeholder="Search City" | 位于面板顶部 |
| 当前位置 | 显示当前选中的城市,带定位图标 | 如"Abu Dhabi" |
| Near me | 地理定位链接 | 触发浏览器定位 |
| Used Locations | 最近使用的城市历史记录 | 最多10个,按时间倒序 |
| Top Cities | 显示Dubai和Abu Dhabi | 热门城市快速选择 |
| 字母导航 | A, D, F, R, S, U | 仅显示有对应城市的字母 |
| 城市列表 | 按字母分组展示 | 完整城市列表 |

### 3.2 搜索规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 搜索触发 | 实时搜索,每次输入立即触发 | 无需点击搜索按钮 |
| 搜索匹配 | 支持部分匹配,从城市名称开头匹配 | 如输入"Al"匹配所有Al开头城市 |
| 大小写 | 不区分大小写 | "dubai"和"Dubai"效果相同 |
| 特殊字符 | XSS防护,不执行JavaScript代码 | 安全过滤 |
| 搜索结果 | 实时筛选城市列表 | Top Cities保持可见 |
| 无结果 | 显示空状态提示 | 如"No cities found" |
| 清空搜索 | 删除所有文字后恢复完整列表 | 包括历史记录、热门城市、字母导航 |
| 最大长度 | ≥200字符 | 无严格限制或限制较宽松 |
| Emoji | 接受Emoji输入但搜索无结果 | 不报错 |
| 纯空格 | 接受空格输入,显示完整列表 | 不报错 |

### 3.3 城市选择规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 选择方式 | Top Cities/Used Locations/城市列表/搜索结果/Near me | 5种选择途径 |
| 面板关闭 | 选择城市后立即关闭 | 无延迟 |
| 页面更新 | 页面内容刷新为选中城市的商品/服务/工作 | 内容切换 |
| URL更新 | 页面URL应更新包含城市参数 | 需验证 |
| 位置显示 | 顶部导航栏当前位置更新为选中城市 | 需验证 |
| 历史记录 | 选中的城市添加到Used Locations | 自动记录 |

### 3.4 Used Locations规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 数据来源 | 用户主动选择的城市 | 不包括默认城市 |
| 存储方式 | LocalStorage | 持久化本地 |
| 显示数量 | 最多10个 | 超出则移除最旧记录 |
| 排序规则 | 按时间倒序,最近使用排最前 | 时间戳排序 |
| 去重规则 | 同一城市只显示一次 | 重复选择更新时间戳到最新 |
| 首次访问 | Used Locations为空或不显示 | 无历史记录 |
| 点击行为 | 点击历史城市与选择新城市相同 | 面板关闭+页面更新 |

### 3.5 Top Cities规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 显示城市 | Dubai和Abu Dhabi | 固定2个热门城市 |
| 显示位置 | 搜索框下方,Used Locations之后 | 固定位置 |
| 样式 | 圆角按钮或标签样式 | 易于识别 |
| 搜索时 | Top Cities保持可见 | 不被搜索结果隐藏 |
| 点击行为 | 与选择城市列表中的城市相同 | 面板关闭+页面更新 |

### 3.6 字母导航规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 显示字母 | A, D, F, R, S, U | 仅显示有对应城市的字母 |
| 点击行为 | 城市列表滚动到对应字母开头的城市区域 | 快速定位 |
| 无对应城市 | 字母不显示或置灰 | 不可点击 |
| 搜索时 | 字母导航隐藏或置灰 | 搜索模式下不需要 |

### 3.7 城市列表规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 分组展示 | 按字母分组,每组有字母标题 | 如"A", "D" |
| 组内排序 | 城市按字母顺序排列 | 字典序 |
| 滚动 | 支持滚动查看完整列表 | 长列表 |
| 搜索筛选 | 搜索时仅显示匹配城市 | 实时筛选 |
| 点击行为 | 点击城市选中该城市 | 面板关闭+页面更新 |

### 3.8 Near me地理定位规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 触发方式 | 点击"Near me"链接 | 位于搜索框下方 |
| 权限请求 | 首次使用弹出浏览器地理位置权限请求 | 原生浏览器弹窗 |
| 允许定位 | 获取用户位置,自动选择最近城市,面板关闭 | 自动完成 |
| 拒绝定位 | 面板保持打开,显示错误提示或无提示 | 降级处理 |
| 不支持 | "Near me"链接不显示或置灰 | 兼容性处理 |
| 定位失败 | 显示错误提示"无法获取位置" | 异常处理 |

### 3.9 关闭面板规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 关闭方式1 | 选择任意城市后自动关闭 | 主流程 |
| 关闭方式2 | 点击面板外蒙层区域 | 取消操作 |
| 关闭方式3 | 按ESC键(需验证) | 键盘快捷键 |
| 关闭后状态 | 蒙层消失,页面恢复正常 | 完全退出 |
| 未选择城市 | 当前选中城市保持不变 | 不影响原状态 |

### 3.10 性能规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 打开速度 | 面板在1秒内完全加载并显示 | 用户体验 |
| 搜索响应 | 输入每个字符后300ms内更新结果 | 实时性 |
| 城市列表 | 完整城市列表一次性加载 | 无分页 |
| 滚动流畅 | 城市列表滚动无明显卡顿 | 性能优化 |

### 3.11 边界与异常规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 无城市数据 | 显示"暂无城市数据" | 兜底方案 |
| 网络异常 | 显示"加载失败,请重试" | 异常提示 |
| 搜索超长 | 接受≥200字符输入,不报错 | 容错处理 |
| 特殊字符 | XSS防护,不执行脚本 | 安全过滤 |
| Emoji | 接受输入,无搜索结果 | 容错处理 |
| 纯数字 | 接受输入,无搜索结果 | 容错处理 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | No cities found | 搜索无匹配结果 | 空状态提示 |
| - | Location access denied | 用户拒绝地理位置权限 | Toast或面板内提示 |
| - | Unable to get location | 地理定位失败 | Toast提示 |
| - | Loading failed | 城市数据加载失败 | "加载失败,请重试" |
| - | Browser not supported | 浏览器不支持定位 | "Near me"链接不显示或置灰 |

## 6. 已知问题
- **URL未更新**: 选择城市后页面URL不更新城市参数,需验证是否为预期设计
- **顶部位置未更新**: 选择城市后顶部导航栏当前位置显示不更新,需验证
