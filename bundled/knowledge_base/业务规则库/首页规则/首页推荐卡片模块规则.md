# 首页推荐卡片模块规则

## 1. 功能概述
- **业务价值**: 首页推荐卡片模块位于金刚位下方,通过横滑推荐卡片为用户提供个性化商品推荐,提升用户发现效率和平台GMV
- **用户角色**: 
  - 访客(visitor): 未登录用户,可浏览推荐内容,点击收藏会触发登录引导
  - 买家(buyer): 已登录用户,可浏览推荐内容并直接收藏
- **模块位置**: 首页金刚位正下方,包含多个横滑推荐区(Top Picks、Popular in For Sale等)
- **依赖模块**: 
  - 推荐算法服务
  - 收藏服务
  - 登录服务
  - 详情页服务

## 2. 核心流程

### 2.1 推荐模块展示流程
1. 用户访问首页(纽约首页为例)
2. 页面加载完成后,金刚位下方展示第一个推荐区"Top Picks"
3. 向下滚动可看到更多推荐区(如"Popular in For Sale")

### 2.2 推荐内容浏览流程
1. 用户查看推荐区内的横滑卡片
2. 点击右侧箭头查看更多推荐卡片
3. 点击左侧箭头回退到之前的卡片

### 2.3 推荐卡片跳转流程
1. 用户点击推荐卡片主体区域
2. 新开浏览器标签页,进入帖子详情页
3. 详情页展示完整的帖子信息

### 2.4 推荐收藏流程
1. 已登录用户点击卡片上的心形收藏按钮
2. 触发收藏埋点,心形图标变为实心/红色
3. 再次点击取消收藏,心形图标恢复空心/灰色

## 3. 业务规则

### 3.1 推荐区展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 位置 | 金刚位正下方 | 固定位置,访客和买家均展示 |
| 推荐区数量 | 多个横滑区 | 包含Top Picks、Popular in For Sale等 |
| 区块标题 | 左侧标题+右侧View more | 如"Top Picks \| View more" |
| 横滑箭头 | 左右箭头图标 | 类名含Recommend_itemIconLeft/Recommend_itemIconRight |
| 卡片排列 | 横向排列 | 支持左右滑动查看更多 |
| 访客态 | 展示推荐模块 | 访客也能看到推荐内容 |
| 买家态 | 展示推荐模块 | 买家看到的推荐内容可能不同 |

### 3.2 Top Picks推荐区规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 区块标题 | "Top Picks" | 固定文案 |
| View more链接 | 跳转全城All类目列表页 | URL为`/city-{city}/cate/` |
| 左键点击View more | 当前标签页跳转 | URL为`https://us.ok.com/en/city-new-york1/cate/` |
| 中键点击View more | 当前标签页打开 | 非新标签页 |
| 落地页标题 | "{城市} Classifieds Website - OK" | 如"New York Classifieds Website - OK" |
| 落地页面包屑 | "Home > All" | 展示全部分类 |
| 落地页筛选 | Best Match/Filter/Category/New York/Price | 多维度筛选 |

### 3.3 Popular in For Sale推荐区规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 区块标题 | "Popular in For Sale" | 固定文案 |
| View more链接 | 跳转Marketplace列表页 | URL为`/city-{city}/cate-marketplace/` |
| 落地页标题 | "Marketplace in New York" | 展示Marketplace类目 |
| 落地页筛选 | 类目筛选条 | 支持子类切换 |

### 3.4 横滑箭头规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 右侧箭头 | 向右滑动,展示后续卡片 | 类名含Recommend_itemIconRight |
| 左侧箭头 | 向左滑动,回退到之前卡片 | 类名含Recommend_itemIconLeft |
| 滑动效果 | 视口内可见卡片内容变化 | 以实际可见内容为准,非DOM前N个 |
| 回退效果 | 恢复接近箭头前的展示 | 支持多次左右切换 |

### 3.5 推荐卡片展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 卡片内容 | 图片、标题、价格、收藏按钮 | 完整信息展示 |
| 长标题处理 | 截断显示,以"…"结尾 | 固定宽度下省略 |
| 价格格式 | $X、$X/hour、$X Monthly、Free等 | 支持多种价格单位 |
| 图片展示 | 卡片顶部封面图 | 点击可进入详情 |
| 收藏按钮 | 心形图标,位于图片区域内 | 类名为.list-components-item-favorite |

### 3.6 推荐卡片跳转规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 点击区域 | 卡片主体区域(非心形按钮) | 整张卡片除收藏按钮外均可点击 |
| 跳转方式 | 新开标签页 | target="_blank" |
| 目标页面 | 帖子详情页 | URL格式为`/cate-xxx/[slug]/` |
| 详情页内容 | 标题、价格、图片、描述等 | 完整帖子信息 |
| 面包屑 | Home > [类目] > [子类目] | 展示层级结构 |

### 3.7 推荐收藏规则(已登录)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 收藏按钮 | 心形图标,类名.list-components-item-favorite | 位于卡片图片区域内 |
| 点击收藏 | 触发home_favourite_click埋点 | 心形图标变为实心/红色 |
| 图标状态 | 空心→实心,灰色→红色 | 视觉反馈 |
| 页面行为 | 仍停留在首页 | 不跳转详情页 |
| Toast提示 | 无强制Toast | 以埋点与交互为准 |
| 再次点击 | 触发home_favourite_remove_click埋点 | 取消收藏 |
| 取消后图标 | 实心→空心,红色→灰色 | 恢复未收藏状态 |

### 3.8 推荐收藏规则(访客)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 点击收藏 | 弹出登录弹层 | 引导用户登录 |
| 弹层标题 | "Welcome to OK.com US" | 国家站点名称 |
| 弹层副标题 | "Free to post. Easy to find." | 营销文案 |
| 登录方式 | Email or phone number输入框 | 主输入方式 |
| Continue按钮 | 初始禁用态 | 输入后启用 |
| 三方登录 | Google/Facebook/Apple图标 | 快速登录入口 |

### 3.9 数据一致性规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 卡片价格 | 与详情页主价格一致 | 价格数值一致 |
| 价格格式 | 与详情页价格单位/周期一致 | 如$X/hour、$X Monthly |
| 卡片标题 | 与详情页标题一致 | 文案一致性 |
| 卡片图片 | 与详情页主图一致 | 图片一致性 |

### 3.10 登录态差异规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 访客态 | 页眉显示"Log in / Register" | 未登录标识 |
| 买家态 | 页眉显示展示名(如"OKerUS_t8bete9") | 已登录标识 |
| 推荐内容 | 访客和买家可能看到不同推荐 | 算法个性化 |
| 收藏功能 | 访客需登录,买家直接收藏 | 权限差异 |
| 模块展示 | 访客和买家均展示推荐模块 | 无展示差异 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | 推荐内容加载失败 | 推荐服务不可用 | 不展示推荐模块或显示占位符 |
| - | 收藏失败 | 收藏服务不可用 | 图标状态不变,Toast提示"收藏失败,请稍后重试" |
| - | 登录弹层打开失败 | JS错误或组件加载失败 | 降级处理,不阻塞主流程 |
| - | 详情页跳转失败 | 目标页面不存在或网络异常 | 显示404或错误提示 |
| - | View more跳转失败 | 目标列表页不存在 | 显示404或错误提示 |

## 5. 依赖模块

### 5.1 上游依赖(谁调用我)
- **首页**: 用户访问首页时自动加载推荐模块
- **用户操作**: 用户主动点击View more、卡片、收藏按钮或横滑箭头

### 5.2 下游依赖(我调用谁)
- **推荐算法服务**: 获取个性化推荐内容
- **收藏服务**: 处理收藏/取消收藏请求
- **登录服务**: 访客点击收藏时引导登录
- **详情页服务**: 点击卡片跳转到帖子详情页
- **列表页服务**: 点击View more跳转到分类列表页
- **埋点服务**: 触发home_favourite_click和home_favourite_remove_click埋点

### 5.3 跨域交互说明
- **通用业务域**: 推荐模块是首页核心内容分发功能
- **Marketplace业务域**: Popular in For Sale推荐区引流到Marketplace列表页
- **收藏业务域**: 推荐卡片收藏功能与收藏页联动
- **详情页业务域**: 推荐卡片跳转到详情页

## 6. 埋点规则

| 埋点名称 | 触发时机 | 说明 |
|---------|----------|------|
| home_favourite_click | 已登录用户点击收藏按钮 | 首页推荐卡片收藏 |
| home_favourite_remove_click | 已登录用户再次点击收藏按钮 | 首页推荐卡片取消收藏 |

## 7. 已知问题
- **推荐内容动态**: 推荐卡片内容由后端算法实时生成,访客和买家看到的内容可能不同
- **截断规则**: 长标题截断规则取决于卡片宽度和字体大小,可能在不同视口下表现不同
- **收藏无Toast**: 收藏/取消收藏操作无强制Toast提示,仅依赖图标变化和埋点,可能影响用户反馈体验
