# 首页右上角功能区规则

## 1. 功能概述
- **业务价值**: 页面右上角功能区提供城市切换、语言切换、收藏、发布、消息、登录/账号管理等核心功能入口,是用户与平台交互的关键枢纽
- **用户角色**: 
  - 访客(visitor): 未登录用户,可切换城市和语言,点击收藏/发布/消息会触发登录引导
  - 买家(buyer): 已登录用户,可使用所有功能,显示展示名和消息未读数
- **模块位置**: 页面顶部导航栏右侧
- **依赖模块**: 
  - 登录服务
  - 收藏服务
  - 发布服务
  - 消息服务
  - 城市定位服务
  - 多语言服务

## 2. 核心流程

### 2.1 功能区展示流程
1. 用户访问首页
2. 页面顶部导航栏右侧展示功能区
3. 根据登录状态展示不同功能入口

### 2.2 登录流程
1. 访客点击"Log in / Register"按钮或受限功能入口
2. 弹出登录弹层(模态dialog)
3. 第一步:输入Email或手机号,点击Continue
4. 第二步:输入密码,点击Log in
5. 登录成功后弹层关闭,顶栏显示展示名

### 2.3 语言切换流程
1. 用户点击语言入口(如"English")
2. 展开语言浮层(tooltip)
3. 选择目标语言(如"Español")
4. 页面URL和内容切换为目标语言

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | Incorrect password. | 密码错误 | Alert顶部提示 |
| - | Your password doesn't meet the required format. | 密码格式不符合要求 | Alert顶部提示,客户端校验 |
| - | 登录弹层打开失败 | JS错误或组件加载失败 | 降级处理,不阻塞主流程 |
| - | 语言浮层打开失败 | JS错误或组件加载失败 | 降级处理,不阻塞主流程 |
| - | 账号菜单打开失败 | JS错误或组件加载失败 | 降级处理,不阻塞主流程 |
| - | 收藏/发布/消息页面跳转失败 | 网络异常或目标页面不可用 | 显示错误提示 |

## 5. 依赖模块

### 5.1 上游依赖(谁调用我)
- **首页**: 用户访问首页时展示功能区
- **用户操作**: 用户主动点击功能区各入口

### 5.2 下游依赖(我调用谁)
- **登录服务**: 处理登录请求,验证凭证
- **收藏服务**: 跳转到收藏列表页(uspub子域)
- **发布服务**: 跳转到发布类目页(uspub子域)
- **消息服务**: 跳转到消息中心(uspub子域)
- **城市定位服务**: 提供城市切换功能
- **多语言服务**: 提供语言切换功能
- **账号服务**: 管理用户账号信息和会话

### 5.3 跨域交互说明
- **通用业务域**: 功能区是首页核心导航功能
- **收藏业务域**: 收藏入口引流到收藏列表页
- **发布业务域**: 发布入口引流到发布类目页
- **消息业务域**: 消息入口引流到消息中心
- **账号业务域**: 账号菜单管理用户信息和设置

## 6. 已知问题
- **展示名规则**: 买家展示名由站点生成(如"OKerUS_t8bete9"),与邮箱(如"shenchang@58.com")不同,可能造成用户困惑
- **消息未读数**: 未读数(如"6")与账号数据相关,可能随时变化
- **窄视口布局**: 窄视口下部分功能区图标可能不可见,需单独验证响应式布局
- **子域跳转**: 收藏、发布、消息等功能跳转到uspub子域,可能导致会话或Cookie处理问题
