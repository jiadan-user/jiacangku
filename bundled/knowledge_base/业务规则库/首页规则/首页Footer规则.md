# 首页Footer规则

## 1. 功能概述
- **业务价值**: 提供全站通用的法律合规入口、用户帮助支持、隐私控制和应用下载引导
- **用户角色**: 所有用户（访客、买家、卖家）
- **入口位置**: 
  - 所有页面底部
  - 固定位于页面最底部
- **依赖模块**: 
  - Cookie 管理服务
  - 第三方链接（Terms、Privacy、Help中心等）
  - 应用商店（App Store、Google Play）

## 2. 核心流程

### 2.1 主流程
1. **用户滚动到页面底部** → 看到Footer区域
2. **点击链接** → 在新标签页打开对应页面（About Us、Help、Cookie Policy等）
3. **点击Cookie Settings** → 打开Cookie设置弹窗 → 查看/修改Cookie偏好 → 保存设置
4. **点击应用下载按钮** → 跳转到应用商店（App Store或Google Play）
5. **切换城市** → URL自动跳转到新城市页面 → Cookie设置保持

### 2.2 异常流程
- **场景1**: 第三方链接无法访问 → 显示404或错误页面
- **场景2**: Cookie弹窗无法打开 → 用户无法修改隐私设置
- **场景3**: 城市切换后Cookie丢失 → 用户需重新设置Cookie偏好
- **场景4**: 应用商店链接错误 → 无法下载应用

## 3. 业务规则

### 3.1 Footer基础展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Footer位置 | 始终位于页面最底部 | 下方无其他内容,不被遮挡 |
| Footer内容 | 包含5个区块 | About Us、Help、Cookie、Our Apps、版权信息 |
| 版权信息 | © 2025 Servanan International Pte. Ltd. | 固定文案 |
| 可见性 | 所有页面均展示 | 全站通用组件 |
| 响应式布局 | 适配不同屏幕尺寸 | 桌面端/移动端 |

### 3.2 About Us 区块规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Terms of Use链接 | 跳转到服务条款页面 | 新标签页打开,target="_blank" |
| Privacy Policy链接 | 跳转到隐私政策页面 | 新标签页打开,target="_blank" |
| 链接href | 指向正确的法律文档页面 | 必须可访问 |
| 新标签页打开 | 所有链接使用target="_blank" | 保留原页面 |
| 法律合规 | 满足GDPR、CCPA要求 | 法律文档必须可达 |

### 3.3 Help 区块规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Help链接 | 跳转到帮助中心页面 | 新标签页打开 |
| Contact Us链接 | 跳转到联系我们页面 | 显示联系表单或客服信息 |
| FAQ链接 | 跳转到常见问题页面 | 显示问题列表或折叠面板 |
| Support and feedback链接 | 跳转到支持反馈页面 | 显示反馈表单或支持选项 |
| Return Policy链接 | 跳转到退货政策页面 | 显示退货规则和流程 |
| Refund Policy链接 | 跳转到退款政策页面 | 显示退款规则和流程 |
| 新标签页打开 | 所有链接使用target="_blank" | 保留原页面 |
| 用户支持入口 | 提供多种用户求助渠道 | 帮助、联系、FAQ等 |

### 3.4 Cookie 区块规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Cookie Policy链接 | 跳转到Cookie政策页面 | 新标签页打开 |
| Cookie Settings链接 | 打开Cookie设置弹窗 | 当前页面弹窗,非跳转 |
| Cookie弹窗标题 | "Cookie Settings" 或 "Cookie 设置" | 清晰标识 |
| Cookie类型 | 必要Cookie、分析Cookie、营销Cookie | 至少3种类型 |
| 必要Cookie | 不可关闭 | 开关禁用或灰色 |
| 可选Cookie | 可关闭 | 开关可点击 |
| Accept All按钮 | 一键开启所有可选Cookie | 快捷操作 |
| Cookie Information入口 | 点击Cookie类型后出现 | 显示详细信息(名称、用途、有效期、提供方) |
| Cookie持久化 | 设置保存后刷新页面仍保持 | Cookie存储 |
| GDPR合规 | 满足欧盟GDPR隐私法规 | 必要Cookie不需同意,可选Cookie需用户同意 |

### 3.5 Cookie 设置详细规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Strictly Necessary Cookies | 必要Cookie,不可关闭 | 开关禁用,始终开启 |
| Analytics Cookies | 分析Cookie,可选 | 开关可切换,默认状态根据产品定义 |
| Marketing Cookies | 营销Cookie,可选 | 开关可切换,默认状态根据产品定义 |
| Cookie开关状态 | 开启/关闭二态 | 点击切换 |
| 保存设置 | 点击Accept All或Save按钮保存 | 设置生效 |
| 刷新后保持 | 设置保存后刷新页面仍保持 | Cookie持久化 |
| Cookie Information展开 | 点击Cookie类型后出现详细信息入口 | 透明度要求 |
| Cookie详细信息 | 包含名称、用途、有效期、提供方 | 用户知情权 |

### 3.6 Our Apps 区块规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| App Store按钮 | 跳转到iOS应用商店页面 | 新标签页打开 |
| Google Play按钮 | 跳转到Android应用商店页面 | 新标签页打开 |
| 按钮图标 | 显示对应平台的官方图标 | App Store图标、Google Play图标 |
| href正确性 | 链接指向正确的应用商店页面 | 应用ID正确 |
| 新标签页打开 | 使用target="_blank" | 保留原页面 |
| 下载引导 | 引导用户下载官方应用 | 提升应用安装率 |

### 3.7 城市切换与Cookie持久化规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 城市切换后URL跳转 | 切换城市后,URL自动跳转到新城市页面 | 如从Dubai切换到Ajman,URL从/city-dubai/变为/city-ajman/ |
| Cookie设置保持 | 切换城市后,Cookie设置保持不变 | 用户之前关闭的Analytics Cookies仍为关闭状态 |
| Footer内容一致性 | 不同城市页面的Footer内容一致 | 链接、按钮、文案相同 |
| 多次切换稳定性 | 多次切换城市后,Cookie设置仍保持 | 设置不丢失 |
| 清除Cookie后重置 | 清除浏览器Cookie后,城市选择重置为默认 | 不再自动跳转 |

### 3.8 链接跳转规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 新标签页打开 | 所有外部链接使用target="_blank" | About Us、Help、Cookie Policy、应用商店等 |
| href属性 | 链接指向正确的目标页面 | 不能为空或错误 |
| 链接可点击 | 所有链接可正常点击 | 不禁用 |
| 跳转成功 | 点击后目标页面正常加载 | 不显示404或错误 |
| 页面标题正确 | 目标页面标题与链接文案一致 | 如Privacy Policy页面标题包含"Privacy" |

### 3.9 弹窗交互规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Cookie Settings弹窗触发 | 点击Cookie Settings链接打开弹窗 | 非跳转 |
| 弹窗遮罩 | 弹窗打开时,背景变暗有遮罩 | 聚焦弹窗 |
| 关闭弹窗 | 点击遮罩或关闭按钮关闭弹窗 | 取消操作 |
| 保存设置 | 点击Accept All或Save按钮保存并关闭 | 设置生效 |
| 弹窗内容 | 显示Cookie类型、开关、描述 | 清晰易懂 |

### 3.10 健壮性规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 链接404处理 | 第三方链接不可访问时,显示错误页面 | 不崩溃 |
| Cookie弹窗异常 | 弹窗无法打开时,降级处理 | 不阻塞主流程 |
| 应用商店链接失效 | 应用商店链接错误时,显示错误提示 | 不崩溃 |
| 城市切换异常 | 城市切换失败时,保持当前城市 | 不丢失Cookie |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| 404 | Not Found | 第三方链接不存在 | "页面不存在" |
| 500 | Internal Server Error | 服务端错误 | "系统错误,请稍后再试" |
| - | Cookie弹窗打开失败 | JS错误或网络异常 | 降级处理,不显示提示 |
| - | 应用商店链接错误 | href配置错误 | "无法跳转到应用商店" |
