# 收藏页规则

## 1. 功能概述
- **业务价值**: 为登录用户提供收藏内容的集中管理功能，方便用户快速访问感兴趣的帖子
- **用户角色**: 登录用户（买家、卖家）
- **入口位置**: 
  - 用户菜单 → "Favourites" 选项
  - 直接访问URL: `/biz/en/list/favorites`
- **依赖模块**: 
  - 用户会话管理（登录态验证）
  - 收藏服务（收藏/取消收藏接口）
  - 帖子详情服务
  - 分页服务

## 2. 核心流程

### 2.1 主流程
1. **访客访问收藏页** → 显示登录引导卡片 → 点击Login按钮 → 弹出登录弹窗
2. **输入邮箱** → 点击Continue → 输入密码 → 点击Log in → 登录成功
3. **自动展示收藏列表** → 4列网格布局展示收藏帖子
4. **点击帖子卡片** → 跳转到详情页 → 浏览器后退返回收藏页
5. **取消收藏** → 点击心形图标 → 卡片立即移除，后续卡片补位
6. **分页浏览** → 点击Next/Prev/页码 → 切换到指定页面
7. **退出登录** → 点击用户名 → 点击Log Out → 页面刷新显示访客状态

### 2.2 异常流程
- **场景1**: 访客直接访问收藏页 → 显示登录引导，不显示收藏列表
- **场景2**: 登录失败 → 显示错误提示，停留在登录弹窗
- **场景3**: 空收藏列表 → 显示空状态提示 + Refresh按钮
- **场景4**: 过期帖子点击 → 不跳转详情页，停留在收藏页
- **场景5**: 会话过期 → 自动跳转登录弹窗

## 3. 业务规则

### 3.1 访问控制规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 访客拦截 | 访客访问收藏页必须显示登录引导卡片 | 卡片包含插图、"Log in to view more content" 文案和 "Login" 按钮 |
| 登录要求 | 必须登录才能查看收藏列表 | 未登录状态下不显示任何收藏帖子 |
| 会话保持 | 登录后刷新/后退保持登录状态 | Cookie持久化登录态 |
| URL直接访问 | 已登录用户可直接访问URL | 无需重新登录，直接显示收藏列表 |

### 3.2 登录流程规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 登录弹窗标题 | "Welcome to OK.com AE" | 首次登录提示 |
| 邮箱输入框 | "Email or phone number" | 支持邮箱或手机号登录 |
| Continue按钮状态 | 有内容时启用，无内容时禁用 | 前端校验 |
| 密码输入界面标题 | "Welcome back!" | 已输入邮箱后显示 |
| Log in按钮状态 | 有密码时启用，无密码时禁用 | 前端校验 |
| 密码显示 | 以掩码形式显示 | 安全保护 |
| 登录成功行为 | 弹窗自动关闭，SPA刷新列表 | 无页面刷新 |
| 用户名显示 | 页面右上角显示用户名 | 如 "OKerAE_dkk3duf" |
| 三方登录 | 显示Google、Facebook、Apple图标 | 支持第三方登录 |

### 3.3 收藏列表展示规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 页面标题 | "Favourites" | 固定标题 |
| 布局方式 | 4列网格布局 | 响应式布局 |
| 卡片元素 | 图片、实心心形图标、标题、位置、价格 | 标准卡片结构 |
| 心形图标状态 | 实心表示已收藏 | 右上角位置 |
| 类目混合展示 | Services、Cars、Jobs、Furniture等 | 不按类目分组 |
| 过期标识 | 过期帖子左上角显示"Expired"标签 | 灰色标签，图片区域显示 |
| 过期帖子点击 | 不可跳转详情页 | URL指向通用首页 https://ae.ok.com/en |
| 正常帖子点击 | 跳转到详情页 | 当前标签页打开 |
| 详情页收藏状态 | 详情页Favourites按钮显示为实心（已收藏） | 状态同步 |

### 3.4 取消收藏规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 触发方式 | 点击卡片右上角实心心形图标 | 无hover状态要求 |
| 确认机制 | 无二次确认弹窗 | 直接移除 |
| 列表更新 | 该卡片立即从列表中移除 | 实时更新 |
| 卡片补位 | 后续卡片自动向前补位 | 无空位 |
| 提示信息 | 无toast提示 | 静默移除 |
| 接口调用 | 异步调用取消收藏接口 | 前端乐观更新 |

### 3.5 重新收藏规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 操作位置 | 在帖子详情页点击Favourites按钮 | 空心图标状态 |
| 图标状态变化 | 空心 → 实心 | 立即更新 |
| 提示信息 | 显示toast "Added to favourites" | 成功提示 |
| 页面刷新 | 无页面刷新 | SPA行为 |
| 列表同步 | 返回收藏页后该帖子出现在第一位 | 最新收藏在前 |
| 收藏状态保持 | 其他收藏帖子保持不变 | 仅新增一条 |

### 3.6 分页规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 默认页码 | 第1页 | 首次访问默认第1页 |
| 每页数量 | 约20张卡片（4列×5行） | 可能略有浮动 |
| Prev按钮状态（第1页） | 禁用状态，灰色样式 | 不可点击 |
| Next按钮状态（最后一页） | 禁用状态，灰色样式 | 不可点击 |
| 当前页高亮 | 页码数字高亮显示 | 视觉区分 |
| 页码点击 | 点击页码数字跳转到指定页 | 直接跳转 |
| Next按钮 | 点击跳转到下一页 | 页码+1 |
| Prev按钮 | 点击跳转到上一页 | 页码-1 |
| 数据完整性 | 不同页面数据不重复 | 分页正确 |
| 状态保持 | 翻页不影响收藏状态 | 状态一致 |
| URL参数 | URL可能包含页码参数 | 如 ?page=2 |

### 3.10 会话与状态规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 刷新页面 | 登录状态保持，收藏列表正常展示 | Cookie持久化 |
| 浏览器后退 | 从详情页返回收藏页，状态保持 | 历史记录管理 |

| 多标签页 | 不同标签页登录态独立 | 无同步 |

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| 401 | Unauthorized | 会话过期或未登录 | 自动弹出登录弹窗 |
| 403 | Forbidden | 无权限访问 | "您没有权限访问该页面" |
| 404 | Not Found | 帖子不存在或已删除 | "帖子不存在" |
| 500 | Internal Server Error | 服务端错误 | "系统错误，请稍后再试" |
| - | 登录失败 | 邮箱或密码错误 | "邮箱或密码错误" |
