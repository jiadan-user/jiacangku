# 车辆列表页规则

## 1. 功能概述
- **功能描述**: 展示车辆列表(二手车/新车),支持筛选、排序、搜索、分页功能
- **用户角色**: 所有用户(游客、买家、卖家)
- **入口位置**: 首页Cars图标 / Browse菜单 / 搜索结果
- **依赖模块**: 搜索模块、筛选模块、分页模块、分类模块

## 2. 核心流程
### 2.1 主流程
1. 从首页点击Cars图标或Browse菜单进入
2. 进入车辆列表页(默认Used cars)
3. 使用筛选条件(城市、价格、里程、品牌)
4. 选择排序方式(Price: Low to High / High to Low / Most recent / Lowest Mileage)
5. 浏览车辆卡片列表
6. 点击卡片进入详情页

### 2.2 异常流程
- 场景1: 筛选条件无结果 → 显示"We couldn't find anything. Try a new search"空态
- 场景2: Min > Max价格/里程输入 → 系统拦截或提示错误
- 场景3: 输入非法字符 → 前端过滤或失焦清空
- 场景4: 分页超出范围 → 显示最后一页或第一页
- 场景5: 网络超时 → 显示"Loading failed"

## 3. 业务规则
### 3.1 页面初始加载规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 页面标题 | 显示"Cars in {城市名称}" | 如"Cars in Abu Dhabi" |
| 面包屑导航 | 显示"Home > Cars" | 路径正确 |
| Location Tag | 显示"Location: {城市名称} ×" | 城市筛选Tag |
| 筛选栏 | 显示Sort/Filter/Location/Price/Mileage/Brand/Reset | 所有筛选入口可见 |
| Loading状态 | 列表区域显示骨架屏或Spinner | 加载完成后显示真实内容 |

### 3.2 Sort排序规则
| 排序选项 | 说明 |
|---------|------|
| Price: Low to High | 按价格升序排列 |
| Price: High to Low | 按价格降序排列 |
| Most recent | 按发布时间降序排列(最新发布排在最前) |
| Lowest Mileage | 按里程数升序排列 |

**排序交互规则**:
- 点击Sort按钮展开排序下拉面板
- 面板包含4个排序选项+Clear+Confirm按钮
- 选中后选项右侧显示填充勾选图标(●)
- 点击Confirm后面板关闭,列表按选择的方式排序
- Sort按钮箭头朝上(展开态)
- 排序为单选,切换排序时前一选项自动取消
- 点击Clear清空排序选择,所有选项恢复未选状态
- 不选任何选项直接Confirm,面板关闭,列表保持默认排序
- 点击面板外区域关闭下拉,若未点击Confirm,排序选择不生效
- 排序后刷新页面,URL参数保留排序状态

### 3.3 Filter综合筛选规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Filter按钮 | 点击展开综合筛选面板 | 侧边抽屉或弹窗 |
| Filter角标 | 已激活筛选时显示角标数字 | 如"Filter · 1","Filter · 2" |
| 角标数字 | 等于激活条件数 | 实时更新 |
| 多条件组合 | 支持多维度筛选(AND逻辑) | 如Category+Year+Transmission |
| 筛选结果为空 | 显示空态"We couldn't find anything. Try a new search" | 空态图标正常显示 |
| Reset/Clear按钮 | 清空所有筛选条件 | 面板内所有选项恢复默认 |
| 按ESC键 | 关闭Filter面板 | 若已选择条件未确认,条件不生效 |

### 3.4 Location城市筛选规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 城市下拉 | 点击城市名称展开城市列表 | 显示UAE主要城市(Abu Dhabi、Dubai、Sharjah等) |
| 切换城市 | 选择Dubai,页面标题变为"Cars in Dubai" | Location Tag变为"Location: Dubai ×" |
| URL更新 | URL路径更新为city-dubai | - |
| 移除城市筛选 | 点击Location Tag的×按钮 | Tag消失,页面标题变为"Cars",列表展示全站数据 |
| 当前选中城市 | 城市下拉列表中高亮显示 | - |
| URL含无效城市 | 显示404或重定向到默认列表页 | 不显示JS错误或白屏 |

### 3.5 Price价格区间筛选规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 价格输入 | 输入最小值和最大值 | 如10000-50000 |
| 合法区间 | 列表展示价格在区间内的车辆 | Price Tag显示已选区间 |
| Min > Max | 提示错误"最大值不能小于最小值" | 不执行筛选请求 |
| 非数字输入 | 输入框限制只能输入数字 | 非数字字符被过滤 |
| 负数输入 | 负数不被接受,提示错误 | - |
| 仅设置Min | 筛选生效,展示价格≥Min的所有车辆 | 单边筛选 |
| 仅设置Max | 筛选生效,展示价格≤Max的所有车辆 | 单边筛选 |

### 3.6 Mileage里程区间筛选规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 里程输入 | 输入最小里程和最大里程 | 如0-50000 km |
| 合法区间 | 列表展示里程在区间内的车辆 | Mileage Tag显示已选区间 |
| Min > Max | 报错提示范围不合法 | - |

### 3.7 Brand品牌筛选规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 品牌下拉 | 点击Brand展开品牌列表 | 显示Toyota、BMW、Mercedes等主流品牌 |
| 品牌列表 | 品牌列表可滚动 | 支持大量品牌 |
| 单个品牌筛选 | 点击Toyota,列表仅显示Toyota品牌车辆 | Brand Tag显示"Brand: Toyota ×" |
| 多个品牌筛选 | 依次选择Toyota和BMW | 列表显示Toyota和BMW的车辆(OR逻辑) |
| 品牌搜索 | 下拉内搜索框输入"Mer" | 品牌列表过滤,仅显示包含"Mer"的品牌 |

### 3.8 Reset重置功能规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Reset按钮 | 点击Reset按钮(带刷新图标) | 清空所有筛选条件 |
| 清空效果 | 所有筛选Tag清除 | 筛选栏恢复初始默认状态 |
| 列表恢复 | 列表恢复默认展示 | Filter按钮角标数清零 |
| 无筛选条件时 | Reset按钮为禁用态或不显示 | 或点击Reset后页面无变化 |

### 3.9 筛选Tag展示与交互规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Tag显示 | 激活筛选后显示对应Tag | 如"Location: Dubai ×","Category: Cars ×" |
| 多个Tag | 同时显示多个Tag | 横向排列,超出时换行或支持滚动 |
| 移除单个Tag | 点击Tag的×只移除该筛选条件 | 其他Tag保持不变,列表根据剩余条件重新加载 |
| 移除所有Tag | 逐一移除所有Tag | Tag区域消失或为空,列表回到初始默认状态 |

### 3.10 搜索框规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 关键词搜索 | 输入关键词点击Search或按Enter | 跳转至搜索结果页,URL包含关键词参数(如q=Toyota) |
| 空值搜索 | 不输入任何内容点击Search | 不提交空请求,或跳转至全量列表页 |
| 特殊字符搜索 | 输入<script>alert(1)</script> | 对特殊字符进行转义,不执行XSS脚本 |
| 超长字符串 | 输入500+字符 | 输入被截断到最大长度,或提交后服务端返回错误提示 |

### 3.11 列表卡片展示规则
| 信息项 | 说明 |
|-------|------|
| 车辆图片 | 外观照片第1张(主图) |
| 车辆标题 | 品牌+型号+年份 |
| 价格 | AED格式,带千分位分隔,保留2位小数或整数 |
| 里程 | 显示里程数+单位(km) |
| 城市 | 显示车辆所在城市 |
| 发布时间 | 相对时间(如"2 days ago") |

**卡片点击规则**:
- 点击任意车辆卡片跳转至车辆详情页
- URL包含车辆ID
- 详情页展示完整车辆信息

### 3.12 空状态规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 空态图标 | 显示放大镜文档图 | - |
| 空态文案 | "We couldn't find anything. Try a new search" | - |
| 无列表项目 | 列表区域为空 | 不显示任何卡片 |

### 3.13 分页规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 每页显示数量 | 20-30条车辆 | 根据站点配置 |
| 分页方式 | 页码跳转/上一页/下一页按钮 | 或无限滚动(下拉加载更多) |
| 首页 | 禁用"上一页"按钮 | - |
| 末页 | 禁用"下一页"按钮 | - |
| 分页后参数保留 | 分页后保留所有筛选和排序参数 | URL参数不丢失 |

### 3.14 会话与状态规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 筛选后刷新 | URL参数保留,筛选条件在刷新后仍有效 | Tag区域、列表结果与刷新前一致 |
| 点击详情后后退 | 回到列表页,筛选条件和滚动位置恢复 | 不需要重新设置筛选条件 |
| 复制URL分享 | 在新标签页打开,展示相同筛选条件和结果 | 筛选Tag正确还原 |

### 3.15 面包屑导航规则
| 层级 | 点击行为 | 目标页面 |
|-----|---------|---------|
| Home | 跳转首页 | /en/ 或根路径 |
| Cars | 跳转Cars分类首页 | /cate-car/ |

### 3.16 健壮性与兼容性规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 筛选参数在分页后保持 | 翻页不丢失筛选参数 | URL参数保留 |
| 筛选参数在进入详情页再返回后保持 | 返回列表页参数不丢失 | 浏览器返回参数保留 |
| Filter面板文案拼写正确 | 关键Label无错别字 | 文案正确 |
| 断网后提交Filter | 显示错误不崩溃 | 友好错误提示 |
| API超时 | 显示Loading或超时提示 | 不白屏 |
| 服务器500 | 显示友好错误文案 | 不暴露堆栈 |
| 移动端响应式 | 筛选栏可横向滚动,卡片为单列布局 | 各按钮触摸点≥44px |
| 多浏览器兼容 | Chrome、Firefox、Safari均可正常加载 | UI无明显差异 |

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | We couldn't find anything. Try a new search | 筛选条件无匹配结果 | 未找到符合条件的车辆,请调整筛选条件 |
| - | Invalid price range | Min > Max | 最低价格不能大于最高价格 |
| - | Invalid mileage range | Min里程 > Max里程 | 最小里程不能大于最大里程 |
| - | Invalid input | 输入非数字字符 | 请输入有效的数字 |
| - | Page not found | 页码超出范围 | 页面不存在 |
| - | Loading failed | 网络超时或服务异常 | 加载失败,请重试 |
