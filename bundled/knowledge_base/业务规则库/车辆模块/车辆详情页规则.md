# 车辆详情页规则

## 1. 功能概述
- **功能描述**: 展示车辆完整信息,支持收藏、联系卖家、分享、查看地图、查看相关车辆等交互功能
- **用户角色**: 所有用户(游客、买家、卖家、发布者)
- **入口位置**: 车辆列表页点击车辆卡片 / 搜索结果 / 相关车辆推荐 / 直接URL访问
- **依赖模块**: 用户登录模块、收藏模块、地图模块、推荐模块

## 2. 核心流程
### 2.1 主流程
1. 从列表页或搜索结果点击车辆卡片
2. 进入车辆详情页(/cate-car-used-car/<car-model>-<post_id>/)
3. 浏览车辆信息(主图、价格、描述、车辆信息、基本特征、位置)
4. 可选操作: 收藏、联系卖家、分享、查看地图、查看相关车辆
5. 发布者可进行编辑或撤回操作
6. 点击面包屑或相关车辆跳转到其他页面

### 2.2 异常流程
- 场景1: 车辆不存在 → 显示404或"车辆不存在"友好提示
- 场景2: 未登录点击收藏 → 弹出登录框
- 场景3: 未登录点击联系 → 弹出登录框
- 场景4: 非发布者尝试编辑/撤回 → 无按钮显示(权限控制)
- 场景5: 地图加载失败 → 显示"Map loading failed"

## 3. 业务规则
### 3.1 页面展示规则
| 信息项 | 必填 | 说明 |
|-------|-----|------|
| 主图区 | 是 | 外观照片轮播,支持左右切换 |
| 价格 | 是 | 显示格式: AED 1,234,567(带千分位逗号) |
| 车辆标题 | 是 | 品牌+型号+年份+配置 |
| 年份/里程/地点 | 是 | 横向排列显示 |
| 发布时间标签 | 是 | 如"Posted 0 min ago"或"Updated X min ago" |
| Seller's Note | 否 | 卖家自定义描述,为空时不显示该区域 |
| Vehicle Info | 是 | Specs/Mileage/Body Color/First Registration |
| Basic Features | 是 | Fuel Type/Drive Type/Engine(cc)/Transmission |
| Location | 是 | 显示地址+"Show map"按钮 |
| 卖家信息卡片 | 是 | 头像+用户名 |
| Related Cars | 否 | 横向滚动展示相关车辆 |
| 收藏按钮 | 是 | Favourites按钮 |
| 联系按钮 | 是 | Contact按钮 |
| 分享按钮 | 是 | Share按钮 |

### 3.2 收藏功能规则
| 状态 | 操作 | 效果 |
|-----|------|------|
| 未登录 | 点击Favourites | 弹出登录框(Welcome to OK.com) |
| 已登录-未收藏 | 点击Favourites | 收藏成功,按钮或图标变为已收藏状态 |
| 已登录-已收藏 | 点击Favourites | 取消收藏,按钮或图标变为未收藏状态 |
| 刷新页面 | - | 收藏状态保持 |

**登录弹窗内容**:
- 标题: "Welcome to OK.com"
- 站点标识: "AE"
- Email or phone number输入框
- Continue按钮(未输入时为disabled)
- 第三方登录入口(Google、Facebook、Apple)
- 政策文案: "By continuing, you accept OK's Terms of Use..."

### 3.3 联系功能规则
| 状态 | 操作 | 效果 |
|-----|------|------|
| 未登录 | 点击Contact | 弹出登录框(与收藏相同) |
| 已登录 | 点击Contact | 进入联系卖家流程(打开聊天/表单弹窗或跳转) |

### 3.4 分享功能规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Share按钮 | 点击Share按钮触发分享 | 复制链接到剪贴板 |
| 分享提示 | 显示"Link copied"提示 | 提示在2秒后自动消失 |
| 页面URL | 分享时页面URL保持不变 | 不导致页面异常跳转 |

### 3.5 地图弹窗规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Show map按钮 | 点击弹出地图弹窗(dialog) | 地图弹窗显示 |
| 地图弹窗内容 | 展示地图区域及车辆位置标记 | Google Maps或等效地图 |
| Google Maps链接 | 显示"Open this area in Google Maps"链接 | 可点击跳转 |
| 关闭方式1 | 点击close图标或关闭按钮关闭地图弹窗 | 弹窗关闭 |
| 关闭方式2 | 按ESC键关闭弹窗 | 弹窗关闭 |
| 地图加载 | 弹窗打开后地图正常加载 | 显示地图和标记 |

### 3.6 面包屑导航规则
| 层级 | 点击行为 | 目标页面 | 说明 |
|-----|---------|---------|------|
| Home | 跳转首页 | /en/city-{city}/ | 首页正确 |
| Cars | 跳转Cars分类列表 | /cate-car/ | 车辆分类页 |
| Used cars | 跳转二手车列表 | /cate-car-used-car/ | 二手车列表页 |
| 当前页 | 不可点击 | - | 当前层面包屑为不可点击态 |

### 3.7 相关车辆推荐规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 推荐区域 | "Related Cars"区域展示相关车辆卡片 | 横向滚动 |
| 左箭头初始状态 | 第一页时左箭头为disabled状态 | 不可点击 |
| 右箭头可点击 | 第一页时右箭头可点击 | 可切换到下一组 |
| 点击右箭头 | 列表向左滚动,展示更多相关车辆 | 轮播内容切换 |
| 点击相关车辆卡片 | 跳转到该车辆的详情页 | URL与标题更新为新车 |

### 3.8 Vehicle Info展示规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 标题 | 显示"Vehicle Info"标题 | - |
| Specs | 显示规格(如European/GCC) | - |
| Mileage | 显示里程数(如123 km) | 带单位 |
| Body Color | 显示车身颜色(如White) | - |
| First Registration | 显示首次注册日期(如06/2025) | 为空时不显示 |

### 3.9 Basic Features展示规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 标题 | 显示"Basic Features"标题 | - |
| Fuel Type | 显示燃料类型 | 如Petrol/Diesel |
| Drive Type | 显示驱动类型 | 如FWD/AWD/RWD |
| Engine(cc) | 显示发动机排量 | 如2.0L |
| Transmission | 显示变速箱类型 | 如Auto/Manual |

### 3.10 Seller's Note展示规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 标题 | 显示"Seller's Note"标题 | - |
| 内容 | 显示卖家填写的描述内容 | 为空时不显示该区域 |

### 3.11 顶部搜索规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 搜索框输入 | 在"Search for anything"输入关键词 | 输入框可正常填写 |
| 搜索建议 | 输入关键词后显示搜索建议列表 | 如bmw m3、bmw x5等 |
| 点击Search | 跳转至搜索结果页 | 结果页展示与关键词相关的车辆 |

### 3.12 卖家信息规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 头像 | 显示卖家头像或默认头像 | - |
| 用户名 | 显示卖家用户名 | 如OKerAE_xxx |
| 点击头像/用户名 | 跳转到该卖家的个人/店铺页 | URL包含profile或用户标识 |

### 3.13 图片查看器规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 点击主图 | 打开全屏或大图查看器 | 可左右切换多图 |
| 关闭方式1 | 点击关闭按钮 | 查看器关闭,回到详情页 |
| 关闭方式2 | 按ESC键 | 查看器关闭 |

### 3.14 权限规则
| 用户角色 | 可见操作 | 说明 |
|---------|---------|------|
| 游客(未登录) | 浏览、搜索 | 不展示Edit、Withdraw按钮,收藏/联系需登录 |
| 已登录买家 | 浏览、搜索、收藏、联系、分享 | 不展示Edit、Withdraw按钮 |
| 已登录卖家(非发布者) | 浏览、搜索、收藏、联系、分享 | 不展示Edit、Withdraw按钮 |
| 车辆发布者 | 所有操作+Edit+Withdraw | 可编辑或撤回自己的车辆 |

### 3.15 危险操作规则

#### Edit(编辑)
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Edit按钮可见性 | 仅发布者可见Edit按钮 | 权限控制 |
| 点击Edit | 跳转至编辑页,URL包含id参数 | /biz/en/cars/publish?id=<post_id> |
| 编辑权限 | 可修改车辆信息 | 所有字段都可以编辑 |

#### Withdraw(撤回)
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Withdraw按钮可见性 | 仅发布者可见Withdraw按钮 | 权限控制 |
| 点击Withdraw | 显示确认对话框 | 询问是否确认撤回列表 |
| 确认撤回 | 点击Confirm,帖子被撤回 | 跳转到我的发布列表或首页 |
| 取消撤回 | 点击Cancel,对话框关闭 | 帖子状态不变,仍为已发布 |

### 3.16 会话与状态规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 详情页刷新 | 刷新后仍为同一辆车详情页 | 核心信息一致 |
| 浏览器后退 | 从详情页后退,返回列表页 | 列表状态合理(如页码、筛选) |

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| 404 | Car not found | 访问无效车辆ID | 该车辆不存在或已下架 |
| - | Please login first | 未登录点击收藏/联系 | 请先登录 |
| - | Map loading failed | 地图服务不可用 | 地图加载失败,请稍后重试 |
| - | Loading failed | 网络超时或服务异常 | 加载失败,请重试 |
