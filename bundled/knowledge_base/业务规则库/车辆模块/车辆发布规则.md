# 车辆发布规则

## 1. 功能概述
- **功能描述**: 车辆发布功能,支持二手车/新车发布,包含车型选择、图片/视频上传、车辆信息填写、价格与联系方式设置
- **用户角色**: 卖家/车主
- **入口位置**: 首页Post按钮 → 发布分类选择 → Cars分类 → 发布表单
- **依赖模块**: 图片上传服务、车型数据库、地图服务

## 2. 核心流程
### 2.1 主流程
1. 用户登录后点击首页Post入口
2. 在发布分类页选择Cars分类
3. 进入车辆发布页面(/biz/en/cars/publish?categoryId=6548)
4. 选择车型(三级联动: 品牌→车型→配置)
5. 上传外观照片(必填,1-9张)
6. 填写价格(必填)
7. 上传内饰照片(可选,0-9张)
8. 填写Description(可选,0-10000字符)
9. 填写车辆信息(里程数、车身颜色、首次注册、规格)
10. 填写联系信息(电话、位置)
11. 点击Post发布

### 2.2 异常流程
- 场景1: 未登录点击Post → 跳转登录页,登录成功后返回发布页
- 场景2: 图片上传失败 → 显示错误提示,允许重新上传
- 场景3: 必填项未填写 → 提交失败,高亮显示未填写字段
- 场景4: 价格/里程数超出范围 → 自动截断或显示错误提示
- 场景5: 网络超时 → Toast提示"提交失败,请稍后重试"

## 3. 业务规则
### 3.1 车型选择规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 车型选择方式 | 三级联动对话框 | 品牌→车型→配置 |
| 品牌选择 | 点击Car model字段打开对话框,显示所有品牌列表 | 如Audi, BMW, Mercedes-Benz等 |
| 车型选择 | 选择品牌后自动进入车型选择页 | 显示该品牌下所有车型 |
| 配置选择 | 选择车型后自动进入配置选择页 | 显示该车型的所有配置 |
| 选择完成 | 选择配置后对话框关闭,Car model字段显示完整车型信息 | 如"Audi A6 2025 2.0L 190 HP Petrol Auto FWD" |
| 返回按钮 | 每级显示返回按钮可返回上级 | 支持重新选择 |
| 取消选择 | 点击关闭或按ESC,对话框关闭且不填充数据 | Car model字段保持原状态 |

### 3.2 图片/视频上传规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 外观照片数量 | 1-9张,必填 | 至少上传1张 |
| 内饰照片数量 | 0-9张,可选 | 非必填 |
| 图片格式 | JPG/PNG | 其他格式拒绝 |
| 主图逻辑 | 第一张外观照片为主图 | 删除主图后下一张自动成为主图 |
| 图片预览 | 点击图片可打开图片查看器 | 显示大图,支持左右切换 |
| 图片查看器功能 | Set as Main / Delete | 设置主图/删除图片 |
| 未上传图片提交 | 提示"Please upload a photo before submitting." | 发布被阻止 |
| 图片计数显示 | 显示已上传数量/最大数量 | 如"1/9"或"2/9" |

### 3.3 价格设置规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 价格范围 | 1 - 100,000,000 AED | 必填 |
| 价格为0 | 提交失败,显示"Price cannot be 0." | 焦点移动到Price字段 |
| 负数输入 | 负号被自动拒绝或去除 | 字段值保持为正数或空 |
| 超过最大值 | 输入被自动截断为100,000,000 | 无验证错误提示 |
| 边界值 | 1和100,000,000均可成功提交 | 详情页正确显示价格 |
| 非数字输入 | 输入被过滤或提交时报错 | 提示格式错误 |

### 3.4 Description描述规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 字符上限 | 10,000字符 | 非必填 |
| 字符计数 | 显示当前字符数/最大字符数 | 如"152/10000" |
| 达到最大长度 | 无法继续输入更多字符 | 字符计数显示"10000/10000" |
| 超过最大长度 | 输入被截断或提示超过最大长度 | - |
| 为空时提交 | 提交成功 | 详情页不显示"Seller's Note"区域 |
| 详情页展示 | 以"Seller's Note"标题显示 | 下方显示填写的描述内容 |

### 3.5 车辆信息字段规则
| 字段 | 类型 | 必填 | 取值范围 | 格式 | 默认值 | 说明 |
|------|------|------|----------|------|--------|------|
| Mileage(km) | Number | 是 | 0-99,999,999 | 非负整数 | - | 里程数 |
| Body Color | 单选 | 是 | Black/White/Silver/Red等 | 枚举 | - | 车身颜色 |
| First Registration | Date | 否 | 月份+年份 | MM/YYYY | - | 首次注册日期 |
| Specs | 单选 | 是 | GCC/European/American等 | 枚举 | - | 规格 |

**Mileage规则**:
- 拒绝负数输入(负号被自动去除)
- 超过最大值自动截断为99,999,999
- 为空时提交失败,显示"Please fill out this field."

**Body Color规则**:
- 单选模式,选择后按钮状态变为"Selected"
- 为空时提交失败,显示"Please fill out this field."

**First Registration规则**:
- 提供月份(01-12)和年份下拉选择
- 为空时可以成功提交
- 详情页不显示First Registration信息或显示空状态

**Specs规则**:
- 单选模式,选择后按钮状态变为"Selected"
- 为空时提交失败,显示"Please fill out this field."

### 3.6 联系信息规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Contact Phone | 预填值,可修改 | 手机号注册账号自动反显 |
| Contact Phone为空 | 清空后仍可提交(验证不一致问题) | 字段标记为必填但允许为空 |
| 手机号格式校验 | 无效格式被拒绝 | 提交时报错 |
| Location输入 | 输入关键词显示搜索建议列表 | 如"Dubai Mall" |
| Location选择 | 点击搜索建议或按Enter键填充位置信息 | 搜索建议列表关闭 |
| Locate me按钮 | 点击自动定位当前位置 | 浏览器请求地理位置权限 |
| Location为空 | 提交失败 | 必填字段 |

### 3.7 表单提交与验证规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 部分必填项未填写 | 提交失败,显示所有验证错误 | 页面滚动到第一个错误字段 |
| 所有必填项已填写 | 提交成功,显示成功对话框 | 自动跳转到车辆详情页 |
| 详情页URL格式 | /en/city/cate-car-used-car/<car-model>-<post_id>/ | - |
| 详情页时间显示 | "Posted 0 min ago" | 刚发布的帖子 |
| 详情页信息完整性 | 显示所有填写的信息 | 车型/价格/里程/颜色/规格/照片/描述/位置 |

### 3.8 编辑与撤回规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Edit按钮 | 详情页显示Edit按钮 | 仅发布者可见 |
| 编辑页面 | 跳转到编辑页面,URL包含id参数 | /biz/en/cars/publish?id=<post_id> |
| 编辑页面数据 | 所有已填写的数据都保留在表单中 | 可修改任意字段 |
| 编辑提交 | 提交成功,跳转回详情页 | 详情页显示更新后的信息 |
| Withdraw按钮 | 详情页显示Withdraw按钮 | 仅发布者可见 |
| Withdraw确认 | 点击Withdraw显示确认对话框 | 提供Cancel和Confirm按钮 |
| Withdraw取消 | 点击Cancel,对话框关闭 | 帖子状态不变,仍为已发布 |
| Withdraw确认 | 点击Confirm,帖子被撤回 | 跳转到我的发布列表或首页 |

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| 1001 | 图片上传失败 | 图片大小超限或格式不支持 | 请上传有效的JPG/PNG图片 |
| 1002 | 外观照片未上传 | 不上传任何外观照片尝试提交 | Please upload a photo before submitting. |
| 1003 | 外观照片超过9张 | 尝试上传第10张外观照片 | 外观照片最多9张 |
| 1004 | 内饰照片超过9张 | 尝试上传第10张内饰照片 | 内饰照片最多9张 |
| 1005 | 价格为0 | 价格输入0尝试提交 | Price cannot be 0. |
| 1006 | 价格超过最大值 | 输入价格>100,000,000 | 价格不能超过100,000,000 AED |
| 1007 | 里程数超过最大值 | 输入里程>99,999,999 | 里程数不能超过99,999,999 km |
| 1008 | 必填项未填写 | 提交时必填项为空 | Please fill out this field. |
| 1009 | Description超过字符上限 | 输入>10,000字符 | 描述最多10,000字符 |

## 5. 已知问题
- 问题1: Location搜索建议选择 - 在Location输入框中按Enter键会直接提交表单,而不是选择搜索建议
- 问题2: Contact Phone验证不一致 - 字段标记为必填(*),但清空后仍可提交
- 问题3: 图片上传计数 - 上传1张外观照片后,计数器显示"2/9",可能系统自动生成了缩略图
