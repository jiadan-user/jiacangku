# 账户主页规则

## 1. 功能概述
- **业务价值**: 展示用户公开信息、已发布帖子列表,支持编辑个人资料(本人)、发起联系(他人Contact),提升用户间信任和交易转化
- **用户角色**: 
  - 访客: 可查看他人公开主页(部分功能受限,需登录)
  - 本人(已登录): 可查看和编辑自己的主页,查看所有已发布帖子,收藏功能
  - 他人(已登录): 可查看他人公开主页,使用Contact发起微聊,收藏他人帖子
- **入口位置**: 
  - 直接URL访问: `/en/profile/{userId}/`
  - 从详情页点击发布者信息跳转
  - 从用户菜单进入"我的主页"
- **依赖模块**: 
  - 用户信息服务
  - 帖子列表服务
  - 收藏服务
  - 微聊/IM服务
  - 编辑资料服务

## 2. 核心流程

### 2.1 本人主页访问流程
1. **已登录用户访问本人主页URL** → 展示个人资料卡
2. **显示编辑入口** → 可编辑个人信息
3. **展示类目Tab** → Services/Marketplace/Property/Shop/Community/Jobs/Cars
4. **展示帖子列表** → 按类目展示已发布帖子,支持收藏

### 2.2 他人主页访问流程
1. **已登录用户访问他人主页URL** → 展示他人资料卡
2. **显示Contact按钮** → 可发起微聊
3. **展示公开信息** → 隐私信息不可见
4. **展示帖子列表** → 他人已发布帖子,支持收藏

### 2.3 访客态访问流程
1. **未登录用户访问他人主页** → 可查看公开信息
2. **点击收藏/Contact** → 弹出登录引导
3. **完成登录** → 返回主页,功能可用

## 3. 业务规则

### 3.1 URL与路由规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| URL格式 | `/en/profile/{userId}/` | 标准主页路径 |
| userId | 数字ID,如796152584505038400 | 用户唯一标识 |
| Jobs子路径 | `/en/profile/{userId}/jobs/` | 职位类目专属路径,支持翻页 |
| 路径不跳转 | 访问本人/他人URL保持不变 | 不强制跳转到其他profile |
| 多语言 | /en/ | 英文站点前缀 |

### 3.2 document.title规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| title格式 | `OKer_* – Posts covering 类目列表 - OK.com` | 固定格式 |
| 展示名前缀 | `OKer_` | 用户展示名前缀 |
| 类目列表 | 如`Services,Marketplace,Property,Shop,Community` | 逗号分隔 |
| 后缀 | `- OK.com` | 站点标识 |
| 本人示例 | `OKer_c8h3yp8 – Posts covering Services,Marketplace,Property,Shop,Community - OK.com` | 实测 |
| 他人示例 | `OKer_mamengmeng02 – Posts covering Jobs, - OK.com` | 实测 |

### 3.3 资料卡展示规则(本人)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 展示名 | OKer_前缀+唯一标识 | 如OKer_c8h3yp8 |
| Top Seller徽章 | 若账号具备则显示 | 可选 |
| 城市 | 带定位图标,如Dubai | 必填 |
| 简介 | 用户自定义简介文案 | 可选 |
| 已发布帖子数 | 动态数字+listing(s)文案 | 非负整数,随发帖/删帖变化 |
| 编辑图标 | 位于昵称/简介区域右侧 | 仅本人可见 |
| h1标签 | 不存在 | 实测document.querySelector('h1')为空 |

### 3.4 资料卡展示规则(他人)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 展示名 | 他人OKer_前缀标识 | 与本人不同 |
| Contact按钮 | 黑色按钮,带聊天气泡图标 | 位于资料卡右侧 |
| 编辑图标 | 不显示 | 他人主页不可编辑 |
| 公开信息 | 展示名、城市、简介、帖子数 | 隐私信息不可见 |
| 隐私保护 | 不暴露手机号、邮箱、精确地址 | 安全要求 |

### 3.5 类目Tab规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Tab列表 | Services/Marketplace/Property/Shop/Community/Jobs/Cars | 7个类目,横向排列 |
| 默认选中 | Services | 粗体+下划线 |
| Tab切换 | 点击Tab切换列表数据源 | 对应类目帖子 |
| 空态展示 | 空类目显示占位 | 如"There's nothing here." |
| Jobs子路径 | /jobs/路径默认选中Jobs Tab | 特殊路径 |

### 3.6 帖子列表规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 列表布局 | 栅格布局,卡片形式 | 多列展示 |
| 卡片内容 | 图片、标题、地点、价格、收藏图标 | 标准卡片结构 |
| 视频标识 | 部分卡片带播放图标 | 视频帖子 |
| 收藏图标 | 位于卡片图片右上角,心形 | 空心/实心切换 |
| 空态文案 | "There's nothing here." | 无帖子时显示 |
| 翻页支持 | Jobs子路径支持翻页 | 分页/Load more |

### 3.7 收藏功能规则(已登录)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 收藏位置 | 帖子卡片图片右上角心形图标 | 固定位置 |
| 初始状态 | 空心(未收藏)/实心(已收藏) | 状态标识 |
| 点击切换 | 点击空心→实心(收藏),点击实心→空心(取消) | 状态切换 |
| 针对性 | 仅影响当前卡片,不误改其他 | 独立操作 |
| 状态保持 | 刷新后状态与后端一致 | 数据同步 |
| 不弹登录框 | 已登录下直接操作 | 无阻断 |

### 3.8 收藏功能规则(访客)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 点击拦截 | 弹出登录/注册弹窗或跳转登录页 | 需登录提示 |
| 不静默失败 | 必须有明确拦截或引导 | 用户感知 |
| 登录后行为 | 返回主页,收藏功能可用 | 流程闭环 |
| 与已登录区分 | 访客不得误记为已收藏 | 权限区分 |

### 3.9 Contact→微聊规则(已登录)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Contact位置 | 他人主页资料卡右侧 | 仅他人主页显示 |
| 按钮样式 | 黑色按钮,带聊天气泡图标 | 视觉识别 |
| 点击行为 | 进入微聊页面/IM容器 | 跳转路径 |
| 会话对象 | 当前profile主体用户 | 非本人自己 |
| 不弹登录框 | 已登录下直接进入 | 无阻断 |
| 页面加载 | 微聊页正常加载,无白屏 | 可用性 |
| 返回路径 | 可返回账户主页 | 导航正常 |

### 3.10 Contact规则(访客)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 点击拦截 | 弹出登录引导 | 需登录 |
| 拦截形态 | 统一登录/注册弹窗或跳转 | 待产品统一 |
| 登录后行为 | 返回主页,Contact可用 | 流程闭环 |

### 3.11 编辑资料规则(本人)

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 编辑入口位置 | 昵称/简介区域右侧 | 仅本人主页 |
| 编辑图标 | 编辑图标/按钮 | 明确标识 |
| 点击跳转 | 进入个人信息/资料编辑页 | 跳转路径 |
| 页面加载 | 编辑表单/模块可加载 | 无白屏 |
| 返回路径 | 可返回账户主页 | 导航正常 |
| 他人不可见 | 他人主页不显示编辑入口 | 权限控制 |

### 3.12 顶栏与主体一致性规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 顶栏用户 | 始终显示当前登录用户 | 全局一致 |
| 主体用户 | 资料卡显示当前profile主体 | 可能是本人或他人 |
| 身份分离 | 顶栏≠主体(查看他人时) | 区分登录者与被查看者 |
| 示例 | 顶栏OKer_c8h3yp8,主体OKer_mamengmeng02 | 查看他人主页时 |

### 3.13 隐私与安全规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 展示名公开 | OKer_前缀展示名公开 | 公开身份 |
| 手机号隐私 | 不暴露未脱敏手机号 | 隐私保护 |
| 邮箱隐私 | 不暴露完整邮箱(@+域名) | 隐私保护 |
| 地址隐私 | 不暴露精确住址 | 隐私保护 |
| 用户ID可见 | URL中的userId可见 | 公开标识 |
| 防爬控制 | userId枚举需防爬/频控 | 待产品确认 |

### 3.14 访客态鉴权规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 本人主页访问 | 按产品策略(公开/登录/拦截) | 待实测 |
| 他人主页访问 | 可浏览公开信息 | 部分功能受限 |
| 收藏拦截 | 需登录,有明确引导 | TC041 |
| Contact拦截 | 需登录,有明确引导 | TC042 |
| 编辑入口隐藏 | 访客不可见编辑入口 | 权限控制 |

### 3.15 异常与边界规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 非法userId | 返回404或错误页 | 待实测 |
| 会话过期 | 跳转统一登录页 | 待产品确认路径 |
| 历史栈后退 | 正常后退,无串号 | 浏览器后退 |
| 帖子数动态 | 不得写死固定值 | 随发帖/删帖变化 |
| 空列表 | 显示"There's nothing here." | 空态文案 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| 404 | 用户不存在 | 访问非法userId | "页面不存在"或404页面 |
| 401 | 未登录 | 会话过期或访客操作需登录功能 | 跳转登录页或弹出登录弹窗 |
| 403 | 无权限 | 尝试编辑他人资料 | "无权限"或隐藏入口 |
| - | 收藏失败 | 网络异常或服务不可用 | Toast提示"收藏失败" |
| - | Contact失败 | 微聊服务不可用 | Toast提示"联系失败" |

## 5. 依赖模块

### 5.1 上游依赖(谁调用我)
- **全局导航**: 用户菜单→我的主页
- **详情页**: 点击发布者信息跳转
- **搜索结果**: 点击用户跳转
- **微聊**: 从聊天记录跳转到对方主页

### 5.2 下游依赖(我调用谁)
- **用户信息服务**: 获取用户资料、展示名、城市、简介、徽章
- **帖子列表服务**: 获取用户已发布帖子列表,按类目筛选
- **收藏服务**: 添加/取消收藏,查询收藏状态
- **微聊/IM服务**: Contact跳转微聊,建立会话
- **编辑资料服务**: 跳转资料编辑页,保存修改
- **鉴权服务**: 验证登录态,拦截访客操作

### 5.3 跨域交互说明
- **用户业务域**: 账户主页是用户业务域的核心页面
- **帖子业务域**: 展示用户发布的帖子列表
- **收藏业务域**: 收藏功能跨域调用
- **IM业务域**: Contact跨域跳转微聊
