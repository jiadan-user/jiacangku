# 订单创建规则

## 1. 功能概述
- **功能描述**: 二手交易订单创建功能,支持Checkout下单、收货地址填写、支付方式选择
- **用户角色**: 买家
- **入口位置**: 商品详情页Buy Now按钮 → Checkout页面
- **依赖模块**: 支付服务(Airwallex)、地址管理、商品库存

## 2. 核心流程
### 2.1 主流程
1. 买家在商品详情页点击Buy Now按钮
2. 进入Checkout页面(URL含createOrder)
3. 填写/编辑收货地址(Full Name/Address/Phone等)
4. 确认价格信息(Item Price/Delivery/Total)
5. 点击Pay按钮唤起支付弹窗(Airwallex iframe)
6. 选择支付方式(银行卡/Google Pay)
7. 完成支付,订单状态变为Payment received
8. 跳转到订单详情页

### 2.2 异常流程
- 场景1: 未登录点击Buy Now → 跳转登录页,登录成功后进入Checkout
- 场景2: 商品已被其他买家占用 → 显示"Someone placed a bid but didn't complete payment"
- 场景3: 收货地址必填项未填写 → 显示"Cannot be empty"错误,弹窗不关闭
- 场景4: 支付弹窗超时 → 订单保持Pending状态,可重新支付
- 场景5: 支付失败 → 显示错误提示,订单保持Pending状态

## 3. 业务规则
### 3.1 Checkout页面展示规则
| 展示区域 | 内容 | 说明 |
|---------|------|------|
| 左侧Order Summary | 商品信息、价格 | 显示商品缩略图、标题、价格 |
| 左侧Shipping | 配送地址 | 显示收货地址,可点击编辑 |
| 左侧Payment Method | 支付方式 | 显示Airwallex支付 |
| 右侧Order Summary | 价格汇总 | Subtotal/Delivery/Total |
| 右侧Pay按钮 | 黑底白字 | 点击唤起支付弹窗 |

### 3.2 收货地址规则
| 字段 | 类型 | 必填 | 长度 | 格式 | 默认值 | 说明 |
|------|------|------|------|------|--------|------|
| Full Name | String | 是 | 1-100 | 纯文本 | - | 收货人姓名 |
| Address Line 1 | String | 是 | 1-200 | 纯文本 | - | 详细地址 |
| County/City | String | 是 | - | 下拉选择 | - | 城市 |
| State | String | 是 | - | 下拉选择 | - | 州/省 |
| Postal Code | String | 否 | 1-10 | 数字/字母 | - | 邮政编码 |
| Phone Number | String | 是 | - | 电话格式 | - | 联系电话 |

**收货地址字段校验规则**:
- Full Name为空 → 字段内显示"Cannot be empty"错误
- Phone输入字母(如"abc") → 字母被过滤,字段为空后显示"Cannot be empty"
- Phone格式不正确(单个数字"1") → toast提示"Invalid phone number."
- 所有必填字段均空点击Apply → 所有字段同时显示"Cannot be empty",弹窗不关闭
- Postal Code超过10字符时,UI层限制继续输入(字符计数器显示x/10)

**收货地址编辑流程**:
- 点击Shipping区块中的收货地址行(或编辑按钮) → 弹出地址编辑弹窗
- 弹窗包含必填字段: Full Name、Address Line 1、Phone Number
- 点击Clean按钮清空所有字段
- 填写合法收货地址后点击Apply,弹窗关闭
- Checkout页面Shipping区块展示更新后的地址

### 3.3 价格展示规则
| 价格项 | 说明 |
|-------|------|
| 货币单位 | AED |
| Item Price | 商品标价,与商品详情页标价一致 |
| Delivery | 运费,Seller Pays Postage时为AED 0.00 |
| Total | Item Price + Delivery |

**价格展示格式**:
- 货币单位显示AED
- 价格带千分位分隔符(如AED 3,500.00)
- 保留2位小数

### 3.4 支付方式规则
| 支付方式 | 说明 |
|---------|------|
| 银行卡支付 | 在Airwallex iframe中输入银行卡信息(CVC=123) |
| Google Pay | 点击Google Pay按钮,弹出Google Pay确认弹窗 |

**银行卡支付流程**:
- 点击Pay按钮,等待Airwallex支付弹窗(iframe)出现
- 在iframe中输入测试银行卡信息(CVC=123)
- 点击支付确认按钮完成支付
- 支付完成后自动跳转至订单详情页
- 订单状态显示"Payment received"或"Paid"或"Unshipped"

**Google Pay支付流程**:
- 点击Pay按钮,等待Airwallex支付弹窗(iframe)出现
- 在iframe中定位Google Pay按钮并点击
- 若弹出Google Pay确认弹窗(新Popup),在弹窗内点击确认支付按钮后关闭弹窗
- 支付完成后自动跳转至订单详情页
- 订单状态显示"Payment received"或"Paid"或"Unshipped"

**Google Pay支付特殊处理**:
- 若测试环境Airwallex iframe中未渲染Google Pay按钮,用例会失败并提示"请确认测试环境已启用Google Pay"
- Google Pay弹窗为浏览器级别Popup,代码通过expect_popup自动捕获并在弹窗内点击确认
- 重试机制(最多3次): 若支付弹窗显示"Something went wrong, please try again later.",代码自动关闭弹窗并切换商品重试
- Google登录自动检测: 通过弹窗URL判断登录状态(URL含identifier时直接执行邮箱+密码登录)

### 3.5 商品占用规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 商品占用状态 | Buyer paid but incomplete | 其他买家下单但未完成支付 |
| 占用提示 | "Someone placed a bid but didn't complete payment" | 不允许进入Checkout页面 |
| 占用时长 | 24小时 | 超过24小时自动释放 |

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| 2001 | 商品已被占用 | 商品已有其他买家下单但未完成支付 | Someone placed a bid but didn't complete payment |
| 2002 | Full Name为空 | Full Name未填写点击Apply | Cannot be empty |
| 2003 | Phone为空 | Phone未填写点击Apply | Cannot be empty |
| 2004 | Phone格式不正确 | Phone格式不正确点击Apply | Invalid phone number. |
| 2005 | Address Line 1为空 | Address Line 1未填写点击Apply | Cannot be empty |
| 2006 | Postal Code超长 | Postal Code超过10字符 | 字符计数器显示x/10 |
| 2007 | 支付弹窗超时 | 支付弹窗长时间未响应 | 请稍后重试 |
| 2008 | 支付失败 | 支付过程中出现错误 | 支付失败,请重试 |

## 5. 已知问题
- 问题1: Location搜索建议选择 - 在Location输入框中按Enter键会直接提交表单,而不是选择搜索建议
- 问题2: Google Pay支付 - 若测试环境未启用Google Pay,支付弹窗不显示Google Pay按钮
