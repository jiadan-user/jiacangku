# 订单状态流转规则

## 1. 功能概述
- **功能描述**: 二手交易订单完整生命周期管理,涵盖Pending→Unshipped→Pending Receipt→Completed全流程
- **用户角色**: 买家、卖家
- **入口位置**: 
  - 买家: 头像 → Purchase Orders
  - 卖家: 头像 → Sales Orders
- **依赖模块**: 支付服务、物流追踪、微聊服务、退款服务

## 2. 核心流程
### 2.1 主流程
**完整订单流转路径**: 下单 → 支付(Pending) → 卖家发货(Unshipped) → 买家待收货(Pending Receipt) → 交易完成(Completed)

**买家视角流程**:
1. 下单后订单进入Pending状态(未支付)
2. 支付成功后订单进入Unshipped状态(已支付未发货)
3. 卖家发货后订单进入Pending Receipt状态(待收货)
4. 买家确认收货后订单进入Completed状态(已完成)

**卖家视角流程**:
1. 买家下单后订单进入Pending状态(买家支付中)
2. 买家支付成功后订单进入Unshipped状态(待发货)
3. 卖家发货后订单进入Pending Receipt状态(待买家收货)
4. 买家确认收货后订单进入Completed状态(已完成)

### 2.2 异常流程
- 场景1: Pending状态超时未支付 → 24小时后自动取消
- 场景2: 买家/卖家在Pending状态取消订单 → 订单变为Cancelled
- 场景3: 卖家在Unshipped状态取消订单 → 订单变为Cancelled,触发退款
- 场景4: Pending Receipt状态14天未确认收货 → 自动确认收货,订单变为Completed

## 3. 业务规则
### 3.1 订单状态定义
| 状态 | 英文 | 买家视角 | 卖家视角 | 说明 |
|-----|------|---------|---------|------|
| 待支付 | Pending | Processing payment | Buyer paying | 买家下单但未完成支付 |
| 待发货 | Unshipped | Payment Success/Paid | Ready to ship | 买家已支付,卖家未发货 |
| 待收货 | Pending Receipt | Shipped | Shipped | 卖家已发货,买家未确认收货 |
| 已完成 | Completed | Order Completed | Order Completed | 买家已确认收货,交易完成 |
| 已取消 | Cancelled | Order Cancelled | Order Cancelled | 订单已取消 |
| 退款中 | Cancelled (refunding) | - | Cancelled (refunding) | 卖家取消Unshipped订单,退款处理中 |
| 退款完成 | Cancelled (Refund completed) | Cancelled (Refund completed) | - | 退款已到账 |

### 3.2 买家视角状态规则

#### 3.2.1 Purchase Orders页面展示
| Tab | 状态 | 说明 |
|-----|------|------|
| ALL | 所有状态 | 显示所有订单 |
| Pending | 待支付 | 未完成支付的订单 |
| Unshipped | 待发货 | 已支付未发货的订单 |
| Pending Receipt | 待收货 | 已发货未确认收货的订单 |
| Completed | 已完成 | 已确认收货的订单 |

#### 3.2.2 Pending状态(买家视角)
**页面展示**:
- 状态区域显示"Processing payment" + Refresh刷新按钮
- 倒计时显示"Pay within XX:XX:XX or auto-cancel"(蓝色)
- 进度条节点: Placed(已完成) → Paid → Shipped → Completed
- Shipping区块展示买家收货地址(Full Name、Address、City、Country、Phone)
- Order Info区块显示: Order Number、Transaction snapshot、Seller nickname、Order time
- 商品区块显示: 缩略图 + 名称 + 价格
- 价格明细: Total / Item Price / Delivery / Buyer Protection Fee
- 操作按钮: Pay(主操作,黑底白字)、Cancel(次操作)
- 右上角显示Message Seller按钮

**可执行操作**:
- Pay: 点击唤起支付弹窗,完成支付后订单状态变为Unshipped
- Cancel: 点击弹出取消弹窗,选择取消原因后订单状态变为Cancelled
- Message Seller: 点击跳转到与卖家的微聊聊天页面
- Transaction snapshot: 点击"click to view"跳转到交易快照页面
- 修改收货地址: 点击Shipping区块中的收货地址,弹出地址编辑弹窗

**取消原因选项**(5项,单选):
- I don't want to buy it anymore
- Information filled in incorrectly
- Seller out of stock
- Same city meeting and trading
- Other reasons(选择后出现文本输入框)

**取消弹窗操作按钮**:
- Cancel Order(主操作): 选择原因后点击,订单状态变为Cancelled
- Keep Order(次操作): 点击后弹窗关闭,订单保持Pending状态

#### 3.2.3 Unshipped状态(买家视角)
**页面展示**:
- 状态区域显示"Payment Success"或"Paid"
- 进度条: Placed(✓) → Paid(✓) → Shipped → Completed
- Shipping区块展示买家收货地址
- Order Info区块显示: Order Number、Transaction snapshot、Seller nickname、Order time、Payment Time
- 商品区块展示缩略图 + 名称 + 价格
- **无Cancel按钮**(订单已支付,买家不可主动取消)
- 右上角显示Message Seller按钮

**可执行操作**:
- Message Seller: 点击跳转到与卖家的微聊聊天页面
- Transaction Snapshot: 点击"click to view"跳转到交易快照页面

#### 3.2.4 Pending Receipt状态(买家视角)
**页面展示**:
- 状态区域显示"Shipped"
- 自动完成倒计时显示"Auto-complete in Xd XX:XX:XX"(蓝色)
- 进度条: Placed(✓) → Paid(✓) → Shipped(✓) → Completed
- Package Tracking区块展示: Tracking Number、logistics company、"View logistics trajectory"链接
- Order Info区块显示: Order Number、Transaction snapshot、Seller nickname、Receiving address、Order time、Payment Time、Delivery time
- 操作按钮仅有Confirm(黑底白字),**无Cancel按钮**
- 右上角显示Message Seller按钮

**可执行操作**:
- Confirm: 点击弹出确认收货弹窗,点击弹窗Confirm后订单状态变为Completed
- Message Seller: 点击跳转到与卖家的微聊聊天页面
- View logistics trajectory: 点击跳转到物流追踪页面

**确认收货弹窗**:
- 弹窗显示确认提示文字
- 弹窗操作按钮: Confirm(确认收货)、Back(返回)
- 点击弹窗Back → 弹窗关闭,订单保持Shipped状态
- 点击弹窗Confirm → 订单状态变为Completed

#### 3.2.5 Completed状态(买家视角)
**页面展示**:
- 状态区域显示"Order Completed"
- 进度条全部完成: Placed(✓) → Paid(✓) → Shipped(✓) → Completed(✓)
- Order Info区块含新增字段Transaction Time
- 操作按钮仅有"View Transaction"(单一按钮)
- 右上角显示Message Seller按钮

**可执行操作**:
- View Transaction: 点击弹出交易记录弹窗,显示-AED 3500(红色/负数,代表支出)
- Message Seller: 点击跳转到与卖家的微聊聊天页面
- Upload Buyer Photos: 上传买家秀图片

**View Transaction弹窗内容**:
- 显示**-AED 3500**(红色/负数,代表支出)
- 显示"Transaction Successful"
- 显示Payment Time、Product Name、Order ID、Reference ID
- 显示汇率说明文字及Help链接
- 金额为负数(-AED),表示买家支出

### 3.3 卖家视角状态规则

#### 3.3.1 Sales Orders页面展示
| Tab | 状态 | 说明 |
|-----|------|------|
| ALL | 所有状态 | 显示所有订单(含Pending/Unshipped/Cancelled/Cancelled (refunding)/Completed (Payment in progress)) |
| Pending | 待支付 | 买家未完成支付的订单 |
| Unshipped | 待发货 | 买家已支付未发货的订单 |
| Pending Receipt | 待收货 | 已发货未确认收货的订单 |
| Completed | 已完成 | 已确认收货的订单 |

**订单卡片显示**:
- 买家昵称
- 状态标签(颜色区分)
- 商品名称
- 价格
- 超过10条时显示分页控件(1 / 2 / 3 … N)

#### 3.3.2 Pending状态(卖家视角)
**页面展示**:
- 状态标题显示"Buyer paying"
- 倒计时显示"Pay within 23:XX:XX or auto-cancel"(蓝色)
- 进度条: Placed(✓) → Paid → Shipped → Completed
- Order Info区块显示: Order Number、Transaction snapshot、Buyer nickname、Order time
- **无Shipping区块**(买家尚未支付,地址未传给卖家)
- 操作按钮仅有Cancel(单一按钮)
- 右上角显示Message Buyer按钮

**可执行操作**:
- Cancel: 点击弹出取消弹窗,选择取消原因后订单状态变为Cancelled
- Message Buyer: 点击跳转到与买家的微聊聊天页面

**取消原因选项**(7项,单选,与买家选项不同):
- Buyer requested cancellation
- Incorrect product information or price
- Product out of stock or sold out
- Agreed local meetup transaction
- Buyer information is abnormal
- Product damaged or lost before shipment
- Other reasons

**取消弹窗操作按钮**:
- Back(次操作): 点击后弹窗关闭,订单保持Pending状态
- Confirm(主操作,未选原因时禁用): 选择原因后Confirm变为可用,点击后订单状态变为Cancelled

#### 3.3.3 Unshipped状态(卖家视角)
**页面展示**:
- 状态标题显示"Ready to ship"
- 倒计时显示"Ship in Xd XX:XX:XX or auto-cancel"(蓝色)
- 进度条: Placed(✓) → Paid(✓) → Shipped → Completed
- Shipping区块展示买家收货地址(Full Name、Address、City、Country、Phone)及copy按钮
- Order Info区块显示: Order Number、Transaction snapshot、Buyer nickname、Order time、Payment Time
- 操作按钮: Cancel + Add Tracking(主操作,黑底白字)
- 右上角显示Message Buyer按钮

**可执行操作**:
- Add Tracking: 点击弹出发货弹窗,填写Tracking Number和logistics company后提交
- Cancel: 点击弹出取消弹窗,选择取消原因后订单状态变为Cancelled,触发退款
- Message Buyer: 点击跳转到与买家的微聊聊天页面

**Add Tracking发货弹窗**:
- 弹窗标题: "Add Shipping Tracking"
- 弹窗包含: Seller Address(可点击编辑)、Tracking Number输入框(必填)、logistics company下拉(必填)
- logistics company下拉共13个选项: Aramex / Australia Post / DHL / Expeditors / FedEx / J.B. Hunt / TNT / Toll Group / UPS / USPS / XPO Logistics / iMile / Other Couriers
- 警示文字: "After submitting the shipment, it cannot be changed. Please carefully check the information"
- 底部显示"Mark as Shipped"按钮

**Seller Address编辑流程**:
- 点击Seller Address右侧箭头图标,打开发货地址编辑弹窗
- 弹窗包含必填字段: Full Name、Address Line 1、Phone Number
- 点击Clean按钮清空所有字段
- 填写合法发货地址后点击Apply,弹窗关闭
- Add Tracking弹窗中Seller Address展示更新后的地址

**Seller Address字段校验规则**:
- Full Name为空 → 字段内显示"Cannot be empty"错误
- Phone输入字母(如"abc") → 字母被过滤,字段为空后显示"Cannot be empty"
- Phone格式不正确(单个数字"1") → toast提示"Invalid phone number."
- 所有必填字段均空点击Apply → 所有字段同时显示"Cannot be empty",弹窗不关闭
- Postal Code超过10字符时,UI层限制继续输入(字符计数器显示x/10)

**Add Tracking字段校验规则**:
- Tracking Number为空 → 字段下方显示"Cannot be empty"错误提示
- logistics company未选择 → 字段下方显示"Cannot be empty"错误提示
- 两个必填字段同时校验,提交被阻止,弹窗不关闭

**Tracking Number特殊字符输入**:
- 前端**无字符类型过滤**,所有字符(字母/数字/连字符/下划线/特殊符号/汉字)均可正常输入并显示

**提交发货成功**:
- 弹窗关闭,订单状态切换为"Shipped"(即Pending Receipt状态)
- 页面新增Package Tracking区块: Tracking Number: TEST1234567890 / logistics company: DHL / "View logistics trajectory"链接
- Order Info新增Delivery time字段,记录发货时间
- 原"Add Tracking"按钮消失(被Package Tracking区块替代)
- 倒计时从"Ship in Xd"切换为"Auto-complete in 14d 23:59:58"

**取消已支付未发货订单(退款流程)**:
- 点击Cancel按钮,在弹窗中选择取消原因(如"Incorrect product information or price")
- 点击Confirm,订单页面状态显示"Order Cancelled"
- 显示取消原因: "Reason for order cancellation: Incorrect product information or price"
- 显示退款说明: "The funds will be refunded to the buyer from the platform's escrow account."
- Order Info新增Transaction closure time字段
- **注意**: 取消后状态直接显示"Order Cancelled",不显示"Cancelled (refunding)"中间状态(Web端刷新后跳过中间态)

#### 3.3.4 Pending Receipt状态(卖家视角)
**页面展示**:
- 状态标题显示"Shipped"
- 倒计时显示"Auto-complete in 13d XX:XX:XX"(蓝色)
- 进度条: Placed(✓) → Paid(✓) → Shipped(✓) → Completed
- Package Tracking区块展示: Tracking Number、logistics company、"View logistics trajectory"链接
- Order Info区块显示: Order Number、Transaction snapshot、Buyer nickname、Receiving address、Order time、Payment Time、Delivery time
- **无操作按钮**(已发货后买卖家均不可取消)
- 右上角显示Message Buyer按钮

**可执行操作**:
- View logistics trajectory: 点击跳转到物流追踪页面
- Message Buyer: 点击跳转到与买家的微聊聊天页面

#### 3.3.5 Completed状态(卖家视角)
**页面展示**:
- 状态标题显示"Order Completed"
- 显示提示文字: "The funds have been deposited into the wallet, you can go to the wallet to withdraw them."
- 进度条全部完成: Placed(✓) → Paid(✓) → Shipped(✓) → Completed(✓)
- Order Info区块含新增字段Transaction Time
- 操作按钮仅有"View Transaction"(单一按钮)
- 右上角显示Message Buyer按钮

**可执行操作**:
- **卖家Completed订单详情页不显示View Transaction按钮**(该按钮仅在买家侧展示)
- Message Buyer: 点击跳转到与买家的微聊聊天页面

### 3.4 取消权限规则
| 订单状态 | 买家可取消 | 卖家可取消 | 说明 |
|---------|----------|----------|------|
| Pending(未支付) | ✅ 可取消 | ✅ 可取消 | 双方均可取消 |
| Unshipped(已支付未发货) | ❌ 不可取消 | ✅ 可取消 | 仅卖家可取消,取消后触发退款 |
| Pending Receipt(已发货) | ❌ 不可取消 | ❌ 不可取消 | 双方均不可取消 |
| Completed(已完成) | ❌ 不可取消 | ❌ 不可取消 | 交易已完成,不可取消 |

### 3.5 发货规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 发货入口 | Unshipped订单详情页Add Tracking按钮 | 仅卖家可见 |
| 必填字段 | Tracking Number、logistics company | 两个字段均必填 |
| Seller Address | 可编辑 | 点击Seller Address右侧箭头图标编辑 |
| logistics company选项 | 13个选项 | Aramex/Australia Post/DHL/Expeditors/FedEx/J.B. Hunt/TNT/Toll Group/UPS/USPS/XPO Logistics/iMile/Other Couriers |
| 提交后不可修改 | 警示文字提示 | "After submitting the shipment, it cannot be changed. Please carefully check the information" |
| 发货后状态变化 | 订单状态变为Pending Receipt | 买家可查看物流信息 |

### 3.6 确认收货规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 确认收货入口 | Pending Receipt订单详情页Confirm按钮 | 仅买家可见 |
| 确认收货弹窗 | 显示确认提示文字 | 弹窗操作按钮: Confirm(确认收货)、Back(返回) |
| 点击Back | 弹窗关闭,订单保持Shipped状态 | 不确认收货 |
| 点击Confirm | 订单状态变为Completed | 交易完成 |
| 自动确认收货 | 14天未确认收货自动完成 | 倒计时显示"Auto-complete in Xd XX:XX:XX" |

### 3.7 退款规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 退款触发条件 | 卖家取消Unshipped订单 | 订单已支付未发货时卖家取消 |
| 退款说明 | "The funds will be refunded to the buyer from the platform's escrow account." | 平台托管账户退款给买家 |
| 退款状态 | Cancelled (refunding) → Cancelled (Refund completed) | 退款处理中 → 退款完成 |
| 退款到账时间 | 3-5个工作日 | 根据支付方式不同 |

### 3.8 Message Seller/Buyer规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 买家Message Seller | 所有状态均可见 | 点击跳转到与卖家的微聊聊天页面 |
| 卖家Message Buyer | 所有状态均可见 | 点击跳转到与买家的微聊聊天页面 |
| 聊天对象 | 当前订单对应的买家/卖家 | Buyer/Seller nickname一致 |
| 跳转URL | /biz/en/chat | 微聊聊天页面 |

## 4. 错误处理

| 3002 | Tracking Number为空 | 未填写Tracking Number直接提交 | Cannot be empty |
| 3003 | logistics company未选择 | 未选择logistics company直接提交 | Cannot be empty |
| 3004 | Seller Address必填项为空 | Seller Address必填项未填写点击Apply | Cannot be empty |
| 3005 | Phone格式不正确 | Phone格式不正确点击Apply | Invalid phone number. |
| 3006 | Postal Code超长 | Postal Code超过10字符 | 字符计数器显示x/10 |
| 3007 | 订单已取消 | 尝试操作已取消的订单 | 订单已取消,无法操作 |
| 3008 | 订单已完成 | 尝试取消已完成的订单 | 订单已完成,无法取消 |
| 3009 | 无权限操作 | 买家尝试取消Unshipped订单 | 无权限操作 |
| 3010 | 无权限操作 | 卖家尝试取消Pending Receipt订单 | 无权限操作 |
