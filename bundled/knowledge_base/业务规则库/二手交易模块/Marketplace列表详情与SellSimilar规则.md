# Marketplace列表详情与SellSimilar规则

> **知识库依据**：列表/详情与 Sell Similar 行为以线上为准；**Sell Similar** 文本用例主文档为 [sell_similar_test_cases.md](../../文本用例/marketplace/sell_similar_test_cases.md)（与 `test_ae_marketplace_sell_similar_v2.py` 一一对应），每条用例含 `case_id_sell_similar_tc*` 与 `**UI自动化**：✅ 可自动化`。

## 1. 功能概述

### 业务价值
- 为买家提供商品浏览、筛选、详情查看的完整链路
- 通过 Sell Similar 功能降低卖家发布门槛，提升商品供给效率
- 增强商品发现能力，提高交易匹配效率

### 用户角色
| 角色 | 权限 | 说明 |
|------|------|------|
| 游客 | 浏览列表、查看详情、无法收藏/联系 | 未登录用户 |
| 买家 | 浏览、筛选、收藏、联系卖家、Sell Similar | 已登录的普通用户 |
| 卖家/发布者 | 浏览、编辑/撤回自己的商品 | 商品所有者 |

### 入口位置
| 入口 | 路径 | 说明 |
|------|------|------|
| 首页金刚位 | 首页 → 点击 Marketplace 图标 | 主入口 |
| 直接访问 | `https://{site}.58v5.cn/{language}/city-{city}/cate-marketplace/` | URL 直达 |
| 搜索结果 | 全站搜索 → 筛选 Marketplace 分类 | 搜索导流 |
| Sell Similar | 商品详情页 → Sell Similar 按钮 → 发布页 → 返回列表 | 卖家快速发布入口 |

## 2. 核心流程

### 2.1 主流程

#### 列表页浏览流程
```
进入列表页 → 浏览商品卡片 → [可选]搜索/筛选/排序 → 点击商品标题 → 进入详情页
```

#### 详情页浏览流程（非本人帖）
```
进入详情页 → 查看商品信息 → [可选]查看地图/推荐商品 → [可选]收藏/分享 → [可选]联系卖家 → [可选]点击 Sell Similar
```

#### Sell Similar 流程
```
非本人帖详情页 → 点击 Sell Similar 按钮 → [未登录则调起登录] → 跳转发布页 → 预加载原帖数据 → 修改/补充信息 → 发布
```

### 2.2 异常流程

| 场景 | 处理方式 |
|------|---------|
| 列表为空 | 显示 "No results found" 提示 |
| 筛选无结果 | 显示空状态，引导调整筛选条件 |
| 商品已下线 | 详情页显示 "This listing is no longer available" |
| 图片加载失败 | 显示默认占位图，不影响浏览 |
| 未登录点击 Sell Similar | 调起登录弹窗，登录后进入发布页 |
| 本人帖点击 Sell Similar | 不展示按钮（显示 Withdraw/Edit） |

## 3. 业务规则

### 3.1 列表页规则

#### 筛选规则
| 筛选项 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| Transaction | 单选 | Online / Offline | 无筛选（显示全部） |
| Category | 多级级联 | 二手交易子分类（Electronics、Bedroom Furniture 等） | 无筛选 |
| Price | 区间 | Min - Max 金额 | 无限制 |
| Location | 多选 | 城市/区域 | 当前城市 |
| Condition | 多选 | New / Excellent / Good / Fair / Poor | 无筛选 |

#### 排序规则
| 排序方式 | 说明 |
|---------|------|
| Default | 默认推荐排序（综合相关性、时间、质量） |
| Newest | 按发布时间倒序 |
| Price: Low to High | 按价格升序 |
| Price: High to Low | 按价格降序 |

#### 商品卡片展示规则
| 元素 | 必填 | 说明 |
|------|------|------|
| 商品主图 | ✅ | 第一张图片，失败时显示占位图 |
| 商品标题 | ✅ | 点击进入详情页 |
| 价格 | ✅ | 格式：`AED {金额}`，0 元显示 "Free" |
| 位置信息 | ✅ | 城市或区域名称 |
| 收藏按钮 | ✅ | 已登录可点击，未登录调起登录 |
| 配送标签 | 可选 | Online 商品显示 "Free Delivery" / "Available for Pickup" |

### 3.2 详情页规则

#### Online 详情页特有元素
| 元素 | 说明 |
|------|------|
| Free Delivery 标签 | 商品支持免费配送时显示 |
| Available for Pickup 标签 | 商品支持自提时显示 |
| 精确位置 | 显示详细地址（如 "ADCB ATM - Emirates Center"） |

#### Offline 详情页特有元素
| 元素 | 说明 |
|------|------|
| 位置信息 | 显示更通用的位置（如 "United Arab Emirates"） |
| 无配送标签 | 不显示 Free Delivery / Pickup 标签 |

#### 详情页通用元素
| 模块 | 元素 | 必填 | 说明 |
|------|------|------|------|
| 商品信息 | 主图（1-9张） | ✅ | 支持轮播/点击放大 |
| | 标题 | ✅ | 最多 200 字符 |
| | 价格 | ✅ | 格式：`AED {金额}` |
| | Condition 标签 | ✅ | New / Excellent / Good / Fair / Poor |
| | Description | ✅ | 最多 10000 字符 |
| 卖家信息 | 卖家昵称 | ✅ | 点击进入卖家主页 |
| | Verified User 标签 | 可选 | 已认证用户显示 |
| | Listings 数量 | ✅ | 显示卖家发布的商品总数 |
| 操作按钮 | Favourites | ✅ | 已登录可点击，未登录调起登录 |
| | Share | ✅ | 分享到社交媒体/复制链接 |
| | Contact | 条件 | **非本人帖**显示，点击调起联系弹窗 |
| | Sell Similar | 条件 | **非本人帖 + Marketplace 分类**显示 |
| | Withdraw | 条件 | **本人帖**显示，撤回商品 |
| | Edit | 条件 | **本人帖**显示，编辑商品信息 |
| 推荐模块 | You may also like | ✅ | 展示 4-8 个相似商品 |
| 地图模块 | Show map 按钮 | ✅ | 点击展开地图，显示商品位置 |

### 3.3 Sell Similar 规则

#### 按钮展示规则
| 条件 | 是否展示 Sell Similar |
|------|----------------------|
| 本人发布的商品 | ❌ 不展示（显示 Withdraw/Edit） |
| 他人发布的 Marketplace 商品 | ✅ 展示 |
| 他人发布的非 Marketplace 商品 | ❌ 不展示（如 Jobs、Property 等） |
| 未登录用户 | ✅ 展示，点击调起登录 |
| 已登录用户 | ✅ 展示，点击直接跳转发布页 |

#### 数据继承规则
从原帖详情页点击 Sell Similar 后，发布页应预加载以下数据：

| 字段 | 继承规则 | 说明 |
|------|---------|------|
| 分类 | ✅ 完全继承 | 继承原帖的完整分类路径（如 Electronics → Cell Phones → Apple） |
| 价格 | ✅ 完全继承 | 继承原帖价格，用户可修改 |
| 标题 | ✅ 完全继承 | 继承原帖标题，用户可修改 |
| 描述 | ✅ 完全继承 | 继承原帖描述，用户可修改 |
| 商品属性 | ✅ 完全继承 | 继承原帖的自定义属性（如 Brand、Model 等） |
| 图片 | ❌ 清空 | **不继承图片**，用户必须重新上传 |
| 视频 | ❌ 清空 | **不继承视频**，用户必须重新上传 |
| 位置 | ❌ 使用用户默认位置 | 不继承原帖位置 |
| 配送选项 | ❌ 使用默认值 | 不继承原帖配送选项 |

### 3.4 业务约束

#### 列表页约束
- 每页最多展示 30 个商品
- 支持无限滚动加载或分页器（视站点配置）
- 筛选条件最多组合 5 个维度
- 搜索关键词最多 100 字符

#### 详情页约束
- 商品下线后详情页仍可访问，显示 "已下线" 状态
- 图片最多支持 9 张轮播
- 视频最多支持 1 个
- 地图模块依赖有效的位置信息，无效时不展示

#### Sell Similar 约束
- 点击 Sell Similar 后 **3 秒内**必须跳转到发布页
- 发布页 URL 必须包含 `/publish/` 路径
- 未登录用户登录成功后，自动跳转到发布页（保留原跳转意图）
- 发布页预加载数据失败时，显示空表单，不阻止用户发布

## 4. 错误处理

### 4.1 错误码定义
| 错误码 | 场景 | HTTP 状态 |
|--------|------|-----------|
| `LISTING_NOT_FOUND` | 商品不存在或已删除 | 404 |
| `LISTING_OFFLINE` | 商品已下线 | 200（展示下线状态） |
| `UNAUTHORIZED` | 未登录访问受限功能 | 401 |
| `FORBIDDEN` | 无权限访问（如编辑他人商品） | 403 |
| `NETWORK_ERROR` | 网络请求失败 | 500 |

### 4.2 错误提示文案
| 场景 | 提示文案 | 说明 |
|------|---------|------|
| 列表加载失败 | "Failed to load listings. Please try again." | 网络错误或服务异常 |
| 详情页加载失败 | "This listing is no longer available." | 商品不存在或已删除 |
| 图片加载失败 | 显示占位图，无文案提示 | 静默降级，不影响浏览 |
| 收藏失败 | "Failed to add to Favourites. Please try again." | Toast 提示 |
| Sell Similar 跳转失败 | "Failed to open publish page. Please try again." | Toast 提示 |

## 5. 依赖模块

### 5.1 上游依赖（谁调用我）
| 模块 | 调用场景 | 说明 |
|------|---------|------|
| 首页搜索 | 搜索结果 → 筛选 Marketplace → 进入列表页 | 搜索导流 |
| 通用业务域: AI 推荐 | Sell Similar → 发布页 → 调用 AI 推荐类目 | 可选依赖，失败时降级 |
| 用户业务域: 登录 | 未登录点击 Sell Similar → 调起登录 → 跳转发布页 | 保留跳转意图 |

### 5.2 下游依赖（我调用谁）
| 模块 | 调用场景 | 说明 |
|------|---------|------|
| 商品发布业务流程 | Sell Similar → 跳转发布页 → 预加载数据 | 核心依赖 |
| 地图服务 | 详情页 → Show map → 展示商品位置 | 第三方地图 API |
| 分享服务 | 详情页 → Share → 分享到社交媒体 | 第三方分享 API |
| 收藏服务 | 列表/详情页 → 收藏 → 同步到用户收藏列表 | 内部服务 |

### 5.3 跨域交互说明
- **Sell Similar → 商品发布**：核心跨域交互，确保数据继承规则一致
- **未登录 → 登录 → 返回原页面**：保留用户跳转意图，登录成功后回跳
- **AI 推荐类目**：Sell Similar 发布页调用 AI 服务，失败时降级展示默认类目

## 6. 已知问题

### 产品待确认问题
| 问题 | 影响 | 状态 |
|------|------|------|
| Sell Similar 按钮在移动端位置 | H5 端按钮位置与 PC 端不一致，影响用户体验 | 待 UI 规范统一 |
| 图片清空逻辑 | Sell Similar 后图片是否清空，PRD 与实现不一致 | 待产品确认 |
| 本人帖列表页标识 | 列表页无法快速识别本人帖，需进入详情页 | 待产品评估 |

### 技术风险
| 风险 | 影响 | 缓解方案 |
|------|------|---------|
| 第三方地图服务不稳定 | 地图模块加载失败，影响位置展示 | 降级：显示文字地址，隐藏地图按钮 |
| 图片 CDN 故障 | 大量图片加载失败，影响浏览体验 | 降级：显示占位图，不阻塞页面加载 |
| Sell Similar 数据继承失败 | 发布页无法预加载数据，用户体验下降 | 降级：显示空表单，允许用户手动填写 |
