# Marketplace Post草稿与体验扩展规则

> **知识库依据**：草稿与发布体验以 AE Classified 发布页实测为准；PC 专项文本用例为 [OK-AE-Marketplace-Post-草稿体验优化-测试用例-PC-20260407.md](../../文本用例/marketplace_post/OK-AE-Marketplace-Post-草稿体验优化-测试用例-PC-20260407.md)。每条用例含 `case_id_ae_marketplace_post_draft_pc_XXX`（三位序号）；**UI自动化** 在 TC020/050/058/064 等为 **⚠️ 半自动化**，其余多为 **✅ 可自动化**（见用例正文）。

## 1. 功能概述

### 业务价值
- 降低卖家发布门槛，避免信息丢失风险
- 提升发布体验，支持中断恢复、多次编辑
- 通过草稿箱快捷入口，提高发布效率

### 用户角色
| 角色 | 权限 | 说明 |
|------|------|------|
| 卖家/发布者 | 创建草稿、编辑草稿、删除草稿、发布草稿 | 已登录用户 |
| 游客 | 无权限 | 未登录用户无法访问发布页 |

### 入口位置
| 入口 | 路径 | 说明 |
|------|------|------|
| 发布页草稿入口 | 发布页 → Draft·N 按钮 | 有草稿且无输入时展示 |
| 账户中心 | 主选单 → Account → My Post → Drafts | 全局草稿管理入口 |
| 返回发布页时 | 刷新/重新打开发布页 | 自动检测草稿，智能提示 |

## 2. 核心流程

### 2.1 主流程

#### 草稿保存流程
```
用户填写表单 → 点击 "Save the draft" → 表单验证 → 保存到服务端 → Toast 提示 "Draft Saved Successfully" → 按钮状态变为 "Draft saved"（置灰 3 秒）
```

#### 草稿加载流程
```
打开发布页 → 检测草稿 → [有草稿且无输入] 展示 "Draft·N" 按钮 → 点击按钮 → 打开 Draft Box → 选择草稿 → 加载草稿数据 → URL 更新为 `?id={draftId}`
```

#### 草稿快捷入口展示流程
```
打开发布页 → 检测草稿 → [有草稿 + 无输入 + 无 LocalStorage 误判] → 展示 "Draft·N" 按钮 → [用户输入任意字段] → 隐藏 "Draft·N" 按钮
```

### 2.2 异常流程

| 场景 | 处理方式 |
|------|---------|
| 草稿保存失败 | 显示 Toast "Failed to save draft. Please try again." |
| 草稿加载失败 | 显示 Toast "Failed to load draft. Please try again." |
| 空草稿保存 | 显示 Toast "Please fill in at least one field to save draft" |
| 网络超时 | 显示 Toast "Network error. Please check your connection." |
| 草稿数量超限 | 显示 Toast "Draft limit reached. Please delete old drafts." |

## 3. 业务规则

### 3.1 草稿保存规则

#### 保存条件
| 条件 | 说明 |
|------|------|
| 至少一个字段有值 | Title、Description、Price、Category 等任一字段非空 |
| 用户已登录 | 未登录用户无法保存草稿 |
| 网络连接正常 | 需要将草稿保存到服务端 |

#### 保存行为
| 行为 | 说明 |
|------|------|
| 首次保存 | 创建新草稿，分配 `draftId`，URL 更新为 `?id={draftId}` |
| 再次保存 | 更新现有草稿，保留 `draftId` |
| 自动保存 | **不支持**，必须手动点击 "Save the draft" |
| 保存成功反馈 | Toast "Draft Saved Successfully"（2-3秒消失） |
| 按钮状态 | 保存成功后 3 秒内，按钮变为 "Draft saved"（置灰不可点） |

#### 保存的字段
| 字段 | 是否保存 | 说明 |
|------|---------|------|
| Title | ✅ | 必填字段，草稿可为空 |
| Description | ✅ | 必填字段，草稿可为空 |
| Category | ✅ | 必填字段，草稿可为空 |
| Price | ✅ | 必填字段，草稿可为空 |
| Location | ✅ | 必填字段，草稿可为空 |
| Images | ✅ | 已上传的图片，草稿可为空 |
| Video | ✅ | 已上传的视频，草稿可为空 |
| Delivery Options | ✅ | 已选择的配送选项，草稿可为空 |
| Condition | ✅ | 商品状况，草稿可为空 |
| 自定义属性 | ✅ | 如 Brand、Model 等，草稿可为空 |

### 3.2 草稿快捷入口规则

#### 入口展示条件（必须**同时满足**）
| 条件 | 说明 |
|------|------|
| 有草稿 | 服务端存在当前分类的草稿 ≥ 1 |
| 无输入 | Title、Description、Price 等所有字段均为空 |
| 无 LocalStorage 误判 | 无遗留的 LocalStorage 数据导致误判 |

#### 入口隐藏条件（满足**任一**即隐藏）
| 条件 | 说明 |
|------|------|
| 用户输入任意字段 | Title、Description、Price 等任一字段有值 |
| 草稿数量为 0 | 服务端无草稿 |
| LocalStorage 有数据 | 浏览器本地存储有未保存数据 |

#### 入口元素规则
| 元素 | 说明 |
|------|------|
| 选择器 | `button.draft-entry` |
| 文案 | `Draft·{N}`（N 为草稿数量） |
| 位置 | 发布页标题区域附近 |
| 响应速度 | 用户输入后 ≤500ms 内隐藏 |

### 3.3 Draft Box 规则

#### Draft Box 元素
| 元素 | 选择器 | 说明 |
|------|--------|------|
| 弹窗容器 | `[role="dialog"]` | 居中 Modal |
| 标题 | `text=Draft Box` | 文案随语言包变化 |
| 关闭按钮 | `[role="dialog"] button[aria-label='Close']` | 右上角 X 图标 |
| 草稿列表项 | 含 `Save time:` 的条目 | 显示标题、保存时间 |

#### 草稿列表项规则
| 字段 | 说明 |
|------|------|
| 标题 | 草稿标题（Title 字段），若为空显示 "Untitled" |
| 保存时间 | `Save time: {timestamp}` 格式（如 "Save time: 2026-04-07 14:30"） |
| 缩略图 | 显示第一张图片缩略图，若无图片显示占位图 |
| 排序 | 按保存时间倒序（最新保存的在最上方） |
| 点击行为 | 点击草稿项 → 加载草稿数据 → 关闭 Draft Box → URL 更新为 `?id={draftId}` |

### 3.4 草稿加载规则

#### 加载行为
| 行为 | 说明 |
|------|------|
| URL 更新 | 加载草稿后，URL 更新为 `.../publish...?id={draftId}` |
| 表单回填 | 所有保存的字段回填到表单 |
| 图片回显 | 已上传的图片显示在图片上传区域 |
| 视频回显 | 已上传的视频显示在视频上传区域 |
| 草稿标识 | 页面顶部显示 "Editing draft"（可选，视产品设计） |

#### 加载失败处理
| 场景 | 处理方式 |
|------|---------|
| 草稿不存在 | Toast "Draft not found"，清空表单 |
| 草稿已被删除 | Toast "Draft has been deleted"，返回空表单 |
| 网络错误 | Toast "Failed to load draft. Please try again." |

### 3.5 退出拦截规则

#### 拦截条件（必须**同时满足**）
| 条件 | 说明 |
|------|------|
| 表单有未保存数据 | Title、Description、Price 等任一字段有值 |
| 未保存草稿 | 未点击 "Save the draft" 或保存失败 |
| 用户尝试退出 | 点击返回/关闭/浏览器后退/刷新页面 |

#### 拦截弹窗规则
| 元素 | 说明 |
|------|------|
| 弹窗标题 | "Save draft before leaving?" |
| 弹窗内容 | "You have unsaved changes. Would you like to save as draft?" |
| 按钮1 | "Save draft"（主按钮，保存后退出） |
| 按钮2 | "Discard"（次按钮，直接退出不保存） |
| 按钮3 | "Cancel"（取消退出，继续编辑） |

#### 不拦截场景
| 场景 | 说明 |
|------|------|
| 表单为空 | 所有字段均为空，直接退出 |
| 已保存草稿 | 已点击 "Save the draft" 且成功，直接退出 |
| 已点击发布 | 已点击 "Post" 按钮，进入发布流程，不拦截 |

### 3.6 业务约束

#### 草稿数量限制
| 限制项 | 值 | 说明 |
|--------|---|------|
| 单用户最大草稿数 | 50 | 超过后需删除旧草稿 |
| 单分类最大草稿数 | 20 | 同一分类最多保存 20 个草稿 |
| 草稿有效期 | 90 天 | 超过 90 天未编辑的草稿自动删除 |

#### 字段限制
| 字段 | 最大长度 | 说明 |
|------|---------|------|
| Title | 200 字符 | 超过时截断或提示 |
| Description | 10000 字符 | 超过时截断或提示 |
| Images | 9 张 | 超过时提示 "Maximum 9 images allowed" |
| Video | 1 个 | 超过时提示 "Maximum 1 video allowed" |

#### 性能约束
| 约束项 | 值 | 说明 |
|--------|---|------|
| 保存响应时间 | ≤3 秒 | 超过 3 秒显示超时错误 |
| 加载响应时间 | ≤2 秒 | 超过 2 秒显示超时错误 |
| 入口隐藏响应时间 | ≤500ms | 用户输入后快速隐藏入口 |
| Toast 显示时长 | 2-3 秒 | 保存成功 Toast 自动消失 |
| 按钮置灰时长 | 3 秒 | "Draft saved" 状态持续 3 秒 |

## 4. 错误处理

### 4.1 错误码定义
| 错误码 | 场景 | HTTP 状态 |
|--------|------|-----------|
| `DRAFT_SAVE_FAILED` | 草稿保存失败 | 500 |
| `DRAFT_LOAD_FAILED` | 草稿加载失败 | 500 |
| `DRAFT_NOT_FOUND` | 草稿不存在或已删除 | 404 |
| `DRAFT_LIMIT_REACHED` | 草稿数量超限 | 400 |
| `EMPTY_DRAFT` | 空草稿无法保存 | 400 |
| `UNAUTHORIZED` | 未登录无法操作草稿 | 401 |
| `NETWORK_ERROR` | 网络请求失败 | 0 |

### 4.2 错误提示文案
| 场景 | 提示文案 | 展示方式 |
|------|---------|---------|
| 草稿保存失败 | "Failed to save draft. Please try again." | Toast（3秒消失） |
| 草稿加载失败 | "Failed to load draft. Please try again." | Toast（3秒消失） |
| 空草稿保存 | "Please fill in at least one field to save draft" | Toast（3秒消失） |
| 草稿不存在 | "Draft not found" | Toast（3秒消失） |
| 草稿数量超限 | "Draft limit reached. Please delete old drafts." | Toast（5秒消失） |
| 网络超时 | "Network error. Please check your connection." | Toast（5秒消失） |

## 5. 依赖模块

### 5.1 上游依赖（谁调用我）
| 模块 | 调用场景 | 说明 |
|------|---------|------|
| 商品发布业务流程 | 发布页 → 草稿保存/加载 | 核心依赖 |
| Sell Similar 流程 | Sell Similar → 发布页 → 可保存草稿 | 继承数据后可保存草稿 |
| 账户中心 | My Post → Drafts → 进入发布页加载草稿 | 全局草稿管理入口 |

### 5.2 下游依赖（我调用谁）
| 模块 | 调用场景 | 说明 |
|------|---------|------|
| 草稿存储服务 | 保存/加载/删除草稿 | 后端服务，负责草稿持久化 |
| 图片上传服务 | 草稿图片上传/回显 | 第三方 CDN 或内部图片服务 |
| 视频上传服务 | 草稿视频上传/回显 | 第三方 CDN 或内部视频服务 |

### 5.3 跨域交互说明
- **草稿保存 → 图片/视频上传服务**：保存草稿时需上传图片/视频到 CDN，返回 URL 存入草稿
- **Sell Similar → 草稿功能**：从 Sell Similar 进入发布页预加载数据后，用户可保存为草稿
- **账户中心 → 草稿功能**：账户中心的草稿列表与发布页的草稿功能数据互通

## 6. 已知问题

### 产品待确认问题
| 问题 | 影响 | 状态 |
|------|------|------|
| 首次保存是否需要教育气泡 | PRD 要求教育气泡，但实测为 Toast | 待产品确认设计 |
| 空草稿是否可保存 | 实测不允许，PRD 未明确 | 待产品确认 |
| 草稿有效期 | 90 天自动删除，PRD 未明确 | 待产品确认 |
| 草稿数量超限提示 | 超过 50 个是否阻止保存 | 待产品确认 |

### 技术风险
| 风险 | 影响 | 缓解方案 |
|------|------|---------|
| LocalStorage 数据冲突 | 草稿入口误判展示 | 定期清理 LocalStorage，避免数据残留 |
| 图片/视频上传失败 | 草稿保存成功但媒体丢失 | 降级：保存草稿时忽略上传失败的媒体 |
| 网络不稳定 | 草稿保存/加载失败率高 | 增加重试机制（最多 3 次） |
| 并发保存冲突 | 多次点击保存导致数据覆盖 | 防抖处理，3 秒内只允许一次保存 |
| 文本用例分级 | 专项/矩阵用例误计为每日 CI 全自动 | 以用例正文 `**UI自动化**` 为准；TC020（≥100 草稿）、TC050（系统原生关闭标签）、TC058（多浏览器+RTL）、TC064（越权造数）标为半自动化 |
