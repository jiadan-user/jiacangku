# 充值规则

## 1. 功能概述
- **功能描述**: 钱包充值功能，允许用户通过脚本或其他方式向钱包充值
- **用户角色**: 卖家/发布者
- **入口位置**: 钱包首页 > Balance区域
- **依赖模块**: 钱包模块、Airwallex支付服务

## 2. 核心流程
### 2.1 主流程
1. 用户进入钱包首页
2. 查看当前余额
3. 执行充值操作（通过脚本或其他方式）
4. 充值成功
5. 刷新页面查看余额更新

### 2.2 异常流程
- 场景1: 充值金额无效 → 显示错误提示
- 场景2: 充值服务不可用 → 显示"Service unavailable"
- 场景3: 网络超时 → 显示"Network timeout, please try again"

## 3. 业务规则
### 3.1 余额显示规则
| 规则项 | 规则内容 | 说明 |
|-------|---------|------|
| 默认状态 | 隐藏显示`****` | 保护隐私，首次进入或刷新页面时为隐藏状态 |
| 眼睛图标位置 | 余额右侧 | 用于切换显示/隐藏 |
| 点击眼睛图标（隐藏→显示） | 显示实际余额和汇率转换 | 如`$4,934.84` + `≈ AED 17928.24` |
| 点击眼睛图标（显示→隐藏） | 恢复隐藏显示`****` | 汇率信息同时隐藏 |
| 问号图标 | Balance标题旁 | 点击显示钱包规则说明弹窗或跳转帮助页面 |

**余额显示格式**：
- 隐藏状态：`****`（灰色星号）
- 显示状态：
  - 主余额：`$金额`（如`$4,934.84`）
  - 汇率转换：`≈ 货币代码 金额`（如`≈ AED 17928.24`）

**眼睛图标状态**：
- 隐藏状态：眼睛图标（表示可点击显示）
- 显示状态：眼睛图标状态改变（表示可点击隐藏）

### 3.2 充值脚本规则（测试环境）
| 规则项 | 规则内容 | 说明 |
|-------|---------|------|
| 脚本路径 | `test_cases/airwallex_recharge/airwallex_recharge_cli.py` | 充值脚本位置 |
| 命令格式 | `python airwallex_recharge_cli.py --amount 50.00 --reason living_expenses` | 充值命令示例 |
| 金额参数 | `--amount` | 充值金额，如50.00 |
| 原因参数 | `--reason` | 充值原因，如living_expenses |
| 执行结果 | 充值成功后余额增加 | 需刷新页面查看 |

**使用场景**：
- 余额<$20时，执行充值脚本使余额增加到≥$20
- 测试提现功能前，确保余额充足

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|-------|---------|---------|---------|
| - | Invalid amount | 充值金额无效 | 充值金额无效 |
| - | Service unavailable | 充值服务不可用 | 服务暂不可用，请稍后重试 |
| - | Network timeout | 网络超时 | 网络超时，请重试 |
| - | Recharge successful | 充值成功 | 充值成功 |
