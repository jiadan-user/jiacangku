# 银行账户规则

## 1. 功能概述
- **功能描述**: 钱包银行账户绑定/解绑功能，支持用户绑定银行账户用于提现，也可随时解绑
- **用户角色**: 卖家/发布者（需要提现收入）
- **入口位置**: 钱包首页 > Bank Account 区域
- **依赖模块**: 钱包模块、Airwallex支付服务、提现模块

## 2. 核心流程
### 2.1 主流程
**绑定流程**：
1. 用户进入钱包首页
2. 点击"+ Add Bank Account"按钮
3. 打开银行账户绑定表单对话框
4. 选择国家/地区（Account country / region）
5. 选择货币（Account currency，根据国家自动填充）
6. 选择转账方式（Transfer method：ACH/Fedwire/FedNow/SWIFT）
7. 填写银行账户信息（routing number、账号、持卡人姓名等）
8. 填写联系信息（邮箱、地址）
9. 点击Submit提交
10. 绑定成功，显示银行账户后四位

**解绑流程**：
1. 用户进入钱包首页
2. 点击银行账户右侧的三点菜单图标
3. 点击"Unbind Bank Account"
4. 弹出二次确认对话框
5. 点击"Confirm"确认解绑
6. 解绑成功，显示"+ Add Bank Account"按钮

### 2.2 异常流程
- 场景1: 有待处理提现时解绑 → 显示错误提示"Cannot unbind bank account with pending withdrawal"
- 场景2: 必填字段未填写提交 → 显示字段必填提示
- 场景3: 邮箱格式错误提交 → 显示"Invalid email format"
- 场景4: 快速连续点击提交 → 防重复提交，仅触发一次
- 场景5: 网络超时 → 显示"Network timeout, please try again"

## 3. 业务规则
### 3.1 银行账户显示规则
| 状态 | 显示内容 | 交互 |
|-----|---------|------|
| 已绑定 | 银行卡图标 + 账号后四位（如`************7854`）+ 三点菜单 | 可点击三点菜单解绑 |
| 未绑定 | `+ Add Bank Account`按钮/链接 | 可点击打开绑定表单 |

**显示规则**：
- 账号显示格式：`************{后四位}`
- 三点菜单图标：显示在账号右侧
- 解绑入口：三点菜单 > "Unbind Bank Account"

### 3.2 解绑规则
| 规则项 | 规则内容 | 说明 |
|-------|---------|------|
| 解绑入口 | 三点菜单 > "Unbind Bank Account" | 已绑定状态下显示 |
| 二次确认 | 弹出确认对话框 | 标题"Unbind"，内容"Are you sure to unbind the bank account?" |
| 确认按钮 | "Confirm" | 点击后执行解绑 |
| 取消方式 | X按钮、ESC键、点击蒙层 | 关闭对话框且不解绑 |
| 解绑限制 | 有待处理提现时禁止解绑 | 显示错误提示 |
| 解绑成功 | 显示"+ Add Bank Account"按钮 | 之前绑定的账户信息不再显示 |

**待处理提现判断**：
- 提现状态为"Bank Processing"时视为待处理
- 提现状态为"Receiving Bank Processed"时视为已完成，可解绑

### 3.3 绑定表单规则
| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| Account country / region | 下拉框 | 是 | 选择收款银行所在国家/地区 |
| Account currency | 下拉框 | 是 | 根据国家自动填充（如USA→USD） |
| Transfer method | 单选 | 是 | 选择转账方式（ACH/Fedwire/FedNow/SWIFT） |

**表单展示规则**：
- 表单在iframe中加载
- 对话框标题："Bind Bank Account"
- 副标题："Bank account"
- 右上角显示X关闭按钮
- 底部显示Submit提交按钮

**国家与货币映射**：
- United States of America → USD（自动填充）
- 其他国家根据实际情况映射

### 3.4 转账方式规则

#### ACH（本地银行转账）
| 字段 | 类型 | 必填 | 格式 | 说明 |
|-----|------|-----|------|------|
| ACH routing number | 文本框 | 是 | 9位数字 | 支持自动补全银行列表 |
| Bank account number | 文本框 | 是 | 数字 | 银行账号 |
| Name of account holder | 文本框 | 是 | 文本 | 持卡人姓名 |
| Nickname Optional | 文本框 | 否 | 文本 | 账户昵称 |
| Email address | 文本框 | 是 | 邮箱格式 | 联系邮箱 |
| Country or region | 下拉框 | 是 | - | 地址国家 |
| Address | 文本框 | 是 | 文本 | 输入3个字母后显示自动补全 |
| City | 文本框 | 是 | 文本 | 选择地址后自动填充，也可手动输入 |

**ACH特性**：
- 描述："Local bank transfer with a limit of 15,000,000.00 USD"
- Transfer fee: 3.00 USD
- Speed: 0 - 2 business days
- 限额：15,000,000.00 USD

#### Fedwire（实时银行转账）
- 描述："Real-time bank transfer"
- Transfer fee: 15.00 USD
- Speed: 0 - 1 business days

#### FedNow（实时银行转账，有限额）
- 描述："Real-time bank transfer with a limit of 500,000.00 USD"
- Transfer fee: 3.00 USD
- Speed: 0 - 1 business days
- 限额：500,000.00 USD

#### SWIFT（国际银行转账）
- 描述："International bank transfer"
- Transfer fee: 25.00 USD (OUR) or 15.00 USD (SHA)
- Speed: 0 - 3 business days

### 3.5 字段校验规则
| 字段 | 校验规则 | 错误提示 |
|-----|---------|---------|
| Bank account number | 不能为空 | "This field is required" |
| Name of account holder | 不能为空 | "This field is required" |
| Email address | 不能为空 + 邮箱格式 | "Invalid email format" |
| ACH routing number | 9位数字 | "Invalid routing number" |
| Address | 不能为空 | "This field is required" |
| City | 不能为空 | "This field is required" |

**自动补全规则**：
- ACH routing number：输入数字后显示匹配的银行列表
- Address：输入3个字母后显示地址自动补全列表
- City：选择地址后自动填充，未填充时可手动输入

### 3.6 防重复提交规则
| 规则项 | 说明 |
|-------|------|
| 提交按钮状态 | 提交后进入loading或禁用状态 |
| 重复点击 | 仅触发一次提交请求 |
| 防抖处理 | 快速连续点击仅触发一次 |

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|-------|---------|---------|---------|
| - | Cannot unbind bank account with pending withdrawal | 有待处理提现时解绑 | 不能解绑有待处理提现的银行账户 |
| - | This field is required | 必填字段未填写 | 此字段为必填项 |
| - | Invalid email format | 邮箱格式错误 | 邮箱格式不正确 |
| - | Invalid routing number | routing number格式错误 | routing number格式不正确 |
| - | Network timeout | 网络超时 | 网络超时，请重试 |
| - | Bank account added successfully | 绑定成功 | 银行账户添加成功 |
| - | Bank account unbound successfully | 解绑成功 | 银行账户解绑成功 |
