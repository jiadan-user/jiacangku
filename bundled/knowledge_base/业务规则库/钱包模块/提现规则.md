# 提现规则

## 1. 功能概述
- **功能描述**: 钱包提现功能，允许用户将钱包余额提现到已绑定的银行账户
- **用户角色**: 卖家/发布者（有收入需要提现）
- **入口位置**: 钱包首页 > Withdraw按钮
- **依赖模块**: 钱包模块、银行账户模块、Airwallex支付服务

## 2. 核心流程
### 2.1 主流程
1. 用户进入钱包首页
2. 检查提现条件（余额≥$20、已绑定银行账户、无待处理提现）
3. 点击Withdraw按钮
4. 打开提现表单对话框
5. 输入提现金额
6. 确认提现
7. 提现申请提交成功
8. 提现状态：Withdrawal Initiated → Bank Processing → Receiving Bank Processed

### 2.2 异常流程
- 场景1: 余额<$20 → Withdraw按钮置灰，点击无反应或提示"Minimum withdrawal amount is $20"
- 场景2: 未绑定银行账户 → 点击Withdraw按钮打开"Bind Bank Account"对话框
- 场景3: 有待处理提现 → Withdraw按钮提示"Withdrawal in progress, please try later"
- 场景4: 提现金额>可提现余额 → 显示错误提示"Insufficient balance"
- 场景5: 提现金额<$20 → 显示错误提示"Minimum withdrawal amount is $20"
- 场景6: 网络超时 → 显示"Network timeout, please try again"

## 3. 业务规则
### 3.1 Withdraw按钮状态规则
| 条件 | 按钮状态 | 点击行为 | 说明 |
|-----|---------|---------|------|
| 余额≥$20 且 已绑定银行账户 且 无待处理提现 | 可点击（深色） | 打开提现表单 | 正常可提现 |
| 余额<$20 | 置灰（灰色，包含CSS类`AmountArea_disable__DvFFP`） | 无反应或提示"Minimum withdrawal amount is $20" | 最低提现金额限制 |
| 未绑定银行账户 | 置灰（灰色） | 打开"Bind Bank Account"对话框 | 引导用户先绑定银行账户 |
| 有待处理提现 | 置灰或提示 | 显示"Withdrawal in progress, please try later" | 一次只能有一笔待处理提现 |

**按钮样式**：
- 可点击状态：深色背景，白色文字
- 置灰状态：
  - 背景色：`rgb(240, 241, 247)`（浅灰色）
  - 文字颜色：`rgb(153, 153, 153)`（灰色）
  - CSS类：`AmountArea_disable__DvFFP`

### 3.2 提现金额规则
| 规则项 | 规则内容 | 说明 |
|-------|---------|------|
| 最低提现金额 | $20.00 | 低于此金额无法提现 |
| 最高提现金额 | 当前可提现余额 | 不能超过钱包余额 |
| 金额输入格式 | 数字，最多2位小数 | 如20.00、100.50 |
| 金额显示格式 | $符号 + 金额 + 2位小数 | 如$20.00 |

**可提现余额计算**：
- 可提现余额 = 钱包总余额 - 待处理提现金额
- 如有待处理提现，可提现余额相应减少

### 3.3 提现表单规则
| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| Withdraw amount | 数字输入框 | 是 | 提现金额，最低$20 |
| Bank account | 只读显示 | - | 显示已绑定的银行账户后四位 |

**表单展示规则**：
- 对话框标题："Withdraw to Bank Account"
- 显示提现金额输入框
- 显示已绑定的银行账户（后四位）
- 显示"Confirm"确认按钮
- 显示X关闭按钮

**金额输入规则**：
- 支持手动输入
- 支持复制粘贴
- 自动格式化为2位小数
- 输入非法字符时自动过滤

### 3.4 提现状态流转规则
| 状态 | 说明 | 时间节点 | 显示 |
|-----|------|---------|------|
| Withdrawal Initiated | 提现申请已提交 | 提交时立即记录 | ✅ + 时间戳 |
| Bank Processing | 银行处理中 | 提交后几秒内 | ✅ + 时间戳 |
| Receiving Bank Processed | 收款银行已处理（最终状态） | 银行处理完成后 | ⚪ 空心圆圈（未完成状态） |

**状态流转时间**：
- Withdrawal Initiated → Bank Processing：通常几秒内
- Bank Processing → Receiving Bank Processed：根据转账方式不同，0-3个工作日

**状态显示规则**：
- 已完成状态：✅ 绿色勾选图标 + 时间戳
- 未完成状态：⚪ 空心圆圈（无时间戳）
- 当前状态：高亮显示

### 3.5 交易历史规则
| 规则项 | 规则内容 | 说明 |
|-------|---------|------|
| 入口 | 钱包首页 > Details按钮 | 跳转到交易历史页面 |
| 排序 | 按时间倒序 | 最新的提现记录在最上方 |
| 显示内容 | 提现金额 + 状态 + 时间 + Details链接 | 每条记录显示关键信息 |
| 分页 | 支持分页 | 每页显示N条记录 |

**交易历史页面URL**：
- 格式：`https://aepub.58v5.cn/biz/en/wallet/details`

**记录显示格式**：
- 金额：`-$20.00`（负数表示支出）
- 状态：Bank Processing / Receiving Bank Processed
- 时间：YYYY-MM-DD HH:mm:ss
- Details：可点击链接，打开提现详情对话框

### 3.6 提现详情规则
| 规则项 | 规则内容 | 说明 |
|-------|---------|------|
| 入口 | 交易历史 > Details链接 | 点击打开提现详情对话框 |
| 对话框标题 | "Withdraw to Bank Account" | 固定标题 |
| 显示内容 | 提现金额 + 状态时间线 + 银行账户 + Reference ID + Help链接 + Close按钮 | 完整提现信息 |

**状态时间线显示**：
- ✅ Withdrawal Initiated + 时间戳（如2026-03-05 12:33:24）
- ✅ Bank Processing + 时间戳（如2026-03-05 12:33:27）
- ⚪ Receiving Bank Processed（最终状态，无时间戳）

**Reference ID**：
- 格式：19位数字（如2029414945641771008）
- 可复制
- 用于查询提现状态或联系客服

**Help链接**：
- 点击跳转到帮助页面或联系客服

### 3.7 余额显示规则
| 规则项 | 规则内容 | 说明 |
|-------|---------|------|
| 默认状态 | 隐藏显示`****` | 保护隐私 |
| 点击眼睛图标 | 显示实际余额和汇率 | 如`$4,934.84` + `≈ AED 17928.24` |
| 再次点击眼睛图标 | 恢复隐藏显示`****` | 切换显示/隐藏 |
| 问号图标 | 点击显示钱包规则说明 | 帮助用户了解钱包规则 |

**余额显示格式**：
- 隐藏状态：`****`
- 显示状态：`$金额`（如`$4,934.84`）
- 汇率转换：`≈ 货币代码 金额`（如`≈ AED 17928.24`）

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|-------|---------|---------|---------|
| - | Minimum withdrawal amount is $20 | 提现金额<$20 | 最低提现金额为$20 |
| - | Insufficient balance | 提现金额>可提现余额 | 余额不足 |
| - | Withdrawal in progress, please try later | 有待处理提现 | 提现进行中，请稍后再试 |
| - | Please bind a bank account first | 未绑定银行账户 | 请先绑定银行账户 |
| - | Network timeout | 网络超时 | 网络超时，请重试 |
| - | Withdrawal submitted successfully | 提现申请成功 | 提现申请已提交 |
