# 房产模块 - 房产列表页业务规则

## 1. 功能概述
- **功能描述**: 展示房产列表（租房/买房/学生公寓/商业地产），支持筛选、排序、搜索、分页功能
- **用户角色**: 所有用户（游客、买家、卖家）
- **入口位置**: 首页 Property 图标 / Browse 菜单 / All 分类 / 搜索结果
- **依赖模块**: 搜索模块、筛选模块、分页模块、分类模块

## 2. 核心流程
### 2.1 主流程
1. 从首页点击 Property 图标或 Browse 菜单进入
2. 选择房产类型（For Rent / For Sale / Student / Commercial）
3. 进入对应列表页
4. 使用筛选条件（价格、卧室、浴室、房产类型）
5. 选择排序方式（Best Match / Newest / Price）
6. 浏览房产卡片列表
7. 点击卡片进入详情页或切换到地图视图

### 2.2 异常流程
- 筛选条件无结果 → 显示"No results found"空态
- Min > Max 价格输入 → 系统拦截或自动交换值
- 输入非法字符 → 前端过滤或失焦清空
- 分页超出范围 → 显示最后一页或第一页
- 网络超时 → 显示"Loading failed"

## 3. 业务规则
### 3.1 入口规则
| 入口位置 | 操作 | 目标页面 | 优先级 |
|---------|------|---------|--------|
| 首页 Property 图标 | 点击 | For Sale 列表页 | P0 |
| All → Property for rent | 点击 | For Rent 列表页 | P0 |
| All → Property for sale | 点击 | For Sale 列表页 | P0 |
| All → Student accommodation | 点击 | 学生公寓列表页 | P0 |
| All → Commercial for sale | 点击 | 商业地产列表页 | P0 |
| Browse → Property for rent | 悬停/点击 | For Rent 列表页 | P0 |
| Browse → Property for sale | 悬停/点击 | For Sale 列表页 | P0 |

### 3.2 排序规则
| 排序选项 | URL参数 | sort_id值 | 排序逻辑 | 默认 |
|---------|---------|-----------|---------|------|
| Best Match | 无 sort_id | - | 综合排序（推荐算法） | ✅ |
| Newest First | sort_id | 1 | 按发布时间倒序 | - |
| Lowest Price | sort_id | 3 | 按价格升序 | - |
| Highest Price | sort_id | 4 | 按价格降序 | - |

**排序交互规则**：
- 默认排序为 Best Match，URL 无 sort_id 参数
- 选择排序后 URL 含对应 sort_id（如 sort_id=1）
- 排序状态在分页后保持（URL 中 sort_id 参数保留）
- 排序状态在视图切换（List↔Map）后保持
- 清除排序恢复默认，URL 中 sort_id 消失
- 打开 Sort 面板不选择点击 Done，URL 不变
- 点击 Sort 面板外部，面板关闭，排序状态不变
- 重新选回 Best Match，URL 中 sort_id 消失

### 3.3 筛选规则

#### 价格筛选
| 字段 | 类型 | 必填 | 格式 | URL参数 | 说明 |
|-----|------|-----|------|---------|------|
| Min Price | Number | 否 | 正整数/小数 | lowestPrice | 最低价格 |
| Max Price | Number | 否 | 正整数/小数 | highestPrice | 最高价格 |

**价格校验规则**：
- Min > Max 时系统拦截（显示提示或自动交换值）
- 拒绝负数输入（前端过滤或失焦清空）
- 拒绝非数字输入（输入被过滤）
- 接受超大值（如 99999999），页面不崩溃
- 接受小数值（系统正常处理或取整）
- Min=0 等效不限下限
- 只输入 Min 或只输入 Max 均有效

#### 卧室筛选（Beds）
| 选项 | URL参数 | 说明 |
|-----|---------|------|
| Studio | attr_168=xxx | 单间公寓 |
| 1 | attr_168=xxx | 1卧室 |
| 2 | attr_168=xxx | 2卧室 |
| 3 | attr_168=xxx | 3卧室 |
| 4 | attr_168=xxx | 4卧室 |
| 5 | attr_168=xxx | 5卧室 |
| 6 | attr_168=xxx | 6卧室 |
| 7 | attr_168=xxx | 7卧室 |
| 8+ | attr_168=xxx | 8卧室及以上 |

**卧室筛选规则**：
- 单选模式（选择一个值）
- 选择后 URL 含 attr_168 对应枚举值
- 清除后 URL 中 attr_168 消失
- 连续多次点击 Beds，最后一次选择生效
- Beds 筛选无结果时，显示"No properties found"空态

| 5 | attr_166=xxx | 5浴室 |
| 5+ | attr_166=xxx | 5浴室及以上 |

**浴室筛选规则**：
- 单选模式
- 选择后 URL 含 attr_166 对应枚举值
- 清除后 URL 中 attr_166 消失
- 支持半间浴室（1.5, 2.5, 3.5, 4.5）
- 全枚举映射验证（Shared/1/1.5/.../5+）

|-----|------------|------|
| House | /house-for-rent/ 或 /house-for-sale/ | 独立屋 |
| Townhomes | /townhomes-for-rent/ | 联排别墅 |
| Apartment / Unit | /apartment-for-rent/ | 公寓 |

| Retirement | /retirement-for-rent/ | 退休公寓 |
| Other | /other-for-rent/ | 其他类型 |

**房产类型筛选规则**：
- 单选模式（选择一个类型）
- 选择后 URL 路径更新为对应类型路径
- 清除后恢复默认 URL 路径
- 点击弹窗 X 关闭，URL 不变（未选）
- 刷新页面，Property Type 状态保持（URL 中类型参数保留，选中态恢复）

### 3.4 搜索规则

#### 关键词搜索
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 普通关键词搜索 | URL 含 q 参数 | 如 ?q=keyword |
| 搜索触发 | 输入关键词按 Enter 或点击 Search 按钮 | 页面刷新列表 |
| 搜索结果匹配 | 结果标题含关键词 | 结果相关 |
| 特殊字符搜索 | 页面无报错 | 正常展示（可能无结果） |
| 纯空格搜索 | 被忽略 | 不产生空关键词搜索 |
| 清除搜索 | 点击清除图标，输入框清空 | 清除图标出现并可点击 |
| 大小写不敏感 | "Sydney" == "sydney" | 返回相同结果 |

#### 联想地址搜索（Sug）
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 联想触发 | 输入2个以上字符 | 联想面板出现，显示联想地址列表 |
| 选择联想地址 | URL 含 suglevel 参数 | 如 suglevel=xxx |
| 联想地址格式 | 完整地址名 | 如 "Canberra, ACT" |
| 手动输入搜索 | 不选联想直接搜索 | URL 无 suglevel 参数 |
| 键盘方向键选择 | 选中态跟随键盘，回车确认 | 触发搜索 |
| 无匹配词 | 联想面板为空态 | 显示"No results"或面板消失 |
| 点击联想面板外部 | 面板关闭 | 搜索框保留输入值 |
| 按 Esc 键 | 联想面板关闭 | - |

#### 搜索历史
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 首次访问 | 点击搜索框，无搜索历史 | 历史列表为空或不展示 |
| 搜索后历史 | 搜索后再次点击搜索框，显示搜索历史 | 历史列表含该词 |
| 点击历史条目 | 自动执行该次搜索 | 触发对应关键词或地址搜索 |
| 历史排序 | 多次搜索不同词，历史按倒序排列 | 最新在最前 |
| 历史去重 | 重复搜索同一词，历史不重复 | 历史无重复条目 |
| 历史上限 | 最多 N 条（FIFO） | 超出上限时最旧条目消失 |
| 历史混合 | 历史混合关键词和联想地址 | 分别正确展示 |
| 历史持久化 | 刷新页面后，搜索历史仍存在 | localStorage/Cookie |

#### 搜索分类切换
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 分类切换 | 切换分类，Filters 被清除 | 筛选条件重置 |
| 搜索关键词保留 | 切换分类，搜索关键词保留 | q 参数保留 |
| 联想地址保留 | 切换分类时保留联想地址搜索 | sug 地址参数保留 |
| 搜索+Filters | URL 含所有参数 | 参数完整 |
| 搜索+Filters+分页 | URL 全保留 | 翻页后参数不丢 |

### 3.5 分页规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 每页显示数量 | 20-30条房产 | 根据站点配置 |
| 页码跳转 | 点击页码，URL 含 page 参数 | 如 page=2 |
| 第1页 | 点击第1页，URL page=1 或无 page 参数 | 返回第1页 |
| Next 按钮 | 有多页时 Next 按钮可见，点击后 URL 更新 page 参数 | 最后一页 Next 禁用 |
| Previous 按钮 | 首页禁用 Previous | - |
| 访问不存在页码 | 显示空态或重定向 | 不崩溃 |
| 浏览器返回 | 分页后浏览器返回，回到前一页 | 页码正确回退 |
| 筛选参数保留 | 分页后保留所有筛选和排序参数 | URL 参数不丢失 |
| 搜索参数保留 | 分页后保留搜索关键词 | q 参数保留 |

### 3.6 视图切换规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| List View（默认） | 列表视图，URL 无 view 参数 | 默认视图 |
| Map View | 地图视图，URL 含 view=map | 点击 Map 按钮切换 |
| List → Map | 点击 Map 按钮，URL 含 view=map | 切换到地图视图 |
| Map → List | 点击 List 按钮，URL 移除 view=map | 切换回列表视图 |
| 直接访问含 view=map 的 URL | 正确加载地图视图 | 不重定向到列表 |
| 刷新页面 | URL 参数全部保留 | 刷新后仍在当前视图且参数在 |
| 浏览器返回 | 回到上一视图 | 后退到上一状态 |
| 搜索参数保留 | 切换视图，搜索关键词保留 | q 参数保留 |
| 筛选参数保留 | 切换视图，Filters 全保留 | 所有筛选参数保留 |
| 排序参数保留 | 切换视图，sort_id 保留 | 排序状态保留 |
| 联想地址参数保留 | 切换视图，suglevel 参数保留 | 联想地址搜索保留 |
| 分页参数保留 | 切换视图+分页，所有参数保留 | 参数全量保留 |

### 3.7 多条件组合规则
| 组合场景 | URL 参数 | 说明 |
|----------|----------|------|
| Price + Beds | lowestPrice/highestPrice + attr_168 | 两参数共存 |
| Sort + Price | sort_id + lowestPrice/highestPrice | 两参数共存 |
| Sort + Property Type | sort_id + 路径类型 | 两参数共存 |
| Beds + Bathrooms | attr_168 + attr_166 | 两参数共存 |
| Bathrooms + Property Type | attr_166 + 路径类型 | 两参数共存 |
| Sort + Beds + Price（三合一） | sort_id + attr_168 + lowestPrice/highestPrice | 三参数共存 |
| Price + Beds + Bathrooms（三合一） | lowestPrice/highestPrice + attr_168 + attr_166 | 三参数共存 |
| Sort + Price + Property Type（三合一） | sort_id + lowestPrice/highestPrice + 路径类型 | 三参数共存 |
| Beds + Bathrooms + Property Type（三合一） | attr_168 + attr_166 + 路径类型 | 三参数共存 |
| 全部五个条件 | sort_id + lowestPrice/highestPrice + attr_168 + attr_166 + 路径类型 | 所有参数共存 |
| 修改单一条件 | 修改 Price，Beds 参数不变 | 其他参数不受影响 |
| 清除单一筛选 | 清除一个筛选，其他保留 | 目标参数消失，其余不变 |
| Reset 按钮 | 三个筛选后全 Reset，URL 恢复默认 | 全部参数清除 |
| 搜索 + Sort + Filter | q + sort_id + filter 参数 | 三者参数共存 |
| 搜索 + Price Filter | q + lowestPrice/highestPrice | 参数完整 |
| Sug 地址 + Filters | suglevel + filter 参数 | 两者参数共存 |
| 清除 Filter | 搜索关键词保留 | q 参数保留，filter 参数消失 |
| 清除搜索框 | Filters 保留 | filter 参数保留，q 参数消失 |

**Filter Badge 规则**：
- Badge 数字与当前已激活筛选数量一致
- 添加 Price 筛选后，Badge +1
- 添加任意筛选条件后，Filter Badge 数字递增

### 3.8 列表卡片展示规则

#### 卡片必须包含信息
| 信息项 | 说明 |
|-------|------|
| 主图 | 第一张图片或视频第一帧 |
| 价格 | 显示格式：$1,234（AUD，带千分位）/ "Contact for price" |
| 房产标题 | 完整标题，支持多行显示 |
| 房产类型 | 如 House、Apartment、Townhouse |
| 卧室数量 | 显示 bed 图标 + 数量（如"3 beds"） |
| 浴室数量 | 显示 bathroom 图标 + 数量（如"2 baths"） |
| 停车位数量 | 显示 parking 图标 + 数量（如"1 parking"），0个时不显示 |
| 面积 | 显示面积 + 单位（如"120 m²"），未填写时不显示 |
| 位置/邮编 | 显示地址或邮编 |
| 发布者信息 | 头像 + 名称 |
| 收藏按钮 | 心形图标（空心=未收藏，实心=已收藏） |

#### 图片轮播规则
- **单张图片**：只展示一张主图，无轮播控件
- **多张图片**：显示数量标识（如"1/3"），支持左右切换
- **切换方式**：点击左右箭头或滑动切换
- **点击图片**：跳转到详情页

#### 收藏功能规则
| 状态 | 操作 | 效果 |
|-----|------|------|
| 未登录 | 点击收藏图标 | 弹出登录框 |
| 已登录-未收藏 | 点击收藏图标（空心） | 图标变实心，显示"Added to favourites"提示 |
| 已登录-已收藏 | 点击收藏图标（实心） | 图标变空心，显示"Removed from favorites"提示 |
| 刷新页面 | - | 收藏状态保持 |

**收藏页验证**：
- 收藏后可在"Favourites"页面查看已收藏房产
- 取消收藏后，该房产从收藏页移除

#### 图片质量规则
- 每张卡片图片必须加载成功（naturalWidth > 0 且 complete = true）
- 每张卡片图片必须正确渲染（width > 0 且 visible = true）
- 允许失败率 < 50%（排除 UI 功能图标）

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|-------|---------|---------|---------|
| - | No results found | 筛选条件无匹配结果 | 未找到符合条件的房产，请调整筛选条件 |
| - | Invalid price range | Min > Max | 最低价格不能大于最高价格 |
| - | Invalid input | 输入非数字字符 | 请输入有效的数字 |
| - | Page not found | 页码超出范围 | 页面不存在 |
| - | Loading failed | 网络超时或服务异常 | 加载失败，请重试 |

| 规则项 | 规则内容 | 说明 |
