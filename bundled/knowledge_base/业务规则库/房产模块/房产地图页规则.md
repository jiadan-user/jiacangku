# 房产模块 - 房产地图页业务规则

## 1. 功能概述
- **功能描述**: 以地图形式展示房产位置，支持 Pin 点交互、卡片列表联动、筛选排序功能
- **用户角色**: 所有用户（游客、买家、卖家）
- **入口位置**: 列表页点击 Map 切换按钮 / URL 直接访问（含 view=map）
- **依赖模块**: 地图服务、搜索模块、筛选模块、分页模块

## 2. 核心流程
### 2.1 主流程
1. 从列表页点击 Map 按钮切换到地图视图
2. 页面加载：左侧卡片列表 + 右侧地图（含 Pin 点）
3. 使用筛选条件（价格、卧室、浴室、房产类型）
4. 选择排序方式（Best Match / Newest / Price）
5. 浏览地图 Pin 或卡片列表
6. 点击 Pin 或卡片查看详情
7. 切换回列表视图或翻页

### 2.2 异常流程
- 地图加载失败 → 显示"Map loading failed"
- 筛选条件无结果 → 显示空态，地图无 Pin
- Pin 点击无响应 → 重试或刷新页面
- 卡片列表加载失败 → 显示"Loading failed"

## 3. 业务规则
### 3.1 页面布局规则
| 区域 | 位置 | 内容 | 说明 |
|-----|------|------|------|
| 卡片列表区 | 左侧 | 房产卡片列表 | 可滚动，支持分页 |
| 地图区 | 右侧 | 地图 + Pin 点 | 显示房产位置 |
| 顶部 Bar | 顶部 | 搜索框、筛选、排序、视图切换 | 固定顶部 |
| 面包屑 | 顶部下方 | 导航路径 | 如 Home > Property for rent > Canberra |

**PC 端布局**：
- 左侧卡片列表宽度约 40%
- 右侧地图宽度约 60%
- 两区域同时显示

**M 端布局差异**：
- 全屏地图
- 底部卡片半屏上拉抽屉
- 抽屉内下拉无限滚动

### 3.2 卡片列表规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 卡片信息 | 主图、标题、价格、地址/位置 | 与列表页卡片一致 |
| 点击行为 | 新标签页打开详情页（PC）/ 当前页跳转（M端） | - |
| 分页方式 | 底部分页控件（PC）/ 无限滚动（M端） | - |
| 每页最大数量 | 24张卡片 | 地图模式限制 |
| 卡片数量约束 | 左侧卡片数量（当前页）≤ 结果徽标总数 | 分页展示 |
| 结果徽标格式 | `\d+ results`（如"33 results"） | 显示房源总数 |
| 第1页卡片数量 | 0 < 卡片数量 ≤ 24 | 满页时为24张 |
| 翻到第2页后 | 第2页卡片数量 > 0 且 ≤ 结果徽标总数 | 不满页时为最后一页 |
| 悬停效果 | 鼠标悬停卡片，对应地图 Pin 高亮（PC）/ 无悬停（M端） | PC端联动 |
| 离开卡片悬停 | Pin 恢复原始状态（PC） | - |

### 3.3 地图 Pin 规则

#### Pin 显示规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Pin 点总数 | Pin 点总数 = 结果徽标数字 | 一对一对应 |
| Pin 点数量验证 | `img[alt="bottom icon"]` 数量 + `img[alt="sale marker"]` 数量 = 结果徽标数字 | 实测：33 = 33 |
| Pin 点价格文字 | 所有 Pin 点均显示价格文字 | 如"132"、"5K+"、"100M+" |
| Rent 页面 Pin 颜色 | 橙色（PropertyMarker_rent class） | 租房 Pin 点 |
| Sale 页面 Pin 颜色 | 蓝色 | 买房 Pin 点 |
| Student 页面 Pin 颜色 | 橙色（学生公寓） | 需与 Rent 区分是否同色 |
| 地图缩放 Pin 数量 | 缩放后 Pin 点总数与 badge 保持一致（视口内房源不变） | 如 zoom 11→10，Pin 点 33→33 |
| 聚合 Pin | 多点聚合时显示圆形数字气泡 | 如"5+" |

#### Pin 交互规则
| 操作 | 效果 | 说明 |
|-----|------|------|
| 点击 Pin | Pin 进入选中态（颜色/大小变化） | 放大 + 颜色加深 |
| 点击 Pin | 弹出小卡片（PC）/ 底部抽屉升起（M端） | 含图片/标题/价格 |
| 点击 Pin 弹出卡片 | 点击卡片跳转详情页 | 新标签页（PC）/ 当前页（M端） |
| 点击另一个 Pin | 前一个 Pin 取消选中，新 Pin 选中 | 单选切换 |
| 点击聚合 Pin（cluster） | 地图放大展开 | 地图缩放到更细粒度 |
| 悬停 Pin | Pin 高亮（PC） | M端无悬停 |
| 点击地图空白区域 | 弹卡片关闭，Pin 取消选中 | 状态恢复 |

#### Pin 与卡片联动规则
| 操作 | 效果 | 说明 |
|-----|------|------|
| 鼠标悬停卡片 | 对应 Pin 高亮（颜色/尺寸变化） | PC端联动 |
| 离开卡片悬停 | Pin 恢复原始状态（取消高亮） | PC端 |
| 鼠标悬停地图 Pin | Pin 高亮显示 | PC端 |
| 点击地图 Pin | Pin 进入选中态 | 颜色/样式变化 |
| 点击 Pin | 弹出卡片信息浮层 | 显示小卡片 |
| 点击 Pin | 左侧卡片列表滚动到对应卡片 | 卡片滚动到可视区域（M端抽屉滚动） |
| 多次悬停不同卡片 | Pin 高亮切换 | 每次悬停高亮对应 Pin（PC端） |
| 分页同步 | 翻页后地图 Pin 同步更新为当前页房产 | Pin 数量变化 |

### 3.4 地图加载规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 地图容器渲染 | 地图容器（`.gm-style`）可见 | 无白屏/错误状态 |
| 结果数量徽标 | 显示"N results" | 如"33 results"，格式为`\d+ results` |
| Pin 点标记加载 | 地图上显示至少1个 Pin 点可见 | Pin 点位于地图区域内 |
| 地图控件加载 | 地图控件容器可见，含4个功能按钮 | 全屏、放大、缩小、定位 |
| URL 参数 | URL 包含 `view=map` 参数 | 地图模式标识 |
| 从列表视图切换 | 切换后地图正常加载渲染，URL 更新为含 `view=map` | 地图 Pin 点可见 |

### 3.5 地图搜索规则

#### 地图搜索类型
| 搜索类型 | URL参数 | 说明 |
|---------|---------|------|
| 普通关键词搜索 | q | 如 ?q=keyword |
| 联想地址搜索 | lat/lng 或 suglevel | 从联想下拉选择地址 |

#### 搜索交互规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 搜索框输入 | 输入关键词，搜索框显示清除按钮 | 可点击清空 |
| 联想触发 | 输入2个以上字符，联想下拉出现 | 显示匹配地址（如 Canberra, ACT） |
| 选择联想地址 | URL 含坐标参数（lat/lng 或 suglevel） | 地图自动定位到该区域 |
| 联想搜索 vs 普通搜索 | 联想地址 URL 含坐标/suglevel；普通搜索含 q 参数 | URL 参数不同 |
| 清除搜索 | 点击清除按钮，搜索框清空，联想面板关闭 | - |
| 搜索无结果 | 列表显示空态（"No results"），地图无 Pin，页面不崩溃 | M端空态提示位置在底部抽屉区域 |
| 搜索历史 | 点击搜索框显示历史下拉，历史中显示完整联想地址名 | 历史持久化（localStorage/Cookie） |
| 清空搜索后点击搜索框 | 历史下拉重新出现 | - |
| 刷新页面 | 搜索历史仍存在 | 持久化存储 |
| 中文关键词搜索 | 页面正常（可能无结果），不崩溃不报错 | 健壮性 |
| 联想搜索 URL 含城市级别参数 | 选择城市级别联想地址（如"Canberra, ACT"），URL 含 city 或 district 级别坐标参数 | - |

### 3.6 地图排序规则
| 排序选项 | URL参数 | sort_id值 | 说明 |
|---------|---------|-----------|------|
| Best Match（默认） | 无 sort_id | - | 默认态 |
| Newest First | sort_id | 1 | 卡片按最新排列 |
| Lowest Price | sort_id | 3 | 卡片按低价排列 |
| Highest Price | sort_id | 4 | 卡片按高价排列 |

**排序规则**：
- 排序后切换到 List 视图，sort_id 保留（视图切换不丢排序）
- 打开 Sort 面板不选择，点 Done，URL 不变（排序状态不变）
- 重新选回 Best Match，URL 中 sort_id 消失（恢复默认）
- M端 Sort 面板为底部 ActionSheet，选项与 PC 一致

### 3.7 地图筛选规则

#### 价格筛选
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 输入有效 Min/Max | URL 含价格参数，卡片+Pin 更新 | 筛选生效 |
| 只填 Min | URL 含 lowestPrice，无 highestPrice | 单边筛选 |
| 只填 Max | URL 含 highestPrice，无 lowestPrice | 单边筛选 |
| Min > Max | 系统优雅处理（不崩溃） | 提示或拦截 |
| 输入负数 Min | 系统拒绝 | 清空或报错 |
| 输入非数字 Min | 系统拒绝 | 清空或报错 |
| 输入超大值 | 页面不崩溃 | 正常提交 |
| 清除价格筛选 | URL 中价格参数消失，Pin 恢复全量 | 恢复全量 |

**M端备注**：M端价格 Filter 在底部 Sheet 中，输入框需注意软键盘遮挡

| 选择 Beds=8+ | URL 含最大值 | 边界值 |

| 快速连续点击 Beds 选项 | 最后一次生效 | 防抖 |

**M端备注**：M端 Beds 在 Filter Sheet 中以 Chip 形式展示，触摸选择后点 Done 提交

| 选择 Apartment | URL 路径含 apartment | - |

| Filter 面板选 Beds + Bathrooms Done | URL 含两参数 | 组合参数正确 |

**M端备注**：M端 Property Type 选择器为底部弹窗；TC-MAP-057 在 M 端 Filter Sheet 中，所有筛选区在一个可滚动的 Sheet 内

### 3.8 多条件组合筛选规则
| 组合场景 | URL 参数 | 说明 |
|----------|----------|------|
| Sort（最低价格）+ Price 区间 | sort_id + lowestPrice/highestPrice | 两参数共存 |
| Price 区间 + Beds=2 | lowestPrice/highestPrice + attr_168 | 两参数共存 |
| Beds=2 + Bathrooms=1 | attr_168 + attr_166 | 两参数共存 |
| Sort + Beds + Price（三合一） | sort_id + attr_168 + lowestPrice/highestPrice | 三参数共存 |
| Sort + Price | sort_id + lowestPrice/highestPrice | 两参数共存 |
| 全部五种筛选条件 | sort_id + lowestPrice/highestPrice + attr_168 + attr_166 + 路径类型 | 五参数共存 |
| 清除 Beds | 只移除 attr_168，其余保留 | 其他条件不变 |
| 组合筛选无结果 | 卡片空态 + 地图无 Pin | 显示空态 |

**M端备注**：M端所有组合筛选在同一 Filter Sheet 中完成，点 Done 后 URL 一次性更新所有参数

### 3.9 地图交互控件规则

#### 地图放大（Zoom In）
| 操作 | 效果 | URL变化 | Analytics事件 |
|-----|------|---------|--------------|
| 点击 + 按钮一次 | 地图缩放级别 +1 | viewport `z:11` → `z:12` | map_zoom_in |
| 连续点击 + 按钮 | 缩放级别累积增加 | 每次 +1 | 每次触发 map_zoom_in |
| 达到最大缩放级别 | + 按钮变为 disabled | URL 不再变化 | 不触发事件 |

**最大缩放级别**：Google Maps 最大 zoom 为 22

#### 地图缩小（Zoom Out）
| 操作 | 效果 | URL变化 | Analytics事件 |
|-----|------|---------|--------------|
| 点击 − 按钮一次 | 地图缩放级别 -1 | viewport `z:12` → `z:11` | map_zoom_out |
| 连续点击 − 按钮 | 缩放级别累积减少 | 每次 -1 | 每次触发 map_zoom_out |
| 达到最小缩放级别 | − 按钮变为 disabled | URL 不再变化 | 不触发事件 |
| 缩小后标记聚合 | 多个标记聚合为气泡（如"N+"） | zoom 参数更新 | - |

#### 地图拖动（Pan/Drag）
| 操作 | 效果 | URL变化 | 说明 |
|-----|------|---------|------|
| 向右拖动 | 地图向西移动，经度（lng）增大 | viewport `c:lat,lng` 更新 | 原中心地标移向左侧 |
| 向上拖动 | 地图向南移动，纬度（lat）增大 | viewport `c:lat,lng` 更新 | 原中心地标移向下侧 |
| 拖动后 | 结果数量随视野变化更新 | - | "Searching..." 过渡状态 |

**拖动限制**：
- 拖动操作在无 PropertyMarker 遮挡的空白区域有效
- 拖动不自动触发搜索（"Search this area" 按钮需手动点击）

#### 地图定位（Locate/Compass）
| 场景 | 操作 | 效果 | 说明 |
|-----|------|------|------|
| 未授予地理位置权限 | 点击定位按钮 | 浏览器弹出权限请求弹窗 | 定位按钮呈 active 状态 |
| 已授予地理位置权限 | 点击定位按钮 | 地图跳转至当前位置，URL 更新 | 显示蓝色圆点标记 |
| 拒绝地理位置权限 | 点击定位按钮 | 地图位置不变，URL 不更新 | 可能显示"Location access denied"提示 |

#### 地图全屏（Fullscreen）
| 操作 | 效果 | URL变化 | Analytics事件 |
|-----|------|---------|--------------|
| 点击全屏按钮 | 左侧列表隐藏，地图占据全宽 | URL 不变 | map_fullscreen |

| 全屏模式下按 Esc | 退出全屏，恢复分屏布局 | URL 不变 | - |

**全屏提示**：
- 全屏模式下右上角显示提示："Exit full screen by pressing [esc]"

#### 放大/缩小与拖动联动
- 放大后拖动地图，坐标更新，结果数量刷新
- 缩小后地图标记聚合，显示更大范围区域
- 页面刷新后，URL 中的 zoom 级别和坐标被正确恢复

#### URL viewport 参数规则
| 参数 | 格式 | 说明 | 示例 |
|-----|------|------|------|
| c | `c:lat,lng` | 地图中心坐标（纬度,经度） | `c:-35.2802,149.1310` |
| z | `z:level` | 缩放级别（1-22） | `z:11` |
| 完整格式 | `viewport=c:lat,lng\|z:level` | URL编码后 | `viewport=c%3A-35.2802%2C149.1310%7Cz%3A11` |

**同步规则**：
- 地图操作（放大/缩小/拖动）实时更新 URL viewport 参数
- Google Maps 链接中的 `z=` 参数同步更新
- 页面刷新后，根据 URL viewport 参数恢复地图状态
