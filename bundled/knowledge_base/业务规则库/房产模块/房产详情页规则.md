# 房产模块 - 房产详情页业务规则

## 1. 功能概述
- **功能描述**: 展示单个房产的完整信息，包括图片、价格、描述、位置、联系方式等，支持收藏、分享、编辑、下架操作
- **用户角色**: 所有用户（游客、买家、卖家、发布者）
- **入口位置**: 列表页卡片点击 / 地图 Pin 点击 / 搜索结果 / 直接 URL 访问
- **依赖模块**: 用户登录模块、收藏模块、分享模块、地图模块、推荐模块

## 2. 核心流程
### 2.1 主流程
1. 从列表页或地图页点击房产卡片/Pin
2. 进入房产详情页
3. 浏览房产信息（图片、价格、描述、位置）
4. 可选操作：收藏、分享、查看地图、查看推荐
5. 发布者可进行编辑或下架操作
6. 点击面包屑或推荐卡片跳转到其他页面

### 2.2 异常流程
- 房源不存在 → 显示 404 或"房源不存在"友好提示
- 未登录点击收藏 → 弹出登录框
- 非发布者尝试编辑/下架 → 无按钮显示（权限控制）
- 地图加载失败 → 显示"Map loading failed"
- 网络超时 → 显示"Loading failed"

## 3. 业务规则
### 3.1 页面展示规则
| 信息项 | 必填 | 说明 |
|-------|-----|------|
| 房产主图 | 是 | 轮播图，支持左右切换 |
| 价格 | 是 | 显示格式：$1,234（AUD）/ "Contact for price" |
| 房产标题 | 是 | 完整标题 |
| 房产类型 | 是 | 如 House、Apartment、Townhouse、Other |
| 发布时间标签 | 是 | 如"ADDED 1 MONTH AGO" |
| 分类标签 | 是 | 如"For rent"、"For sale" |
| 卧室数量 | 否 | 显示图标 + 数量（如"3 beds"） |
| 浴室数量 | 否 | 显示图标 + 数量（如"2 baths"） |
| 停车位数量 | 否 | 显示图标 + 数量（如"1 parking"） |
| 面积 | 否 | 显示面积 + 单位（如"120 m²"） |
| Property Introduction | 否 | 房源描述区块 |
| 地址 | 是 | 显示地址 + "Show map" 按钮 |
| 收藏按钮 | 是 | 心形图标（空心=未收藏，实心=已收藏） |
| 分享按钮 | 是 | Share 按钮 |
| 发布者信息 | 是 | 头像 + 名称 |
| 面包屑导航 | 是 | 如 Home > Property > Commercial Property for rent > Other |
| 推荐区域 | 否 | "You may also like" 推荐轮播 |

### 3.2 收藏功能规则
| 状态 | 操作 | 效果 |
|-----|------|------|
| 未登录 | 点击收藏图标 | 弹出登录框 |
| 已登录-未收藏 | 点击收藏图标（空心） | 图标变实心，显示"Added to favourites"提示 |
| 已登录-已收藏 | 点击收藏图标（实心） | 图标变空心，显示"Removed from favorites"提示 |
| 刷新页面 | - | 收藏状态保持 |
| 快速连续点击 | 点击3次 | 仅触发一次有效请求（防重复提交） |

**收藏页验证**：
- 收藏后可在"Favourites"页面查看已收藏房产
- 取消收藏后，该房产从收藏页移除

### 3.3 分享功能规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Share 按钮 | 点击 Share 按钮弹出分享面板 | 分享面板包含多个分享渠道 |
| 分享渠道 | Facebook/Twitter/WhatsApp/Email/Copy Link | 支持多种分享方式 |
| 点击分享渠道 | 触发对应分享行为 | 如 Copy Link 复制链接到剪贴板 |
| 页面 URL | 分享时页面 URL 保持不变 | 不导致页面异常跳转 |
| 浏览器原生分享 | 支持浏览器原生分享能力 | 依赖浏览器/设备 |

### 3.4 地图弹窗规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Show Map 按钮 | 点击弹出地图弹窗（dialog） | 地图弹窗显示 |
| 地图弹窗内容 | 展示地图区域及房源位置标记 | 当前房源位置 |
| 关闭方式1 | 点击 Close 按钮关闭地图弹窗 | 弹窗关闭 |
| 关闭方式2 | 按 ESC 键关闭弹窗 | 弹窗关闭 |
| 关闭方式3 | 点击蒙层区域关闭弹窗（如支持） | 弹窗关闭 |
| 地图加载 | 弹窗打开后地图正常加载 | 显示地图和标记 |

### 3.5 面包屑导航规则
| 层级 | 点击行为 | 目标页面 | 说明 |
|-----|---------|---------|------|
| Home | 跳转首页 | https://au.58v5.cn/en/city-{city}/ | 首页正确 |
| Property | 跳转 Property 分类列表 | Property 列表页 | - |
| 二级分类 | 跳转对应分类列表 | 如 Commercial Property for rent 列表页 | - |
| 三级分类 | 跳转对应子分类列表 | 如 Other 子分类列表页 | - |
| 当前页 | 不可点击 | - | 当前层面包屑为不可点击态 |

**面包屑路径正确性**：
- 面包屑路径正确（Home > 分类 > 当前页）
- 点击面包屑各层级跳转正确

### 3.6 推荐轮播规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 推荐区域 | "You may also like"区域展示推荐房源卡片 | 推荐轮播 |
| 左箭头初始状态 | 第一页时左箭头为 disabled 状态 | 不可点击 |
| 右箭头可点击 | 第一页时右箭头可点击 | 可切换到下一组 |
| 点击右箭头 | 轮播切换到下一组推荐 | 轮播内容切换 |
| 点击左箭头 | 轮播切换到上一组推荐 | 左箭头变为可点击态（若有多页） |
| 点击推荐卡片 | 跳转到对应房源详情页 | 新标签页或当前页 |

### 3.7 顶部搜索规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 搜索框输入 | 在"Search for anything"输入关键词 | 输入框可正常填写 |
| 点击 Search | 跳转至搜索结果页 | 结果页展示与关键词相关的房源 |
| 输入空内容点击 Search | 不跳转或跳转至默认列表页 | 无异常报错 |

### 3.8 地址链接规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 地址链接 | 点击地址链接跳转到地图搜索该地址的列表页 | 地址为可点击链接 |
| 跳转目标 | 列表页，URL 含该地址的搜索参数 | 如 suglevel 参数 |

### 3.9 权限规则
| 用户角色 | 可见操作 | 说明 |
|---------|---------|------|
| 游客（未登录） | 浏览、搜索 | 不展示 Withdraw、Edit 按钮，可能展示登录/注册入口 |
| 已登录买家 | 浏览、搜索、收藏、分享 | 不展示 Withdraw、Edit 按钮 |
| 已登录卖家（非发布者） | 浏览、搜索、收藏、分享 | 不展示 Withdraw、Edit 按钮 |
| 房源发布者 | 所有操作 + Withdraw + Edit | 可下架或编辑自己的房源 |

### 3.10 危险操作规则

#### Withdraw（下架）
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Withdraw 按钮可见性 | 仅发布者可见 Withdraw 按钮 | 权限控制 |
| 点击 Withdraw | 出现二次确认弹窗或提示 | 防误操作 |
| 确认下架 | 确认后房源下架，或进入下架流程 | 房源状态变更 |
| 取消下架 | 点击取消/关闭，房源保持在线状态 | 弹窗关闭 |

#### Edit（编辑）
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Edit 按钮可见性 | 仅发布者可见 Edit 按钮 | 权限控制 |
| 点击 Edit | 跳转至编辑页或打开编辑弹窗 | 按钮存在且可点击 |
| 编辑权限 | 可修改房源信息 | 所有字段都可以编辑 |

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|-------|---------|---------|---------|
| - | Property not found | 访问无效房源 ID | 房源不存在或已下架 |
| - | Added to favourites | 收藏成功 | Added to favourites |
| - | Removed from favorites | 取消收藏成功 | Removed from favorites |
| - | Login required | 未登录点击收藏 | 请先登录 |
| - | Map loading failed | 地图加载失败 | 地图加载失败，请稍后重试 |
| - | Loading failed | 网络超时或服务异常 | 加载失败，请重试 |
