# 房产发布规则

## 1. 功能概述
- **功能描述**: 房产发布功能，支持租房/买房/学生公寓/商业地产发布，包含图片/视频/户型图上传、分类选择、房产信息填写、价格与联系方式、AI辅助生成等
- **用户角色**: 卖家/房东/经纪人
- **入口位置**: 首页Post按钮 → 二级分类选择 → 三级分类选择 → 发布表单
- **依赖模块**: 图片上传服务、AI识图服务、AI文案生成服务、地图服务、草稿箱

## 2. 核心流程
### 2.1 主流程
1. 用户点击首页Post入口
2. 选择二级分类（Property for rent/sale/Student Apartment/Commercial rent/sale）
3. 选择三级分类（House/Apartment/Unit等）
4. 上传图片/视频/户型图（AI自动识别分类和房间信息）
5. 填写房产信息（出租类型/卧室/浴室/楼层/面积/停车位等）
6. 填写价格与联系方式（价格/手机号/WhatsApp）
7. 填写房产介绍与亮点（支持AI生成）
8. 填写地址与地图定位
9. 点击Post发布或Save Draft存草稿

### 2.2 异常流程
- 场景1: 未登录点击Post → 跳转登录页，登录成功后返回发布页
- 场景2: 图片上传失败 → 显示错误提示，允许重新上传
- 场景3: 必填项未填写 → 提交失败，高亮显示未填写字段
- 场景4: AI识图失败 → 按默认值显示，用户可手动修改
- 场景5: 草稿保存失败 → Toast提示"保存失败，请稍后重试"

## 3. 业务规则
### 3.1 发布入口与分类规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 发布入口 | 首页Post按钮 → 二级分类列表 | 显示Property for rent/sale/Student/Commercial |
| 二级分类选择 | 点击二级分类后仅显示对应三级分类 | 租房只显示租房下属类型 |
| 三级分类选择 | 选中三级分类后显示对应房产信息区（Property Info） | 学生公寓无此限制，进入即显示全部 |
| 顶部标题 | 根据二级类型动态显示 | 如"Property for rent Post" |
| 分类切换 | 同二级下切换保留已填内容，跨二级清空 | 避免数据错乱 |

### 3.2 图片/视频/户型图上传规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 图片+视频总数上限 | ≤20个 | 图片+视频共享上限 |
| 视频数量上限 | ≤1个 | 仅允许上传1个视频 |
| 视频大小上限 | ≤200MB | 超过200MB拒绝上传 |
| 户型图数量上限 | ≤10张 | 独立入口，不计入图片+视频总数 |
| 户型图入口 | 住宅/学生公寓有户型图入口，商业地产无 | 根据房产类型显示 |
| 主图逻辑 | 第一张图片/视频第一帧为主图 | 删除主图后下一张自动成为主图 |
| 图片排序 | 支持拖拽排序，第一张为主图 | 移到第一张位置的成为新主图 |
| 图片预览 | 点击图片/视频/户型图可预览 | 图片画廊/视频播放/户型图画廊 |
| 详情页展示顺序 | video → picture → floor plan | 不按用户上传顺序，按类型重新排序 |
| 未上传图片提交 | 提示"Please add property photos (not floor plans)" | 发布被阻止 |
| AI识图 | 上传图片后AI自动识别分类（前4张） | 识别完成前显示loading |
| 户型图AI识别 | 上传户型图后AI识别卧室/浴室数量 | 识别失败时保持默认值 |

### 3.3 房产信息字段规则
| 字段 | 类型 | 必填 | 取值范围 | 格式 | 默认值 | 说明 |
|------|------|------|----------|------|--------|------|
| 出租类型 | 单选 | 是（住宅租） | Entire unit, Shared unit | 枚举 | - | 选Shared unit后厨房/浴室自动默认Shared |
| 卧室数量 | 单选 | 是（住宅买租） | Studio, 1-8+ | 枚举 | - | 单位：bed(s) |
| 浴室数量 | 单选 | 是（住宅买租） | Shared, 1, 1.5, 2, 2.5, 3, 3.5, 4, 4.5, 5, 5+ | 枚举 | - | 单位：bath(s)，含半间 |
| 楼层 | 输入框+开关 | 否 | -10~200 | 整数 | 0 | Single floor单层/Multi Level多层 |
| 面积 | 输入框+开关 | 是 | sqft:100-120000, m²:10-11000 | 整数 | 0 | 住宅单值/商业学生公寓Single↔Range |
| 停车位 | 单选 | 是（商业/学生公寓），否（住宅租） | no car space, 1-10+ | 枚举 | - | 单位：car space(s) |
| 室内设施 | 多选 | 否 | 参考房产特征sheet | 枚举 | - | Unit features |
| 配套设施 | 多选 | 否 | 参考房产特征sheet | 枚举 | - | Amenities |
| 房产服务 | 多选 | 否 | 参考房产特征sheet | 枚举 | - | Property services |

### 3.4 价格与联系方式规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 租房价格单位 | Per Week/Month/Quarter/Year | 默认Per Week |
| 买房价格公开 | Price available/Contact for price | 选Contact for price后价格输入框隐藏 |
| Contact for price | 不出现在价格筛选结果中 | C端筛选时不显示 |
| 价格数值 | 2位小数 | PC底纹词是0.00 |
| 手机号反显 | 手机号注册账号自动反显，历史发帖手机号下次自动反显 | 无需手动输入 |
| 手机号格式校验 | 无效格式被拒绝 | 提交时报错 |
| 区号选择 | 支持同一站点多国家区号可选 | 如中东站点支持沙特和阿联酋2个区号 |
| WhatsApp | 勾选"Use my phone number"后自动带入手机号且不可编辑 | 仅中东站 |
| 学生公寓价格 | 不在价格&联系方式模块填写 | 价格在Step 03 Rent & Availability中填写 |

### 3.5 房产介绍与亮点规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 房产介绍 | 必填，字符上限10000 | 占位符："Please describe your property..." |
| 标题 | 非必填，字符上限200 | 占位符："e.g. Modern 2BR apartment..." |
| 亮点概述 | 非必填，字符上限50（AI生成上限） | Highlights overview |
| 亮点内容 | 非必填，字符上限200 | Highlights content |
| 亮点模块 | 对全部发布类型展示 | 住宅买租/商业地产/学生公寓均展示 |

### 3.6 AI描述与亮点生成规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| AI帮我写 | 初始状态显示"AI helps you write"按钮 | 输入框为空且可点击 |
| AI生成中 | 按钮变为"AI is assisting you in writing..." | 输入框不可点击（置灰） |
| AI生成完成 | 按钮变为"AI helps you rewrite"，显示撤销按钮 | 输入框可点击，描述内容已填充 |
| 用户手动编辑 | 按钮变为"AI polishing" | 输入框仍可继续编辑 |
| 用户清空描述 | 按钮切换回"AI helps you write" | 点击后重新生成一版介绍 |
| 撤销按钮 | 逐步还原内容，持续撤销直到输入框为空 | 撤销按钮消失或置灰 |
| AI生成次数上限 | 最多5次 | 第6次及以后从之前5次内容中循环显示 |
| AI生成标题 | 一句话概括房产信息 | 支持AI生成和用户自己写 |
| AI生成亮点 | 自动生成3条亮点 | 每条包含标题（Label）和内容（Description） |
| 删除亮点 | 二次确认弹窗，删除后显示"重新生成亮点"按钮 | 最多3条 |
| 换一换按钮 | 重新生成该条亮点内容 | 若无更多可替换内容，按钮不显示 |

### 3.7 地址与地图规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 详细地址 | 必填，输入触发sug词联想 | 选择sug后自动补全完整地址 |
| 地图拖拽 | 地图上点击或拖拽定位点，地址自动反显 | 建筑名称如可识别也自动填入 |
| 建筑名称 | 学生公寓类型展示且必填 | 输入触发sug词联想 |

### 3.8 草稿规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 未填写内容存草稿 | 提示"无内容，无法保存草稿" | 草稿箱中不新增记录 |
| 填写内容后存草稿 | 显示存草稿成功提示 | 草稿箱中出现该条草稿记录 |
| 编辑草稿后再次存草稿 | 草稿箱中该条草稿被更新 | 不新增额外草稿条目 |
| 发布成功后草稿 | 草稿自动从草稿箱消失 | 已发布帖子可在个人帖子列表查看 |
| 草稿箱为空 | 显示空状态提示文案 | 不显示异常或报错 |
| 草稿数量上限 | 发帖+草稿总数≤2.5w | 不限制草稿数量，不区分业务 |

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| 1001 | 图片上传失败 | 图片大小超限或格式不支持 | 请上传有效的JPG/PNG图片（<10MB） |
| 1002 | 视频上传失败 | 视频大小超过200MB | 视频大小不能超过200MB |
| 1003 | 图片+视频超过20个 | 上传第21个媒体文件 | You can upload up to 20 images only. |
| 1004 | 视频超过1个 | 尝试上传第2个视频 | 仅允许上传1个视频 |
| 1005 | 户型图超过10张 | 上传第11张户型图 | 户型图最多10张 |
| 1006 | 未上传图片 | 不上传任何图片尝试提交 | Please add property photos (not floor plans). |
| 1007 | 必填项未填写 | 提交时必填项为空 | 请填写所有必填项 |
| 1008 | 楼层超出范围 | 输入楼层<-10或>200 | 楼层需在-10到200之间 |
| 1009 | 面积超出范围 | sqft<100或>120000 | 面积需在100-120,000平方英尺之间 |
| 1010 | 手机号格式错误 | 输入无效手机号 | 请输入有效的手机号码 |
| 1011 | 介绍超过字符上限 | 输入>10000字符 | 介绍最多10000字符 |
| 1012 | 标题超过字符上限 | 输入>200字符 | 标题最多200字符 |

## 5. 已知问题
- 问题1: AI识图在弱光环境下识别准确率低 → 优化AI模型
- 问题2: 草稿保存偶尔失败，需重试 → 增加自动重试机制
- 问题3: 地图定位在部分地区不准确 → 优化地图服务
- 问题4: PC端发布入口点击Property后直接进发布表单，无二级分类选择页 → 需确认PC端交互逻辑
