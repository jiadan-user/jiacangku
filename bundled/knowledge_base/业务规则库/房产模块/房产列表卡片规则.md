# 房产列表卡片规则

## 1. 功能概述
- **功能描述**: 房产列表页卡片展示规则，包含卡片布局、图片展示、价格、标题、位置、房产类型、房间信息、图标数量、收藏功能等
- **用户角色**: 买家/租客/游客
- **入口位置**: 房产列表页（租房/买房/学生公寓/商业地产）
- **依赖模块**: 房产列表页、房产详情页、收藏模块、图片服务

## 2. 核心流程
### 2.1 主流程
1. 用户访问房产列表页
2. 系统加载房产列表数据
3. 按照卡片布局规则展示房产卡片（一行4个，PC端）
4. 每张卡片展示：图片、价格、标题、位置、房产类型、房间信息、Bed/Bath/Parking图标数量、面积、头像和名称
5. 用户可点击卡片任意区域进入详情页
6. 用户可点击收藏图标收藏/取消收藏房产

### 2.2 异常流程
- 场景1: 图片加载失败 → 显示占位图或默认图，不影响其他内容展示
- 场景2: 价格为空 → 显示"Contact for price"或特殊提示文案
- 场景3: 房产类型为空 → 显示默认类型或占位文案
- 场景4: 未登录点击收藏 → 弹出登录弹窗，登录成功后自动收藏

## 3. 业务规则
### 3.1 卡片布局规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| PC端布局 | 一行展示4个卡片 | 网格布局，每行4列 |
| M端布局 | 单列展示，支持无限滚动 | 移动端适配 |
| 卡片排列 | 按照排序规则排列（默认Best Match） | 支持用户自定义排序 |
| 分页 | PC端支持页码翻页，M端支持下拉加载更多 | 每页最多24张卡片（地图模式） |

### 3.2 图片展示规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 单张图片 | 只展示一张主图，无轮播控件 | 无"多图"数量标识 |
| 多张图片 | 显示数量标识（如"1/3"），支持左右切换 | 轮播功能 |
| 图片质量 | 图片加载成功且正确渲染（naturalWidth>0, visible=true） | 失败率<50% |
| 图片点击 | 点击图片进入详情页 | 新标签页打开 |
| 兜底图 | 无图片时显示占位图 | 不出现空白或裂图 |

### 3.3 价格展示规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 租房价格格式 | A$XXX/week 或 A$XXX per week | 包含货币符号、数字、周期单位 |
| 买房价格格式 | A$XXX | 包含货币符号、数字 |
| Contact for price | 显示"Contact for price"文案 | 不出现在价格筛选结果中 |
| 价格一致性 | 列表页价格与详情页价格一致 | 数值和单位相同 |

### 3.4 房产类型规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 住宅类型枚举 | House, Apartment, Townhouse, Unit, Villa, Retirement, Studio, Land, Rural | 租房/买房 |
| 学生公寓类型枚举 | Student Apartment, Studio, 1–3 Bedroom Apartment | 学生公寓 |
| 商业地产类型枚举 | Office, Retail, Industrial, Medical, Hotel/Leisure, Commercial Farming | 商业地产 |
| 类型一致性 | 列表页房产类型与详情页一致 | 文案相同或语义一致 |
| 类型可读性 | 文案清晰可读，长度<100字符 | 无乱码或异常值 |

### 3.5 Bed/Bath/Parking图标数量规则
| 图标类型 | 取值范围 | 格式 | 说明 |
|----------|----------|------|------|
| Bed（卧室） | Studio, 1-8+ | 整数/数字+号/描述型文字 | Studio为特殊房型 |
| Bath（浴室） | Shared, 1-5+ | 整数/小数（含0.5半间）/数字+号/描述型文字 | Shared为共享浴室 |
| Parking（停车位） | 0-10+ | 整数/数字+号 | 0表示无停车位 |
| 图标可见性 | 图标尺寸>0，在视口内可见 | 无遮挡 |
| 数量一致性 | 列表页数量与详情页一致 | 取详情页MainInfo区数量 |

### 3.6 位置邮编规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 位置展示 | 显示suburb/postcode信息 | 每张卡片均展示 |
| 邮编格式 | 澳大利亚邮编为4位数字（如2600） | 符合AU规范 |
| 位置一致性 | 列表页位置与详情页位置一致 | suburb/postcode相同 |
| 位置可读性 | 文案清晰可读，无遮挡 | 字体大小适中 |

### 3.7 房产标题规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 标题展示 | 每张卡片均展示房产标题 | 标题文案可见 |
| 标题非空 | 标题非空、非纯空格 | 为可读文本 |
| 标题一致性 | 列表页标题与详情页Property Introduction副标题一致 | 同一套房源 |
| 标题长度 | 长度在1-200字符范围内 | 无截断异常或乱码 |
| 标题点击 | 点击标题进入详情页 | 当前页或新标签 |

### 3.8 房间型号规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 房间型号展示 | 学生公寓列表卡片展示房间型号 | 位于Bed/Bath图标行之后 |
| 房间型号取值 | Studio, 1–3 Bedroom Apartment, Student Apartment | 非空英文字符串，长度1-100字符 |
| 房间型号一致性 | 列表页房间型号与详情页MainInfo区一致 | 文案相同 |
| 房间型号可见性 | 文本在视口内可见，元素尺寸>0 | 无遮挡 |

### 3.9 面积规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 面积展示 | 买房列表卡片展示面积，租房列表不展示 | 仅买房列表 |
| 面积格式 | XX sqm, XX m², XX sq ft | 包含数字和单位 |
| 面积一致性 | 列表页面积与详情页面积一致 | 数值和单位相同 |
| 面积可读性 | 文案清晰可读，无遮挡 | 字体大小适中 |

### 3.10 头像和名称规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 头像展示 | 每张卡片展示头像区域 | 经纪人/发布者头像或占位图 |
| 名称展示 | 每张卡片展示名称 | 经纪人姓名或发布者名称 |
| 头像名称关联 | 头像与名称在同一卡片内关联展示 | 同一行或相邻区域 |
| 无头像兜底 | 无头像时展示兜底头像 | 默认灰色/白色小人图标 |
| 头像名称点击 | 点击头像或名称进入详情页 | 当前页或新标签页 |

### 3.11 收藏功能规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 未登录收藏 | 点击收藏图标弹出登录弹窗 | 含邮箱输入框、Continue等 |
| 已登录收藏 | 点击收藏图标收藏成功，图标变为实心 | Toast提示"Added to favourites" |
| 取消收藏 | 点击已收藏图标取消收藏，图标变为空心 | Toast提示"Removed from favorites" |
| 收藏状态持久化 | 刷新页面后收藏状态保持 | 图标仍为已收藏状态 |
| 收藏页验证 | 收藏后进入收藏页可查看该卡片，取消收藏后该卡片不在收藏列表 | 通过标题匹配验证 |

### 3.12 卡片排列翻页规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 一行卡片数 | PC端一行展示4个卡片 | 网格布局 |
| 分页Next按钮 | 有多页时Next按钮可见，点击后URL更新page参数 | 最后一页Next禁用 |
| 分页页码 | 点击页码2进入第二页，列表保持一行4个卡片 | 页码点击跳转 |
| 视图切换 | 点击Map切换到地图视图，点击List切换回列表视图 | URL含view=map参数 |
| M端无限滚动 | M端支持下拉加载更多，替代页码翻页 | 滑到底部加载下一批 |

## 4. 错误处理
| 错误场景 | 触发条件 | 用户提示 |
|----------|----------|----------|
| 图片加载失败 | 图片URL无效或网络错误 | 显示占位图，不影响其他内容 |
| 价格为空 | 后端未返回价格数据 | 显示"Contact for price" |
| 房产类型为空 | 后端未返回房产类型数据 | 显示默认类型或占位文案 |
| 未登录收藏 | 用户未登录点击收藏 | 弹出登录弹窗 |
| 收藏失败 | 收藏接口调用失败 | Toast提示"收藏失败，请稍后重试" |

## 5. 已知问题
- 问题1: 部分卡片图片加载慢，影响用户体验 → 优化图片CDN加速
- 问题2: M端卡片排列在横屏模式下布局异常 → 需适配横屏布局
- 问题3: 收藏状态在多标签页间不同步 → 需增加实时同步机制
