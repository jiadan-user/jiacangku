# 地区选择页规则

## 1. 功能概述
- **业务价值**: 地区选择页是OK.com全球站点的流量分发入口,引导用户进入目标国家/地区站点,是跨国业务的核心枢纽
- **用户角色**: 访客(无需登录)
- **入口位置**: https://www.ok.com/biz/en/site
- **依赖模块**: 各国家/地区站点

## 2. 核心流程

### 2.1 页面访问流程
1. 用户访问全球站点入口 https://www.ok.com/biz/en/site
2. 页面加载并展示22个国家/地区选项
3. 用户选择目标国家/地区
4. 页面跳转到对应国家站点首页

## 3. 业务规则

### 3.1 页面标题规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 主标题 | "Please select the country and region you would like to browse." | 引导用户选择 |
| 副标题 | "Explore your community below" | 位于主标题下方 |
| 文案对齐 | 居中显示 | 主副标题均居中 |
| Logo | OK.com Logo居中显示 | 位于主标题上方,彩色图标(红/绿/橙/蓝) |

### 3.2 国家/地区列表规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 总数量 | 22个国家/地区 | 固定数量 |
| 显示格式 | 国旗图标+国家名称 | 国旗在左,名称在右 |
| 排列方式 | 网格布局 | 桌面端约6列,移动端自适应 |
| 间距规则 | 水平和垂直间距均匀 | 保持整齐 |

### 3.3 国家名称多语言规则

| 语言类型 | 显示规则 | 示例 |
|----------|----------|------|
| 阿拉伯语 | RTL(从右到左) | 阿联酋:الإمارات العربية المتحدة、沙特:المملكة العربية السعودية |
| 中文 | LTR(从左到右) | 香港:香港 |
| 英语 | LTR(从左到右) | United States、Canada、Australia |
| 葡萄牙语/西班牙语 | LTR(从左到右),支持特殊字符 | Brasil、España、México、Perú |

### 3.4 链接URL格式规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| URL格式 | https://[国家代码].ok.com/ | 标准格式 |
| 国家代码 | 两位ISO国家代码 | 如us/ae/hk/br |
| 跳转目标 | 对应国家站点首页(含默认城市) | 如美国跳转到华盛顿站 |

### 3.5 核心跳转规则

| 国家/地区 | 链接URL | 跳转目标URL | 目标城市 |
|-----------|---------|-------------|----------|
| United States | https://us.ok.com | https://us.ok.com/en/city-washington1/ | Washington |
| 阿联酋 | https://ae.ok.com | https://ae.ok.com/en/city-abu-dhabi/ | Abu Dhabi |
| 香港 | https://hk.ok.com | https://hk.ok.com(带默认城市) | - |
| Brasil | https://br.ok.com | https://br.ok.com | - |

### 3.6 交互反馈规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 鼠标悬停 | cursor: pointer | 手型指针 |
| 视觉反馈 | 无明显变化 | 无背景色变化/阴影/缩放 |
| 点击响应 | 立即跳转 | 无延迟或加载动画 |
| 重复点击 | 允许多次点击 | 每次均正常跳转 |
| 快速连续点击 | 跳转到最后点击的目标 | 不会卡死或报错 |

### 3.7 页面加载性能规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| DOMContentLoaded | 3秒内完成 | 页面基础结构加载 |
| 可交互时间 | 加载完成后立即可点击 | 所有选项可见可点击 |
| 无白屏 | 不允许长时间白屏 | 用户体验要求 |

### 3.8 响应式布局规则

| 屏幕尺寸 | 布局规则 | 说明 |
|----------|----------|------|
| 桌面端(1920x1080) | 每行约6列 | 内容居中,左右留白 |
| 移动端(375x667) | 自适应列数减少 | 所有内容可见可点击 |
| 大屏幕(2560x1440) | 内容居中不过度拉伸 | 左右留白增加 |

## 4. 错误处理

| 错误码 | 错误信息 | 触发条件 | 用户提示 |
