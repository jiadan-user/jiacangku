# AI能力 - AI自动回复（EasyChat）业务规则

## 1. 功能概述
- **功能描述**: AI 自动回复功能（EasyChat），允许卖家/发布者为单个帖子独立控制 AI 自动回复的开启/关闭，AI 理解用户意图并自动回复消息
- **用户角色**: 卖家/发布者（Job、Property、Marketplace等分类）
- **入口位置**: 
  1. 发布成功页（/biz/en/publish/success?id={postId}）- 首次发布时设置
  2. 发布管理列表页（My Post）> 各分类 Tab > EasyChat Settings 按钮 - 后续管理
  3. 会话页（/biz/en/chat?postId=...）- 买家侧AI回复体验
- **依赖模块**: AI 对话服务、消息模块、发布管理模块

> ⚠️ **实测覆盖说明**: 当前所有业务规则和流程均基于**Jobs分类的58条实测用例**提取。其他分类（Property/Marketplace/Services/Community）产品设计上应支持EasyChat，但尚未通过实际测试验证，可能存在业务场景差异。

## 2. 核心流程
### 2.1 主流程
1. 卖家进入发布管理列表页（My Post）
2. 切换到对应分类 Tab（如 Jobs）
3. 找到目标帖子，点击"EasyChat Settings"按钮
4. 弹出 EasyChat Settings 弹窗
5. 查看当前 AI 开关状态（ON/OFF）
6. 点击 Toggle 开关切换状态
7. 开关状态实时同步到卡片标签（无需关闭弹窗）
8. 关闭弹窗（X 按钮或 ESC 键）
9. 卡片显示最新 EasyChat 状态

### 2.2 异常流程
- 开关切换失败 → 显示错误提示，状态回滚
- 网络超时 → 显示"操作失败，请重试"
- 弹窗加载失败 → 显示"加载失败"提示
- AI 服务不可用 → 开关置灰，显示"服务暂不可用"

## 3. 业务规则
### 3.1 开关控制规则
| 规则项 | 说明 |
|-------|------|
| 控制粒度 | 单个帖子独立控制（不是全局开关） |
| 默认状态 | 新发布帖子默认 OFF（需手动开启） |
| 状态同步 | 开关状态实时同步到卡片标签（无需刷新） |
| 切换确认 | 无需二次确认，立即生效 |
| Toast 提示 | 无 Toast 提示 |
| 持久化 | 状态保存到服务端，刷新页面后保持 |

**开关状态定义**：
- **ON**：AI 自动回复开启，卡片显示"AI EasyChat On"蓝色标签
- **OFF**：AI 自动回复关闭，卡片无"EasyChat On"标签

### 3.2 弹窗交互规则
| 交互方式 | 效果 | 说明 |
|---------|------|------|
| 点击"EasyChat Settings"按钮 | 打开弹窗 | 显示当前开关状态 |
| 点击 Toggle 开关 | 切换状态 | ON ↔ OFF，实时同步 |
| 点击 X 按钮 | 关闭弹窗 | 状态已保存 |
| 按 ESC 键 | 关闭弹窗 | 状态已保存 |
| 点击蒙层区域 | 不关闭弹窗 | 防止误操作 |
| 弹窗保持打开 | 可连续切换 | 切换后弹窗不自动关闭 |

**弹窗内容**：
- 标题："EasyChat Settings"
- AI 图标 + "EasyChat" 文字
- 说明文案："AI Auto-Reply takes care of your conversations, understands intent, and responds instantly. Stay focused on your business — AI handles the rest."
- Toggle 开关（蓝色=ON，灰色=OFF）
- AI 自动回复对话预览图
- 右上角 X 关闭按钮

### 3.3 卡片标签规则
| 标签状态 | 显示位置 | 显示内容 | 交互 |
|---------|---------|---------|------|
| AI 开启 | 卡片右上角 | 蓝色"AI EasyChat On"标签 | 只读，点击无操作 |
| AI 关闭 | 无标签 | - | - |

**标签同步规则**：
- 开关切换后，卡片标签立即更新（无需关闭弹窗）
- 标签为只读展示，点击不触发任何操作
- 标签状态与弹窗 Toggle 开关实时同步
- 刷新页面后标签状态保持

### 3.4 AI 自动回复规则
| 规则项 | 说明 |
|-------|------|
| 触发条件 | EasyChat ON 且收到买家消息 |
| 回复时机 | 买家发送消息后立即回复（秒级） |
| 回复内容 | AI 理解买家意图，生成相关回复 |
| 回复范围 | 仅回复与帖子相关的问题 |
| 回复语言 | 自动识别买家语言，使用相同语言回复 |
| 人工介入 | 卖家可随时查看对话并手动回复 |

**AI 回复能力**：
- 理解买家意图（询价、咨询详情、预约等）
- 回答常见问题（价格、位置、可用性等）
- 引导买家留下联系方式
- 无法回答的问题提示"请联系卖家"

### 3.6 权限规则
- **卖家/发布者**：可开启/关闭自己帖子的 AI 自动回复
- **买家**：无权限查看或修改 EasyChat 设置
- **游客**：无权限访问发布管理页面

### 3.7 发布成功页AI开关规则

| 规则项 | 说明 |
|-------|------|
| 展示位置 | 发布成功页（/biz/en/publish/success?id={postId}） |
| 展示时机 | Job发布成功后自动跳转到发布成功页 |
| 默认状态 | ON（蓝色） |
| 卡片内容 | AI图标 + "EasyChat"标题 + 功能说明文案 + Toggle开关 |
| 功能说明文案 | "AI Auto-Reply takes care of your conversations, understands intent, and responds instantly. Stay focused on your business — AI handles the rest." |
| 开关操作 | 点击Toggle切换ON/OFF状态 |
| 状态持久化 | 刷新页面后状态保持 |
| 页面跳转 | 开关操作不触发页面跳转 |

**交互规则**：
- 点击开关切换状态：ON → OFF 或 OFF → ON
- 切换后无Toast提示
- 切换后无二次确认弹窗
- 开关状态立即生效
- 日志触发：`handleChatAiChange true/false`

### 3.8 会话页AI自动回复规则

| 规则项 | 说明 |
|-------|------|
| 触发条件 | EasyChat ON 且买家发送消息 |
| 回复时机 | 买家发送消息后秒级回复 |
| 回复标识 | 消息标注"AI Auto Reply" |
| 回复位置 | 对话区左侧（对方消息气泡） |
| 回复语言 | 自动识别买家语言，使用相同语言回复 |
| 回复内容 | AI理解买家意图，生成相关回复 |
| 人工介入 | 卖家可随时查看对话并手动回复 |

**AI回复能力**：
- 理解买家意图（询价、咨询详情、预约等）
- 回答常见问题（价格、位置、可用性等）
- 引导买家留下联系方式
- 无法回答的问题提示"请联系卖家"

**文件上传与AI回复（Jobs分类实测）**：
- 买家上传简历（.jpg/.pdf/.doc/.docx等） → AI识别为简历文件，回复确认收到并说明后续流程
- 买家上传形象照片（.jpg/.png） → AI识别为个人照片，回复确认收到并说明用途
- 买家上传护照图片（.jpg/.png） → AI识别为身份证件，回复确认收到并说明身份验证流程

**其他分类可能的文件类型差异**（待实测验证）：
- Property：身份证明、收入证明、房产证等
- Marketplace：商品瑕疵照片、交易凭证等
- Services：资质证明、现场照片等
- Community：活动照片、海报等

### 3.9 会话页底部工具栏规则

| 工具 | 图标位置 | 功能 | 支持格式 |
|-----|---------|------|---------|
| 定位/位置 | 第1个图标 | 发送位置信息 | - |
| 文件上传 | 第2个图标 | 上传简历等文件 | .pdf,.doc,.docx,.xls,.xlsx,.ppt,.pptx,.zip,.txt |
| 图片上传 | 第3个图标 | 上传形象照、护照等图片 | image/JPG,image/PNG,image/JPEG |
| Send按钮 | 右侧按钮 | 发送文本消息 | - |

**Send按钮状态**：
- 输入框为空：disabled（灰色不可点击）
- 输入框有内容：可点击（深色）
- 点击后：消息发送，输入框清空，按钮恢复disabled

**消息展示规则**：
- 己方消息：对话区右侧，深色背景气泡
- 对方消息：对话区左侧，浅色背景气泡
- AI回复消息：左侧，标注"AI Auto Reply"
