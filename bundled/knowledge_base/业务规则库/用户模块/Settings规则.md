# Settings规则

## 1. 功能概述
- **业务价值**：为已登录用户提供自助管理个人资料、账户安全、区域偏好的能力，提升用户体验和账号安全性，减少客服工作量。
- **用户角色**：所有已登录用户（访客无权访问，未登录访问会被重定向）
- **入口位置**：首页右上角用户头像/用户名 → 下拉菜单 → "Settings" → 跳转至 `https://aepub.58v5.cn/biz/en/user/home`

## 2. 核心流程
- **主流程**：
  1. 点击右上角用户头像 → 选择 Settings → 进入 Settings 页面（默认 Account Settings Tab）
  2. 左侧 Tab 切换：Profile / Account Settings / Country & Region
  3. 修改对应字段 → 点击 Save（或自动保存）→ 显示成功提示 → 刷新验证持久化
- **异常流程**：
  - 未登录访问 Settings → 重定向至首页或登录页
  - 修改 Email → 需要邮箱验证流程（发送验证码到新邮箱 → 输入验证码 → 验证成功）
  - 修改密码时旧密码错误 → 显示错误提示，不允许修改
  - 新旧密码相同 → 提示不能相同
  - 切换 Language 为 Arabic → 界面变为 RTL 布局，操作元素定位需适配

## 3. 业务规则

### 3.1 输入规则

| 功能模块 | 字段 | 类型 | 必填 | 格式 | 说明 |
|---------|------|------|------|------|------|
| Profile | Avatar | 文件 | 否 | JPG/PNG/GIF，≤10MB | 头像上传，超过 10MB 提示过大；非图片格式拒绝上传 |
| Profile | User Name | text | 否 | 长度 ≤60字符 | 超过 60 字符应被截断或提示错误；不能为空 |
| Profile | First Name | text | 否 | 无限制 | 可为空 |
| Profile | Last Name | text | 否 | 无限制 | 可为空 |
| Profile | Email | text | 是 | 标准邮箱格式 | 修改后需邮箱验证；显示实时字符数统计 |
| Profile | Phone | text + 区号 | 否 | 区号 + 号码主体 | 区号默认 +971（AE站）；可切换 +86 等 |
| Account Settings | Old Password | password | 是（修改密码时） | 无限制 | 支持任意字符（字母、数字、特殊字符、中文、Emoji） |
| Account Settings | New Password | password | 是（修改密码时） | ≥1数字 + ≥1大写 + ≥1小写 + 8-16位 | 不满足规则时 Confirm 按钮禁用 |
| Country & Region | Country | 下拉单选 | 是 | 22个国家/地区 | UAE/Singapore/United States 等 |
| Country & Region | Language | 下拉单选 | 是 | English/Arabic 等 | 切换后界面语言变化 |

### 3.2 校验规则

| 字段 | 校验规则 | 前端行为 | 后端校验 |
|------|---------|---------|---------|
| User Name | 不能为空 | 清空后点击 Save 应提示错误或禁用按钮 | ✅ |
| User Name | 长度 ≤60字符 | 输入 60 字符应被截断或提示错误 | ✅ |
| User Name | XSS/特殊字符 | 输入 `<script>` 或 Emoji 应被转义或拒绝 | ✅ |
| Email | 标准邮箱格式 | 输入非法格式应提示错误 | ✅ |
| Password | 规则校验 | 不满足规则时 Confirm 按钮 disabled | ✅ |
| Old Password | 正确性校验 | 输入错误旧密码点击 Confirm 应提示错误 | ✅ |
| New Password ≠ Old Password | 新旧密码不能相同 | 相同时点击 Confirm 应提示错误 | ✅ |
| Avatar | 文件大小 ≤10MB | 超过 10MB 应提示文件过大 | ✅ |
| Avatar | 图片格式 | 上传 .pdf 等非图片格式应被拒绝或提示格式错误 | ✅ |

### 3.3 权限规则

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 访问权限 | 仅已登录用户可访问 | 未登录访问 Settings 页面应被重定向至首页或登录页 |
| Email 修改 | 修改后需邮箱验证流程 | 发送验证码到新邮箱 → 输入验证码 → 验证成功后才生效 |
| 第三方账号绑定 | 需跳转到对应平台授权 | 点击 Link 按钮 → 跳转 Google/Facebook/Apple OAuth 页面 → 授权成功后返回 |
| 密码修改 | 需验证旧密码 | 旧密码错误不允许修改 |

### 3.4 业务约束

| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| Profile 保存方式 | 统一 Save 按钮提交所有字段 | 修改任意字段后点击 Save，所有字段一起提交 |
| User Name 修改影响 | 修改后页面右上角昵称同步变化 | 建议测试用例修改后必须恢复原值，否则影响依赖用户名的断言 |
| 密码修改后恢复 | 测试用例必须后置恢复原密码 | 否则后续所有用例无法登录 |
| Country 切换影响 | 切换后首页内容/分类联动更新 | 切换到 Singapore 后首页分类/内容应对应 SG 站 |
| Language 切换影响 | 切换到 Arabic 后界面变为 RTL | 操作元素定位需适配；建议测试用例立即恢复 English |
| 重复执行策略 | 所有用例支持幂等重复执行 | 使用读取-取反、时间戳后缀、A/B 交替、执行后复原等策略 |

## 4. 错误处理

| 错误场景 | 错误提示 | 前台展示 | 处理方式 |
|---------|---------|---------|---------|
| 未登录访问 Settings | - | 重定向至首页或登录页 | 检测登录状态，未登录则跳转 |
| User Name 为空 | "User name cannot be empty" | Save 按钮禁用或提示错误 | 前端校验阻止提交 |
| User Name 超长 | "User name is too long" | 输入时截断或提示错误 | 前端限制 60 字符 |
| Avatar 文件过大 | "File size exceeds 10MB" | 上传时提示错误 | 前端/后端校验文件大小 |
| Avatar 格式错误 | "Invalid file format" | 上传时提示错误 | 前端/后端校验文件类型 |
| Old Password 错误 | "Incorrect old password" | 密码修改弹窗提示错误 | 后端校验旧密码，错误则拒绝修改 |
| New Password 与 Old Password 相同 | "New password must be different" | 弹窗提示错误 | 后端校验新旧密码，相同则拒绝修改 |
| New Password 不满足规则 | - | Confirm 按钮禁用 | 前端实时校验密码规则（数字+大写+小写+8-16位） |
| Email 格式错误 | "Invalid email format" | 输入时提示错误 | 前端校验邮箱格式 |
| 网络异常 | "Network error, please try again" | Save 时提示错误 | 捕获网络异常，提示用户重试 |

## 5. 依赖模块

- **上游依赖（谁调用我）**：
  - 所有业务域：已登录用户可从任何页面通过右上角用户头像下拉菜单进入 Settings。
  - 登录业务域：登录成功后，用户可访问 Settings 页面。
  - 钱包业务域：提现/收款流程中，如用户资料不完整（如未设置密码、未绑定手机号），可能引导用户进入 Settings 完善信息。
  - KYC 认证业务域：KYC 失败后，可能引导用户在 Settings 中更新联系方式或身份信息。

- **下游依赖（我调用谁）**：
  - 邮件服务：修改 Email 时，发送验证码到新邮箱。
  - 短信服务：绑定/修改手机号时，发送验证码到新手机号。
  - OAuth 认证服务：绑定第三方账号（Google/Facebook/Apple）时，调用对应平台的授权接口。
  - 存储服务：上传头像时，调用文件存储服务（如 OSS/S3）。

- **跨域交互说明**：
  - Settings 修改的用户资料（邮箱、手机号、昵称、头像、国家、语言）会同步到所有业务域（如钱包、二手交易、房产、招聘等），影响这些业务域中用户信息的展示和验证。
  - Country 切换后，首页内容和分类会联动更新，影响二手交易、房产、招聘等业务域的推荐内容。
  - Language 切换后，全站界面语言变化，影响所有业务域的文案展示。

## 6. 已知问题

- **技术风险**：
  - **邮箱/短信验证码依赖**：修改 Email/Phone 依赖邮件和短信服务，若服务延迟或失败，用户无法收到验证码。
  - **网络中断场景**：网络中断时点击 Save 应显示错误提示，需确保前端有网络异常捕获和用户提示。
