# 登录规则

## 1. 功能概述
- **业务价值**：为所有平台用户提供安全可靠的身份认证入口，支持多种登录方式（邮箱/手机号+密码、验证码登录、第三方登录），保障用户账号安全并提供便捷的登录体验。
- **用户角色**：所有访客用户（未登录状态）
- **入口位置**：首页右上角「Log in / Register」按钮，点击后打开登录弹窗

## 2. 核心流程
- **主流程**：点击登录按钮 → 打开欢迎弹窗 → 输入邮箱/手机号 → Continue → 进入对应登录页（密码页/验证码页） → 完成登录 → 弹窗关闭，显示已登录状态。
- **异常流程**：
  - 输入错误密码 → 显示错误提示 → 重新输入或选择忘记密码
  - 未注册邮箱/手机号 → 自动进入注册流程（显示 "Hi new friend"）
  - 验证码过期/错误 → 提示错误 → 重新发送或重新输入
  - 第三方登录取消授权 → 返回登录弹窗

## 3. 业务规则
### 3.1 输入规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 统一输入框 | 邮箱或手机号 | 系统自动识别输入类型，无需切换标签 |
| 邮箱格式 | 符合标准邮箱格式 | 如 user@domain.com |
| 手机号格式 | 支持带国家码或仅号码主体 | AE站自动识别 +971，输入 501234570 或 +971 501234570 均可 |
| 密码输入 | 任意字符，前端不做格式限制 | 支持字母、数字、特殊字符、中文等 |
| 验证码输入 | 任意字符，前端不做长度限制 | 由后端验证正确性 |

### 3.2 校验规则
| 字段 | 类型 | 必填 | 格式 | 默认值 | 说明 |
|------|------|------|------|--------|------|
| Email or phone number | String | 是 | 邮箱或手机号格式 | - | 欢迎页统一输入框 |
| Password | String | 是 | 无限制 | - | 密码登录页密码框 |
| Verification code | String | 是 | 无限制 | - | 验证码登录页验证码框 |
| Continue按钮 | - | - | - | disabled | 输入框为空时禁用，有内容时启用 |
| Log in按钮 | - | - | - | disabled | 密码为空时禁用，有密码时启用 |
| Confirm按钮 | - | - | - | disabled | 验证码为空时禁用，有内容时启用 |

### 3.3 权限规则
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 访问权限 | 任何访客均可访问 | 无需预登录 |
| 已登录状态 | 右上角显示用户头像，不显示「Log in / Register」 | 已登录用户可点击头像下拉菜单退出登录 |
| 验证码发送 | 同一邮箱/手机号 60 秒内不可重复发送 | 防止验证码滥用 |

### 3.4 业务约束
| 规则项 | 规则内容 | 说明 |
|--------|----------|------|
| 邮箱/手机号自动识别 | 输入 501234570 自动识别为 AE +971 手机号 | 仅适用于 AE 站 |
| 未注册账号处理 | Continue 后直接进入注册页（显示 "Hi new friend"） | 不进入密码页 |
| 未设置密码账号 | 显示特殊提示并引导使用验证码登录 | 不显示密码输入框，显示 "Send code" 按钮 |
| 验证码倒计时 | 发送验证码后显示 60 秒倒计时（实测 59s） | 倒计时期间不可重复发送 |
| 隐私协议展示 | 底部显示隐私声明文案，无需勾选 | "By continuing, you accept OK's Terms of Use..." |
| 第三方登录 | 支持 Google / Facebook / Apple | 点击后跳转到对应平台的 OAuth 授权页 |

## 4. 错误处理
| 错误码 | 错误信息 | 触发条件 | 用户提示 |
|--------|----------|----------|----------|
| - | 邮箱/手机号格式错误 | 输入非法格式后 Continue | 显示格式错误提示（具体文案待确认） |
| - | 密码错误 | 输入错误密码后 Log in | 页面文案包含 "incorrect password" 或 "error" 关键词 |
| - | 验证码错误 | 输入错误验证码后 Confirm | 后端返回错误提示 |
| - | 验证码过期 | 验证码超过有效期（60秒+）后提交 | 提示验证码已过期，请重新发送 |
| - | 验证码发送频控 | 60秒内重复点击 Send code | 按钮显示倒计时，禁用重复发送 |
| - | 未注册账号 | Continue 后发现账号未注册 | 自动跳转到注册页，显示 "Hi new friend" |

## 5. 依赖模块
- **上游依赖（谁调用我）**：
  - 所有业务域：访问需登录功能时，触发登录弹窗或重定向到登录页。
  - 钱包业务域：提现、收款等功能需先登录。
  - 二手交易业务域：发布商品、创建订单、查看订单需先登录。
  - 房产业务域：发布房源、收藏房源、联系房东需先登录。
  - 招聘业务域：发布职位、投递简历需先登录。
- **下游依赖（我调用谁）**：
  - 短信服务：手机号验证码登录时发送短信验证码。
  - 邮件服务：邮箱验证码登录时发送邮件验证码。
  - OAuth 认证服务：第三方登录（Google/Facebook/Apple）时调用对应平台的授权接口。
- **跨域交互说明**：
  - 登录成功后，用户身份信息（用户ID、邮箱、手机号、头像等）存储在 Session/Token 中，供全站所有业务域使用。
  - 登录状态通过 Cookie 或 Token 维护，过期后需重新登录。

## 6. 已知问题
- **产品待确认问题**：
  - TC014：手机号未设置密码场景，密码页提示文案仍为 "Sign in with your email code instead."，应改为 "Sign in with your phone code instead." 或通用文案。
  - "Forgot your password?" 不是 `<a>` 链接标签，而是可点击的文本元素，可能影响可访问性。
  - 验证码输入框为 `<input type="tel">`，而非 `<input type="text">`，需使用 `input[type="tel"]` 定位。
- **技术风险**：
  - 第三方登录（Google/Facebook/Apple）依赖外部 OAuth 服务，若服务异常可能导致登录失败。
  - 验证码发送依赖短信和邮件服务，若服务延迟或失败，用户无法收到验证码。
  - 密码输入框支持任意字符（包括特殊字符、中文、Emoji），需确保后端有 XSS 防护和 SQL 注入防护。
