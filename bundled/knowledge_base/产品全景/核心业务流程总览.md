# 核心业务流程总览

## 1. 文档说明

本文档提供所有业务模块的核心流程概览，帮助快速理解产品的整体业务架构。

详细的业务流程和观测点请参考 `业务知识图谱/` 下的各业务域文档。

## 2. 房产业务域

### 2.1 核心流程
- **房产发布流程**：卖家发布房产信息
- **房产浏览流程**：买家浏览房产列表和详情
- **房产搜索流程**：买家搜索和筛选房产
- **房产收藏流程**：买家收藏感兴趣的房产
- **房产管理流程**：卖家管理已发布的房产

### 2.2 业务流程全景图

```mermaid
graph TB
    subgraph 卖家侧流程
        A1[登录] --> A2[进入发布页]
        A2 --> A3[选择分类]
        A3 --> A4[填写信息]
        A4 --> A5[提交发布]
        A5 --> A6[发布成功]
        A6 --> A7[管理房产]
    end
    
    subgraph 买家侧流程
        B1[进入首页] --> B2[浏览列表]
        B2 --> B3[查看详情]
        B3 --> B4[收藏房产]
        B2 --> B5[搜索筛选]
        B5 --> B3
    end
    
    subgraph 搜索侧流程
        C1[输入关键词] --> C2[执行搜索]
        C2 --> C3[展示结果]
        C3 --> C4[应用筛选]
        C4 --> C3
    end
    
    A6 --> B2
```
