# Vidflow 群发任务用例 - 问题原因与修改方案

针对 `test_vidflow_group_task.py` 在编写与调试过程中遇到的问题及对应修改方案整理如下。

---

## 1. TC009/TC010 筛选按钮点击未生效

**现象**：选择状态下拉「已暂停」或填写时间范围后点击「筛选」，列表未按条件刷新。

**原因**：
- 点击筛选时 Ant Design 的下拉/日期面板尚未关闭，浮层遮挡导致未点到真实按钮；
- 页面上「筛选」按钮文案为 `<span>筛 选</span>`（中间有空格），用 `get_by_role("button", name="筛选")` 可能未命中或未触发。

**修改方案**：
- 在 **TC009**：选择状态后先 `wait_for_status_dropdown_closed()`，再 `click_filter_button()`；在页面对象中 `click_filter_button()` 优先点击 `locator("span").filter(has_text="筛 选")`。
- 在 **TC010**：填写日期后先 `wait_for_date_picker_closed()`，再 `click_filter_button()`；同样通过点击「筛 选」span 或带 `force=True` 的按钮确保生效。
- 页面对象新增：`wait_for_status_dropdown_closed()`、`wait_for_date_picker_closed()`、`wait_for_filter_applied()`。

**涉及文件**：`pages/vidflow_group_task_page.py`、`test_cases/vidflow/test_vidflow_group_task.py`。

---

## 2. TC001 断言报错 NameError: name 'on_list' is not defined

**现象**：TC001 执行到断言时抛出 `NameError: name 'on_list' is not defined`。

**原因**：断言中使用了变量 `on_list`，但未在用例内赋值。

**修改方案**：在断言前增加赋值：

```python
on_list = group_page.is_on_group_task_list_page(timeout=8000)
assert on_list, "未进入群发任务列表页或 URL 不包含 groupTaskManagement/groupTaskList"
```

**涉及文件**：`test_cases/vidflow/test_vidflow_group_task.py`。

---

## 3. 用例执行中途退出账号 / 未在同一页面执行

**现象**：希望所有 case 在同一浏览器、同一页面顺序执行，且中途不退出登录。

**原因**：每个 case 开头都调用的 `_ensure_logged_in()` 会执行 `load_session()` 并 `goto(entry_url)`，可能覆盖当前 session 或造成多余刷新。

**修改方案**：
- 已登录时：若 `is_logged_in()` 为 True，**不再调用** `load_session()`；若当前已在列表页则直接 return，否则仅 `goto(entry_url)` 回到列表（同一页面内跳转）。
- 未登录时才执行 `load_session()` 或完整登录流程。
- 保持模块级 `page` fixture（`scope="module"`），仅启动一次浏览器，全部用例跑完后才关闭。

**涉及文件**：`test_cases/vidflow/test_vidflow_group_task.py`。

---

## 4. TC011 新建任务流程缺少「下一步」、取消未生效

**现象**：
- 新建任务为多步 wizard，需先点「下一步」才能到有「提交」的步骤；
- 点击「取消」后弹窗未关闭。

**修改方案**：
- 在「点击新建任务」与「点击提交」之间增加一步：`click_next_step_in_modal()`，页面对象中新增 `click_next_step_in_modal()`，点击 `get_by_role("button", name="下一步")` 或 `get_by_text("下一步")`。
- 取消按钮：与筛选类似，页面可能为 `<span>取 消</span>`。在 `cancel_or_close_modal()` 中优先点击 `locator("span").filter(has_text="取 消")`，再回退到 `get_by_role("button", name="取消")` / `get_by_text("取消")`，并使用 `force=True`。

**涉及文件**：`pages/vidflow_group_task_page.py`、`test_cases/vidflow/test_vidflow_group_task.py`。
