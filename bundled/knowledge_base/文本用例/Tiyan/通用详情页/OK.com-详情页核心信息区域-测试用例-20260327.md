从列表页选择不同类型的帖子进行测试：
- **适用类别**: Community、Services、Marketplace、Cars、Others 等

## 📝 测试用例清单

### 模块 A: 价格区域（Price Area）

#### TC001: 普通价格正常展示
- **优先级**: P0（最高）
- **测试类型**: 冒烟测试 (smoke)
- **前置条件**:
  1. 访客身份访问列表页
  2. 列表页至少有一个包含价格的帖子卡片
- **测试步骤**:
  1. 在列表页找到一个有明确价格显示的帖子卡片（如 "$500"）
  2. 记录列表页显示的价格值（如 "$500"）
  3. 点击该帖子卡片进入详情页
  4. 等待详情页加载完成
  5. 定位详情页价格区域元素
- **预期结果**:
  - 详情页价格区域清晰可见
  - 价格文字大小合适（通常为大字号，突出显示）
  - 价格格式正确（包含货币符号 "$"）
  - 价格位于页面显著位置（通常在顶部或标题附近）
- **验证点**:
  - `assert price_element.is_visible()`
  - `assert "$" in price_text`
  - `assert price_text != ""`

#### TC002: 免费帖子价格展示
- **优先级**: P1
- **测试类型**: 功能测试 (regression)
- **前置条件**:
  1. 访客身份访问列表页
  2. 列表页存在价格为 "Free" 的帖子
- **测试步骤**:
  1. 在列表页找到价格显示为 "Free" 的帖子卡片
  2. 点击进入详情页
  3. 等待详情页加载完成
  4. 检查价格区域显示
- **预期结果**:
  - 详情页价格显示 "Free" 或等价标识
  - 价格区域不显示货币数字
  - 元素仍然可见且位置合理
- **验证点**:
  - `assert "free" in price_text.lower()` 或 `assert price_text == "Free"`

#### TC003: 列表页与详情页价格一致性
- **优先级**: P0（最高）
- **测试类型**: 核心流程 (core_flow)
- **前置条件**:
  1. 访客身份访问列表页
  2. 列表页至少有一个包含价格的帖子
- **测试步骤**:
  1. 在列表页找到第一个有价格的帖子
  2. 提取并记录列表页显示的价格（如 "$1200"）
  3. 点击该帖子进入详情页
  4. 等待详情页加载完成
  5. 提取详情页显示的价格
  6. 对比两个价格值
- **预期结果**:
  - 列表页价格 = 详情页价格
  - 格式一致（货币符号、千分位分隔符）
- **验证点**:
  - `assert list_price == detail_price`
  - `assert list_price.replace(",", "") == detail_price.replace(",", "")`（排除格式差异）

#### TC004: 价格格式化正确性
- **优先级**: P2
- **测试类型**: 功能测试 (regression)
- **前置条件**:
  1. 访客身份
  2. 存在价格超过 1000 的帖子
- **测试步骤**:
  1. 从列表页进入一个价格 ≥ 1000 的帖子详情页
  2. 检查价格格式
- **预期结果**:
  - 价格包含货币符号（如 "$"）
  - 大于等于 1000 的价格使用千分位分隔符（如 "$1,200"）
  - 小数点后最多2位（如有小数）
- **验证点**:
  - `assert re.match(r'^\$[\d,]+(\.\d{1,2})?$', price_text)`

#### TC005: 无价格帖子的展示
- **优先级**: P2
- **测试类型**: 边界值测试 (boundary)
- **前置条件**:
  1. 存在不显示价格的帖子类型（如某些服务类、活动类帖子）
- **测试步骤**:
  1. 找到列表页中不显示价格的帖子（或价格区域为空/占位符）
  2. 点击进入详情页
  3. 检查价格区域
- **预期结果**:
  - 价格区域显示 "Contact for price" 或类似占位文本
  - 或价格区域不显示（业务规则允许）
  - 页面其他信息正常展示
- **验证点**:
  - `assert price_element.is_visible() or "contact" in page_content.lower()`

## 📌 特殊场景说明

### 1. 帖子类别限制
**重要**：招聘（Jobs）和房产（Property）类别的帖子不适用本测试用例，原因：
- 这些类别的详情页布局可能不同
- 某些字段（如地点区域的交互方式）可能有差异
- 测试时需从列表页动态获取 URL 时，显式排除这两个类别

**适用类别**：Community、Services、Marketplace、Cars、Others 等

### 2. 地点区域的定位
地点区域位于**标题下方、发布时间上方**，是一个纯文本展示区域：
- 不支持点击跳转
- 通常显示城市、州信息（如 "Washington, DC"）
- 可能伴有位置图标（pin icon）

### 3. 描述内容必填性
描述字段为**必填项**，不存在无描述的帖子：
- 所有测试用例都应验证 `len(description_text) > 0`
- 如果发现无描述的帖子，可能是页面加载异常，需重试或报告 bug

### 4. 价格为 0 的处理
某些帖子可能价格为 "$0" 或 "Free"，需要区分：
- "$0" 仍然显示价格格式
- "Free" 显示为文本标识

### 5. 标题过长的处理
标题超过一定长度时，可能：
- 截断并显示省略号
- 完整显示但换行（最多 2-3 行）

### 6. 相对时间的更新
从列表页到详情页可能经过几分钟，相对时间可能变化：
- "59 minutes ago" → "1 hour ago"
- 验证时允许小幅差异
