## Application Overview - 详情页面包屑导航

### 功能定位
面包屑导航（Breadcrumb）是位于详情页图片上方的导航组件，用于展示当前页面在网站层级结构中的位置，并提供快速返回上级页面的能力。

### 业务价值
1. **用户导航定位**：帮助用户理解当前页面在网站结构中的位置
2. **快速返回上级**：提供点击返回上级类目或首页的快捷方式
3. **SEO优化**：增强页面结构化数据，提升搜索引擎友好度

### 页面状态枚举
- **正常状态**：面包屑完整展示，所有中间节点可点击
- **当前页状态**：最后一个节点为当前页标题，不可点击，以 `<span>` 展示
- **移动端状态**：在小屏幕设备上的响应式展示

### 业务规则（基于 UI 实测推断）
1. **层级展示规则**：按照「首页 > 一级类目 > 二级类目 > ... > 当前页标题」的顺序展示
2. **链接规则**：除最后一个节点外，所有节点均为可点击链接
3. **当前页规则**：最后一个节点为当前页面标题，使用 `<span>` 展示，不可点击
4. **分隔符规则**：节点之间使用箭头图标（`>`）分隔
5. **路径完整性**：面包屑路径必须完整反映页面的类目层级

### 模块划分
1. [P0] **基础展示**：面包屑的基本显示和结构
2. [P0] **链接导航**：点击面包屑节点进行页面跳转
3. [P1] **视觉样式**：面包屑的样式、悬停效果
4. [P1] **响应式**：移动端/平板端的显示适配
5. [P2] **跨类目验证**：不同类目详情页的面包屑一致性
