## Application Overview（阶段一摘要）

**功能定位**：车详情页展示单车完整信息，支持买家浏览、收藏、分享、联系卖家、查看地图与相关车辆，支持卖家管理自己的帖子。

**用户角色**：游客（仅浏览）、买家（收藏/联系）、卖家（自有帖子可编辑）。

**业务规则（从 UI 推断）**：
- 未登录点击 **Favourites** 会弹出登录框（✅ 实测）；**PC Web** 详情页 **Contact** 当前为 **免登录态**，未登录点击 **不弹** 登录框（2026-05-06 与 TC006 对齐）
- 分享为复制链接到剪贴板，并出现 "Link copied" 提示（✅ 实测）
- 地图以弹窗形式展示，带关闭按钮（✅ 实测）
- 面包屑可返回上级（Home / Cars / Used cars）
- 相关车辆横向滚动，可点击跳转其他详情页

**页面状态枚举**：正常详情态、地图弹窗态、登录弹窗态、图片查看器全屏态、搜索建议展开态。

**模块划分（探测顺序）**：
1. [P0] 从列表进入详情与页面展示
2. [P0] 分享与地图
3. [P0] 收藏与联系（未登录/已登录）
4. [P1] 卖家信息与面包屑
5. [P1] 搜索框与全局导航
6. [P1] 主图与图片查看器
7. [P1] 相关车辆
8. [P2] Browse/更多选项菜单、页脚链接
