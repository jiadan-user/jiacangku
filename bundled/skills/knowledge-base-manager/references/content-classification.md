# 内容分类指南

## 分类决策树

### 步骤 1：判断层级

```
输入内容 → 分析特征 → 决策层级

问：内容描述的是什么？

├─ 产品设计、架构、流程？
│  → 产品架构层
│
├─ 具体规则、校验、逻辑？
│  → 业务规则层
│
└─ 测试相关内容？
   → 测试知识层（或保留在原模块下）
```

### 步骤 2：判断分类

#### 业务规则层分类

```
问：适用范围是什么？

├─ 全局通用（所有模块、所有站点）
│  → 通用规则/<规则类型>.md
│  示例：表单校验规则.md、错误码定义.md
│
└─ 特定模块（用户/商品/交易等）
   → 模块规则/<模块名>/<规则类型>.md
   示例：模块规则/用户模块/登录规则.md
   
   站点差异：合并到模块规则中作为章节，不单独创建"站点差异"目录
```

### 步骤 3：确定文件和章节

```
问：应该创建新文件还是追加到已有文件？

├─ 已有相关文件且内容相关
│  → 追加到已有文件的相应章节
│
├─ 已有文件但内容不相关
│  → 创建新文件
│
└─ 没有相关文件
   → 创建新文件
```

## 分类原则

### 1. 特定优于通用

优先放到具体模块，而非通用规则。

**示例**：
```
内容："登录验证码有效期60秒"
决策：放在 模块规则/用户模块/登录规则.md（而非 通用规则/）
```

### 2. 聚合优于分散

相关内容应集中存放。

**示例**：
```
内容：登录相关的多条规则
决策：都放在 登录规则.md（而非分散到多个文件）
```

### 3. 主要优于次要

放到最相关的位置。

**示例**：
```
内容："登录时需要验证手机号格式"
决策：放在 登录规则.md（而非 表单校验规则.md）
```

### 4. 站点差异合并到模块规则

不单独创建"站点差异"目录，作为章节合并到模块规则中。

**示例**：
```markdown
# 车辆发布规则

## 必填字段
...

## AE站特殊规则
- 货币单位：AED
- 价格最大值：100,000,000 AED

## US站特殊规则
- 货币单位：USD
- 价格最大值：1,000,000 USD
```

## 实战案例

### 案例 1：测试用例文档

**输入**：
```
TC001: 登录时验证码错误5次后锁定账号30分钟
TC002: 手机号格式错误时提示"手机号格式不正确"
TC003: 密码长度必须8-20位
```

**分析**：
- 文档类型：测试用例
- 包含知识：业务规则（验证码锁定、手机号校验、密码长度）

**映射决策**：
```
业务规则 → 业务规则层/模块规则/用户模块/登录规则.md
  - 章节：验证码规则
  - 内容："验证码错误5次锁定30分钟"
```

### 案例 2：需求文档

**输入**：
```
需求：US站支付金额显示格式：$1234.56（无千分位逗号）
```

**分析**：
- 文档类型：需求文档
- 包含知识：业务规则（US站货币格式）

**映射决策**：
```
业务规则 → 业务规则层/模块规则/支付模块/支付规则.md
  - 章节：US站货币显示规则
  - 内容："US站格式：$1234.56（无千分位）"
```

### 案例 3：接口文档

**输入**：
```
POST /api/user/login
参数：
- phone: string, 必填, 11位数字
- code: string, 必填, 6位数字

响应：
- 200: 登录成功, 返回 token
- 400: 参数错误
- 401: 验证码错误
```

**分析**：
- 文档类型：接口文档
- 包含知识：业务规则（登录接口参数规则、错误码）

**映射决策**：
```
业务规则 → 业务规则层/模块规则/用户模块/登录规则.md
  - 章节：登录接口规范
  - 内容：完整的接口参数、响应说明
```

## 复杂场景处理

### 场景 1：跨模块内容

**示例**：全局搜索功能（涉及商品搜索、用户搜索、订单搜索）

**处理**：
- 放在 **通用规则/搜索规则.md**（而非某个模块下）
- 在各模块规则中添加引用

### 场景 2：跨层级内容

**示例**：用户登录

**处理**：
- **产品架构层**：登录流程图（宏观流程）
- **业务规则层**：登录校验规则（具体规则）
- 三处都保留，添加交叉引用

### 场景 3：版本变更内容

**处理**：
- 保留历史版本（使用折叠块）
- 标注当前版本和变更时间

```markdown
## 验证码规则

### 当前版本 (v2.0, 2026-03-23)
- 有效期：90秒

### 历史版本
<details>
<summary>v1.0 (2026-01-15)</summary>
- 有效期：60秒
</details>
```

## 快速查询表

| 内容特征 | 目标位置 |
|---------|---------|
| 产品架构图、模块清单 | 产品架构层/ |
| 业务流程图、状态流转 | 产品架构层/业务流程图/ |
| 表单校验、错误码、权限 | 业务规则层/通用规则/ |
| 模块具体规则 | 业务规则层/模块规则/<模块>/ |
| 站点特有规则 | 合并到模块规则中，不单独创建目录 |
| 测试相关内容 | 询问用户或保留在原模块下 |

## 分类检查清单

分类完成后，自查：

- [ ] 内容放在了正确的层级（产品/业务）
- [ ] 分类符合适用范围（通用/模块）
- [ ] 文件命名清晰
- [ ] 章节划分合理
- [ ] 添加了交叉引用（如适用）
- [ ] 元数据完整（来源、时间）
- [ ] 站点差异已合并到模块规则中（不单独创建目录）
