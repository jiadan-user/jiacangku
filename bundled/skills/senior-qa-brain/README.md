# Senior QA Brain - 资深测试思维引擎

> 像资深测试工程师一样思考和分析，从Figma设计生成高质量测试用例

---

## 🚀 5分钟快速上手

### 第一步: 提供Figma链接

```
"请使用senior-qa-brain分析这个Figma设计
https://www.figma.com/design/xxx?node-id=xxx"
```

### 第二步: 选择报告模式（可选）

AI会询问你需要哪种模式：
- **快速版**：核心功能+关键风险+待确认问题（约3000字，推荐）
- **详细版**：完整分析报告（约15000字）

### 第三步: 评审测试分析报告

AI生成报告后，请review以下内容：
- 功能理解是否正确
- 业务流程是否完整
- 风险识别是否合理
- 回答"待确认问题清单"（如果有）

### 第四步: 确认生成用例

```
确认，开始生成用例
```

AI会分批生成：
- **第一批**：核心流程用例（30-50条）
- **第二批**：边界/异常/安全用例（根据需要）

## ✨ v2.0 新特性

### 1. Markdown格式输出

**为什么改用Markdown？**
- ✅ 纯文本,易于Git版本管理
- ✅ 任何编辑器都能打开和编辑
- ✅ 支持全文搜索,快速定位用例
- ✅ 跨平台兼容,无需安装专用软件
- ✅ 便于Code Review和协作

**对比XMind格式**:

| 维度 | XMind | Markdown |
|------|-------|----------|
| 编辑器 | 需安装软件 | 任何文本编辑器 |
| Git diff | 二进制难对比 | 清晰展示变更 |
| 搜索 | 困难 | 全文搜索 |
| 跨平台 | 需安装 | 通用 |
| 文件大小 | 较大 | 小巧 |

### 2. 快速版分析报告

**问题**：完整报告15000+字，阅读负担重

**解决**：提供两种模式
- **快速版**：3000字，核心要点（推荐首次使用）
- **详细版**：15000字，深度分析（复杂项目使用）

### 3. 分批生成策略

**问题**：一次生成100+条用例，耗时长，难以review

**解决**：分批生成
- 第一批：核心流程用例（30-50条）
- 用户review确认
- 第二批：补充边界/异常/安全用例

### 4. Token消耗提示

**新增**：任务开始前预估Token消耗
- 小型功能：约20K-30K tokens
- 中型功能：约50K-80K tokens
- 大型功能：约100K-150K tokens

## ⚡ 常见问题

### Q1: 生成多少条用例合适？
**A**: 第一轮建议30-50条核心用例，后续根据需要补充。

### Q2: Markdown格式和XMind哪个好？
**A**: 
- **Markdown**: 易于编辑、Git版本控制、团队协作
- **XMind**: 可视化漂亮，适合演示

**建议**: 优先使用Markdown，需要演示时可用工具转换。

### Q3: 如果Figma设计不完整怎么办？
**A**: 会在分析报告中标注"待确认"，生成部分用例，提供补充建议。

### Q4: 快速版和详细版报告怎么选？
**A**: 
- 首次使用、简单功能 → 快速版
- 复杂功能、需深度分析 → 详细版
- 不确定 → 先快速版，不够再要详细版

### Q5: Token消耗大约多少？
**A**: 
- 快速版报告 + 50条用例：约40K tokens
- 详细版报告 + 100条用例：约100K tokens
