# 用户登录功能测试分析报告

## 📌 一、功能概述

### 1.1 功能定位
这是一个标准的用户登录功能，支持邮箱或用户名登录，提供"记住我"和"忘记密码"辅助功能。

**核心价值**:
- 用户视角: 快速进入系统，访问个人数据和功能
- 业务视角: 身份验证，保护用户数据安全，建立用户会话

**功能边界**:
- ✅ 包含: 账号密码登录、记住我、忘记密码入口
- ❌ 不包含: 第三方登录（如微信、Google）、验证码登录

### 1.2 目标用户角色

| 角色 | 权限/特征 | 识别依据 | 是否需要测试 |
|------|----------|---------|-------------|
| 已注册用户 | 有效账号密码 | 基本场景 | ✅ 需要 |
| 新用户 | 无账号 | "立即注册"链接 | ✅ 需要 |
| 忘记密码用户 | 账号存在但忘记密码 | "忘记密码"链接 | ✅ 需要 |
| 锁定用户 | 账号被锁定 | 推断（常见场景） | ⚠️ 待确认 |

**❓ 需确认**:
- 是否有多次密码错误后的账号锁定机制？
- 是否支持多设备同时登录？

---

## 🔄 二、核心业务流程

### 2.1 主流程图
```
[用户进入登录页] 
    ↓
[输入账号密码]
    ↓
[点击登录按钮]
    ↓
[后端验证]
    ↓
[成功] → [创建会话] → [跳转首页]
    ↓
[失败] → [显示错误提示] → [返回登录页]
```

### 2.2 详细流程拆解

#### 主流程1: 正常登录

**触发条件**: 用户有有效账号和密码

**步骤拆解**:
1. **进入登录页**
   - 用户操作: 访问/login
   - 系统响应: 显示登录表单
   - 涉及数据: 无
   - 识别依据: Figma登录页设计

2. **输入账号密码**
   - 用户操作: 在输入框填写用户名和密码
   - 系统响应: 实时显示输入内容（密码遮罩）
   - 涉及数据: username, password
   - 识别依据: Figma表单设计

3. **（可选）勾选记住我**
   - 用户操作: 勾选"记住我"复选框
   - 系统响应: 复选框被选中
   - 涉及数据: remember_me = true
   - 识别依据: Figma复选框设计

4. **点击登录按钮**
   - 用户操作: 点击"登录"按钮
   - 系统响应: 按钮进入Loading状态，发送登录请求
   - 涉及数据: POST /api/login {username, password, remember_me}
   - 识别依据: Figma按钮设计 + 推断接口

5. **后端验证**
   - 用户操作: 无（等待）
   - 系统响应: 验证账号密码是否正确
   - 涉及数据: 数据库查询
   - 识别依据: 推断

6. **登录成功**
   - 用户操作: 无
   - 系统响应: 
     * 创建Session/Token
     * 如果勾选"记住我"，延长有效期
     * 跳转到首页或原访问页面
   - 涉及数据: session_id, token
   - 识别依据: 推断

**成功结果**: 用户进入首页，顶部显示用户信息

**异常分支**:
- 用户名不存在 → 提示"用户名或密码错误"
- 密码错误 → 提示"用户名或密码错误"
- 账号被锁定 → 提示"账号已被锁定，请联系管理员"（待确认）
- 网络超时 → 提示"请求超时，请重试"

**❓ 需确认**:
- 登录成功后跳转到哪个页面？首页还是登录前访问的页面？
- 错误提示是否区分"用户不存在"和"密码错误"？（安全考虑：不应该区分）
- "记住我"的有效期是多久？7天？30天？
