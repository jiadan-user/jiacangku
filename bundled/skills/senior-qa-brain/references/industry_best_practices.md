# 行业最佳实践

> 不同行业的特殊测试要求

## 电商行业

### 核心关注点
- 支付安全
- 库存一致性
- 价格准确性
- 促销规则

### 必测场景
```
1. 库存超卖测试
2. 价格篡改测试
3. 优惠券叠加测试
4. 秒杀并发测试
5. 购物车同步测试
```

---

## 金融行业

### 核心关注点
- 资金安全
- 交易幂等性
- 数据加密
- 审计日志

### 必测场景
```
1. 金额精度测试（分为单位）
2. 交易防重测试
3. 密码加密传输测试
4. 操作日志完整性测试
5. 异常回滚测试
```

---

## 社交/UGC平台

### 核心关注点
- 内容审核
- 隐私保护
- 反垃圾
- 可访问性

### 必测场景
```
1. 敏感词过滤测试
2. 图片内容识别测试
3. 用户举报流程测试
4. 黑名单机制测试
5. 防刷测试
```

---

## SaaS/企业服务

### 核心关注点
- 数据隔离
- 权限控制
- 性能稳定性
- 数据备份

### 必测场景
```
1. 多租户数据隔离测试
2. 角色权限矩阵测试
3. 大数据量性能测试
4. 数据导出/备份测试
5. API限流测试
```

---

**记住**: 行业特性决定测试重点
