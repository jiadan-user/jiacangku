# 测试数据策略

> 如何准备高质量的测试数据

## 测试数据分层

```
L1: 基础数据（正常场景）
L2: 边界数据（临界值）
L3: 异常数据（非法值）
L4: 特殊数据（攻击向量）
L5: 极端数据（压力测试）
```

## 数据生成策略

### 1. 正常数据

**原则**: 符合业务规则，真实可用

```
用户注册数据:
- 邮箱: test001@example.com
- 密码: Test123456
- 昵称: 测试用户001
- 手机: 13800138001
```

### 2. 边界数据

**原则**: 最小值、最大值、临界值

```
密码长度(8-20):
- 7位: Abc1234 (边界-1)
- 8位: Abc12345 (最小值)
- 20位: Abcd1234567890123456 (最大值)
- 21位: Abcd12345678901234567 (边界+1)
```

### 3. 异常数据

**原则**: 空、null、错误格式

```
邮箱异常数据:
- 空字符串: ""
- null
- 缺少@: testexample.com
- 缺少域名: test@
- 特殊字符: test@#$%.com
```

### 4. 特殊字符数据

**SQL注入**:
```
' OR '1'='1
admin'--
'; DROP TABLE users--
```

**XSS攻击**:
```
<script>alert('XSS')</script>
<img src=x onerror=alert('XSS')>
```

### 5. 极端数据

**大数据量**:
```
- 10000条列表数据
- 1MB的文本输入
- 100GB的文件上传
```

## 数据管理

### 数据隔离

- 测试环境独立数据库
- 不影响生产数据
- 可重复执行

### 数据清理

- 测试后自动清理
- 避免脏数据积累
- 保持环境干净

---

**记住**: 高质量的测试数据是测试成功的基础
