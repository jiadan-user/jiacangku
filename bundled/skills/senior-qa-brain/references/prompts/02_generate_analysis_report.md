## 报告保存路径


## 交互流程

```
AI生成报告 → 保存文件 → 提示用户阅读 → 等待用户反馈

用户反馈类型:
1. "确认" → 进入用例生成阶段
2. "修正: ..." → 修改报告,重新提交
3. 直接回答问题 → 补充到报告,更新后提交
4. "有XX错误" → 修正后重新生成
5. 提供需求文档 → 执行 03_diff_with_prd.md，追加差距分析章节后再进入用例生成
```

> 可选步骤：若用户在评审阶段提供了需求文档（PRD），执行 `03_diff_with_prd.md` 对报告进行差距补充，再生成测试用例。
