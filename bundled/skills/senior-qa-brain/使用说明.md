# Senior QA Brain - 使用说明

```

│
├── references/                 # 参考文档（分析/报告/用例时的依据）
│   ├── figma_analysis_guide.md      # Figma 分析框架（结构/交互/数据/边界/隐藏需求）
│   ├── test_thinking_framework.md   # 测试思维框架（5W1H、策略、风险、优先级）
│   ├── risk_patterns_library.md     # 风险模式库（安全/业务/数据/性能/兼容）
│   ├── scenario_generation_rules.md # 场景生成规则（五维模型、实用性优先）
│   ├── practical_test_rules.md      # 实用测试规则（80/20、必测/不测清单）
│   ├── test_data_strategy.md        # 测试数据策略（正常/边界/异常/特殊字符）
│   ├── industry_best_practices.md   # 行业最佳实践（电商/金融/社交/SaaS）

│       ├── 02_generate_analysis_report.md # 步骤2：生成测试分析报告
```

## 安装

1. **环境**
   - Python 3.8+（若用 `scripts/generate_md_testcases.py`）
   - Figma MCP Server（在 Cursor 中配置，用于拉取 Figma 设计）

2. **Skill 使用方式（Cursor）**
   - 将本仓库克隆或复制到本地，或在 Cursor 中打开该目录。
   - 在 Cursor 的 Agent Skills 中把本项目的 `SKILL.md` 加入可用 Skill，或确保对话时能引用到该 Skill 的上下文（具体以 Cursor 当前「技能/规则」配置为准）。

3. **脚本（可选）**
   - 若需本地用 Python 生成 Markdown 用例：
   ```bash
   cd /Users/a58/Desktop/senior-qa-brain/scripts
   python3 generate_md_testcases.py   # 运行脚本内 demo_usage() 会生成示例 .md
   ```
   - 脚本仅负责按既定格式输出 .md，不依赖 Figma；与 AI 配合时，通常由 AI 按 `references/prompts/04_generate_markdown_testcases.md` 生成内容，再决定是否用该脚本做二次格式化或合并。

4. **输出目录**
   - 用例/报告默认写入：`/Users/a58/Desktop/测试用例`。若不存在需先创建；或在 Skill/提示词中改为你的路径。

## 使用

1. **在对话中启用**
   - 对 AI 说使用「senior-qa-brain」或引用本 Skill，并给出 Figma 设计链接，例如：
   ```
   请用 senior-qa-brain 分析这个 Figma 设计：https://www.figma.com/design/xxx?node-id=xxx
   ```

2. **流程（由 AI 按 SKILL + references 执行）**
   - 用 Figma MCP 拉取设计 → 按 `01_analyze_figma` 做分析。
   - 按 `02_generate_analysis_report` 生成测试分析报告（快速版/详细版）。
   - 你评审报告并回答「待确认问题」。
   - 确认后，按 `04_generate_markdown_testcases` 生成 Markdown 测试用例，并保存到 `/Users/a58/Desktop/测试用例`。

3. **仅用脚本生成示例 .md**
   ```bash
   cd scripts && python3 generate_md_testcases.py
   ```
   会在脚本中指定的路径生成示例用例文档（见脚本末尾 `demo_usage()`）。

## 文件用途速查

| 文件/目录 | 用途 |
|-----------|------|
| `SKILL.md` | Skill 完整说明，供 AI 理解能力与流程 |
| `references/prompts/*.md` | 分析 Figma、写报告、写用例的分步提示词 |
| `references/*.md`（除 prompts） | 分析/风险/场景/数据/行业等参考规则 |
| `scripts/generate_md_testcases.py` | 用代码生成标准格式的 Markdown 用例文件 |
| `assets/*` | 报告与用例的示例，便于对照格式 |
