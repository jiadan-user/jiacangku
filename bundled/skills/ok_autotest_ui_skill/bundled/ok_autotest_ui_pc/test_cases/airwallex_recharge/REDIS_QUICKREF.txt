├──────────────────────────────────────────────────────────────────────────────┤
│ Q: 提示 "Key 不存在或已过期"？                                               │
│ A: 先触发验证码发送，然后立即查询（验证码通常 5-30 分钟有效）               │
│                                                                              │
│ Q: Redis 连接失败？                                                          │
│ A: 检查网络连通性、host/port 配置、防火墙设置                               │
│                                                                              │
│ Q: Redis 认证失败？                                                          │
│ A: 确认密码正确，使用 --password 参数指定                                   │
│                                                                              │
│ Q: 如何在测试代码中使用？                                                    │
│ A: 参考 REDIS_TOOLS_README.md 的"在自动化测试中使用"章节                   │

│ 📚 Python 代码示例                                                           │
├──────────────────────────────────────────────────────────────────────────────┤
│ import redis                                                                 │
│                                                                              │
│ r = redis.Redis(                                                             │
│     host='test-yongjia01.rdb.58dns.org',                                     │
│     port=50584,                                                              │
│     password='1c34ca4035bf7bc6',                                             │

│ )                                                                            │
│                                                                              │
│ # 获取验证码                                                                 │
│ code = r.get('ucenter:verify:code:100002:wangyongli@58.com')                │
│ print(f"验证码: {code}")                                                     │
│                                                                              │
│ # 检查剩余时间                                                               │
│ ttl = r.ttl('ucenter:verify:code:100002:wangyongli@58.com')                 │
