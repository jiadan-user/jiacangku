## 覆盖度与风险说明（简要）

- **已覆盖（实测/文档化）**: 登录态多 profile URL（含 **Jobs 子路径翻页** URL）；`document.title`；本人 **多类目 Tab + Services 默认**；本人资料卡 **Top Seller / Dubai / 简介、动态帖子数、编辑图标**；帖子卡片 **收藏**（TC007）、**Contact→微聊**（TC012）；**访客态他人主页收藏 / Contact**（TC041、TC042）；他人 **Contact**；他人 A/B 列表与空态；顶栏与资料主体分离；无 `h1` 策略（TC030）。**不覆盖**：资料卡分享、用户举报。  
- **仍待补测**: 访客本人主页（TC014）与 TC041/042 的**具体拦截 UI** 形态、非法 ID（TC017）、历史栈后半、控制台错误、**TC009 翻页 URL** 的截图归档、类目 Tab 切换后的数据差异。  
- **待产品确认**: `document.title` 中类目列表与 Tab 全集不一致的原因；**0 listing** 单复数规范；微聊页 URL/组件命名用于自动化的稳定契约。
