## 关键发现

1. **防重复提交机制**: 系统能正确处理 11ms 内的 5 次连续点击，仅执行一次取消收藏操作，防护机制完善

2. **用户菜单交互**: 标准的下拉菜单行为，支持点击外部区域关闭，符合用户体验最佳实践

3. **页面状态持久化**: 即使在非首页（第2页）刷新，页码状态也能正确保持，说明分页状态可能存储在 URL 参数或 sessionStorage 中

4. **过期帖子保护**: 过期帖子虽然显示在收藏列表中，但其链接指向通用首页且无法跳转到详情页，这是合理的产品设计，防止用户访问已下架内容

5. **登录错误处理**: 错误提示清晰明确 "Incorrect password."，用户可以立即重试，体验良好
