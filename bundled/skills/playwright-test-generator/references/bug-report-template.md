# Bug 清单报告模板

> 阶段 4 生成 bug 清单报告的格式规范

---

## 文件命名

**固定文件名**：`bug-report.md`

**存放位置**：项目根目录或用户指定目录

---

## 文件管理规则

### 规则 1：追加模式

- **第一个批次**：如果文件不存在，创建新文件
- **后续批次**：如果文件已存在，追加新 bug 到文件末尾
- **禁止**：重复创建文件或覆盖已有内容

### 规则 2：无 bug 时不生成

- 如果本批次所有用例都 PASSED，**不生成** bug-report.md
- 如果本批次有 FAILED 用例，才生成或追加

---

```markdown

> 测试文档：[文档名称]

**预期结果**：{从用例文档提取的预期结果}

**实际结果**：{录制时观察到的实际情况}

**问题截图**：`bug-tc{编号}.png`

---

## TC{编号}: {用例标题}

**复现步骤**：
```

## 字段说明

### 1. 用例编号和标题

```markdown
## TC006: 输入关键词点击 Search 执行搜索
```

- 格式：`## TC{编号}: {标题}`
- 编号：与用例文档中的编号一致
- 标题：与用例文档中的标题一致

---

### 2. 复现步骤

```markdown
**复现步骤**：
1. 打开浏览器，访问 https://example.com/search
2. 在搜索框输入 "Toyota"
3. 点击 "Search" 按钮
```

- **来源**：从用例文档的"执行步骤"部分提取
- **格式**：有序列表，每个步骤一行
- **要求**：步骤描述清晰，能够准确复现问题

---

### 3. 预期结果

```markdown
**预期结果**：页面跳转至搜索结果页，URL 包含 q=Toyota
```

- **来源**：从用例文档的"预期结果"部分提取
- **格式**：单行或多行描述
- **要求**：完整提取，不要遗漏任何验证点

---

### 4. 实际结果

```markdown
**实际结果**：页面未跳转，URL 仍为 /search，搜索框清空但无任何反应
```

- **来源**：录制时通过 snapshot 观察到的实际情况
- **格式**：清晰描述实际发生的情况
- **要求**：
  - 描述具体现象，不要猜测原因
  - 包含关键信息（URL、文案、元素状态等）
  - 与预期结果形成对比

---

### 5. 问题截图

```markdown
**问题截图**：`bug-tc006.png`
```

- **格式**：Markdown 代码格式（反引号包裹）
- **命名规范**：`bug-tc{编号}.png`
- **要求**：截图文件必须存在于项目根目录

---

## 禁止添加的内容

以下内容**不要**添加到 bug 清单中：

❌ **优先级**：如 P0、P1、Critical、Major 等
❌ **严重程度**：如 Blocker、Major、Minor 等
❌ **修复建议**：如"建议检查搜索接口"等
❌ **责任人**：如"@开发 @测试"等
❌ **状态**：如 Open、In Progress、Fixed 等
❌ **额外分析**：如"可能原因是..."等

**原因**：保持报告简洁，只记录事实（复现步骤、预期、实际、截图）

## 实现逻辑

### 检查文件是否存在

```python
import os

bug_report_path = "bug-report.md"

if os.path.exists(bug_report_path):
    # 文件存在，追加模式
    mode = "a"
else:
    # 文件不存在，创建模式
    mode = "w"
    # 需要写入文件头部
```

### 追加 bug 条目

```python
with open(bug_report_path, mode, encoding="utf-8") as f:
    if mode == "w":
        # 创建新文件，写入头部
        f.write("# Bug 清单报告\n\n")
        f.write(f"> 生成时间：{current_time}\n")
        f.write(f"> 测试文档：{doc_name}\n\n")
        f.write("---\n\n")
    
    # 追加 bug 条目
    f.write(f"## TC{tc_id}: {tc_title}\n\n")
    f.write("**复现步骤**：\n")
    for i, step in enumerate(steps, 1):
        f.write(f"{i}. {step}\n")
    f.write(f"\n**预期结果**：{expected}\n\n")
    f.write(f"**实际结果**：{actual}\n\n")
    f.write(f"**问题截图**：`bug-tc{tc_id}.png`\n\n")
    f.write("---\n\n")
```

## 注意事项

1. **文件编码**：使用 UTF-8 编码
2. **换行符**：使用 `\n`（Unix 风格）
3. **分隔符**：每个 bug 条目后添加 `---`
4. **截图路径**：使用相对路径，假设截图与 bug-report.md 在同一目录
5. **时间格式**：`YYYY-MM-DD HH:MM:SS`
